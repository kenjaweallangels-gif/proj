# Рябь песка и наносы у харвестера (веб-демо, S3)

## Рябь (`Web/src/desert/terrain.js`, `RIPPLE_GLSL` / `RIPPLE_BLOCK`)
Что было плохо (снимки `Web/dist/shots/sand_before/`): три слоя прямых параллельных гребней (9.5 см / 62 см / 2.9 м) одинаковой контрастности по всей
поверхности, включая склоны скольжения и гребни дюн («вельвет»); тёмные линии «тяжёлых минералов» во впадинах и охристые полосы — это были ЦВЕТОВЫЕ
добавки (`rOcc`, `dmin`), а не рельеф; на удалении гармоники короче пикселя давали муар и полосы.

Как сделано сейчас:
- Рябь — только **возмущение нормали** (функция `rkRippleG`, возвращает градиент высоты). Цвет не трогается, тёмных линий нет.
- Фаза = вдоль ветра + низкочастотное искажение (две октавы шума) → гребни извиваются, шаг и направление меняются; вторая волна с шагом ×1.075
  даёт биения — дислокации: гребни сливаются, обрываются, раздваиваются (Y).
- Профиль несимметричный (пологий наветренный, крутой подветренный склон), скруглённые гребни/впадины; амплитуда неравномерна — есть участки почти без ряби.
- Средний и крупный масштабы изгибаются вокруг рельефа (`kH`): фаза зависит от высоты `vWP.y`.
- Затухание: на склонах скольжения и у кромки гребня (`leeW`, там лавинные полосы), на камне, в следах, на плотном песке.
- **Фильтрация по производным**: размер пикселя вдоль ветра `|dFdx(uu)| + |dFdy(uu)|`; масштаб гаснет, когда длина волны < ~3–8 пикселей (нет муара; дальность — как у наблюдателя).
- Параметры (уклон S: 0.042 / 0.026 / 0.014; длины волн 0.11 / 0.58 / 2.7 м) — в вызовах `rkRippleG` в `RIPPLE_BLOCK`; цветовые добавки лавин смягчены.
- Стоимость: те же 2 шумовых вызова на масштаб + 2 `cos` (было 1 шум + 1 производный), масштабы сами отключаются по фильтру пикселя —
  на дистанции работает 0–1 масштаб вместо 3 (раньше отсекались только по расстоянию).

Проверка: `node tools/ripple_lab.mjs` (быстрая лаборатория без игры, тот же GLSL), `node tools/sand_look.mjs --file=sand_after.html --tag=sand_after` (кадры из игры: рассвет/полдень/закат, 1.5–80 м).

## Наносы харвестера (`Web/src/harvester/berm.js`)
Причины «странного песка» (снимки `berm_before`): наносы — отдельная сетка с упрощённым материалом (`createSandMaterial`: другая палитра и шум, без ряби, зерна, тумана
ландшафта) → видна граница по цвету; форма — симметричное прямоугольное плато/вал 3–6 м вокруг ВСЕГО силуэта, включая место под корпусом, с синусоидальной «рябью» в геометрии;
сетка 2 м против 1 м у ландшафта (ступеньки, z-fight в зоне касания), обновление раз в 7 м хода (на ходу парила/тонула).

Сейчас: материал ландшафта (`terrain.makeSurfaceMaterial()` — тот же фрагментный шейдер), атрибут масок из поля пустыни, шаг сетки 1.5 м, обновление каждые 3 м / 0.12 рад / смена ветра;
форма зависит от ветра (подветренный холм с гребнем у борта, откос осыпи ≤ 32°, язык-хвост по ветру, пологий 12° наветренный подъём, под корпусом — уровень грунта);
с гребней сыплется песок, пока машина работает; колеи — следы ландшафта (`stampRutPose` для стоящей машины, `stampTracks` на ходу).
Проверка формы без рендера: `node tools/harvester_berm_check.mjs`; снимки: `node tools/harvester_sand_look.mjs`, студия — `node tools/harvester_berm_studio.mjs`.
