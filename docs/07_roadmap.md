# 07. Дорожная карта

Оценка для одного инженера с ИИ-ассистентом и технолога на неполный день. Сроки ориентировочные.

| Фаза | Недели | Что делаем | Критерий выхода | Промпты |
|---|---|---|---|---|
| 0. Подготовка | 1–2 | Репозиторий, правила для ИИ, контракты; выбор изделия; запрос SDK VITURE; согласование камеры с ИБ | Контракты в репозитории, SDK запрошен | — |
| Д. Демо (pkg2) | 1–3, параллельно | Веб-демо на реальной GLB и пакете операции | Демо открывается у руководства | pkg2/prompts 01–06 |
| 1. Сервер и данные | 3–5 | Сервер, БД, конвейер STEP→GLB, ТП CSV→JSON, валидатор BOM | Пакет реального изделия скачивается по API | pkg1/prompts 02–04 |
| 2. Симулятор | 4–7 | SimRig: синтетическая камера, траектории, IMU; Godot-сцена рабочего места | Ядро получает кадры и позы из симулятора | pkg1/prompts 01, 05, 08 |
| 3. Трекинг | 7–11 | Плата меток, PnP, фильтр, проверка масштаба, ручная привязка | Ошибка на синтетике в порогах `06_testing.md` | pkg1/prompts 05–06 |
| 4. Шаги и HUD | 10–15 | Движок шагов, голограммы, HUD, КД, режимы | Операция проходится в симуляторе без рук | pkg1/prompts 07, 09 |
| 5. Голос и чат | 14–18 | Vosk, VAD, кнопка; чат по шагам, офлайн-очередь | ≥ 95 % команд на записях шума | pkg1/prompts 07, 10 |
| 6. Очки | 18–22 | VitureRig, запись сеансов, калибровка камера↔дисплей, стерео | Смещение измерено в мм на реальном изделии | pkg1/prompts 11 |
| 7. Пилот | 22–28 | 1–2 комплекта, одно изделие, 2–3 сборщика | Решение о тиражировании | — |

Очки заказываем на 10-й неделе, чтобы они пришли к фазе 6.
