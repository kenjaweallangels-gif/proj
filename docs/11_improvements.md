# 11. Что улучшить: идеи с приоритетами

Данные на 03.10.2026. Приоритеты: **A** — нужно для пилота, **B** — заметно повышает ценность,
**C** — по возможности. Оценка — в неделях одного инженера с ИИ-ассистентом.

## Изделие и данные

| Пр. | Идея | Зачем | Недели |
|---|---|---|---|
| A | Реальная GLB из NX (конвейер `04_cad_kd_tp_pipeline.md`) вместо процедурной модели КМ-2 | голограммы совпадают с деталями до миллиметра | 2 |
| A | Импорт ТП и КД из системы предприятия (CSV/XML → пакет операции) вместо демонстрационных | сборщик видит настоящий техпроцесс | 2 |
| A | Журнал исполнения: кто, когда, значения, фото → сервер цеха и MES; подпись ОТК | прослеживаемость, приёмка | 2–3 |
| B | Партии клея и герметика по штрихкоду: жизнеспособность считается от вскрытия, а не от начала шага | меньше брака по клею | 1 |
| B | Датчики температуры и влажности на участке → таймеры выдержки по реальным условиям | режимы по ТТ, а не «по норме» | 1 |
| B | Динамометрический ключ с Bluetooth: момент записывается сам | нет ошибок ручного ввода | 2 |
