# Озвучка: конвейер Ред. 2 (Piper → ffmpeg → Opus → vo.js)

Владелец: звукорежиссёр / голоса. Язык реплик — хашшана (`docs/lore/language.md`, §13).

## Зачем
Прежний формантный синтезатор звучал «роботом»; речь была рублёной и обрывочной. Ред. 2 заменяет его записями нейросетевого TTS **Piper** (голос `ar_JO-kareem-medium`), обработанными под каждого персонажа. Синтезатор остаётся запасным: он играет только если у реплики нет записи.

## Файлы
| Файл | Роль |

| `Tools/tts/script_s1.py` | авторский источник диалогов: сцены `S(id, условие, [(говорящий, эмоция, хашшана, RU, EN)…])` |
| `Tools/tts/native2ar.py` | латиница → огласованная арабица (единственный источник `Line_NativeScript`) |
| `Tools/tts/gen_dialogue.py` | источник → `Content/Rakis/Data/Dialogue_S1.csv` (диалектный выговор Кайра/Рэйна, арабица, Duration) |
| `Tools/tts/lexicon_check.py` | отчёт: слова реплик, которых нет в `language.md` |

| `Web/src/audio/vo_bank.js` | ленивое декодирование записей (LRU 36), лай-«бормотания» |
| `Web/src/audio/voice.js` | воспроизведение: позиционный источник, реверберация зоны, запасные пути |
| `Web/tools/vo_test.mjs` | проверка: декодирование, RMS, покрытие, синхронность субтитров, фон без гула |

## Сборка
```
pip install piper-tts numpy                # + ffmpeg c rubberband и libopus
python3 Tools/tts/gen_dialogue.py          # CSV из script_s1.py
python3 Tools/tts/piper_build.py           # ~10–40 мин на CPU; кэш WAV Piper в Tools/tts/.cache (по хешу текста и конфига)
python3 Tools/tts/gen_dialogue.py          # второй прогон: Duration в CSV = длина записи + 0.4 с
cd Web && node tools/build_data.mjs && node tools/build.mjs
node tools/vo_test.mjs --file=rakis_demo.html
```
Модель скачивается автоматически в `Tools/tts/models/` (63 МБ; в git не коммитится). Быстрая проверка отдельных реплик на слух:
`piper_build.py --only DLG_A1_001,DLG_B5_P01 --keep-wav /tmp/vo`.

## Что делает пост-обработка (на персонажа, `VOICE_FX`)
1. **Нормализация текста**: паузальные формы (сукун на конце слова), финальное удвоение буквой, «…» и «—» → запятая — иначе espeak читает «книжные» окончания.
2. **Piper**: `length_scale` = база персонажа × эмоция (Whisper/Reverent медленнее, Tense/Angry быстрее), `noise_w` — «живость» просодии.
3. **Высота и форманты** раздельно. Женские голоса — `pitch +4…+7` полутонов и `formant +2…+3`: ресемплинг сдвигает и высоту, и форманты, `rubberband` (formant=preserved) докручивает только высоту; чисто «бурундучий» сдвиг не используется. Старики и наиб — ниже и «дышащее»; дети — выше (+9…+10 / +5.5…+6).
4. **Рэйн**: темп ×1.10 и лёгкое дрожание высоты (вибрато 6.5 Гц) — «чужой» акцент добавляет сама орфография реплики.
5. **Жрица**: темп ×1.55, хор из трёх голосов (основной, октава вниз, квинта вверх с задержкой 20–35 мс), вибрато 5 Гц ±0.28 (мягкая мелизматика), реверберация RT60 2.4 с.
6. **Шёпот/дыхание**: рандомизация фазы STFT (голос → шипение), доля по персонажу (старики 0.30, Хармат 0.28) и эмоции Whisper (+0.55).
7. EQ (highpass 90/130 Гц, peaking-полосы), синтетическая реверберация (свёртка с шумовой ИХ), очень тихий шум комнаты (−58 дБ), выравнивание RMS активной речи к −20 дБFS ± поправки (шёпот −4 дБ).
8. **Кодирование**: Opus (OGG), моно, 24 кГц, `-b:a 14k` (меняется `--bitrate`), VBR, кадр 40 мс. В `vo.js` лежит data-URI по `DialogueID`; рядом — длительности `VO_DUR` и лай `BARKS` (по архетипам).

## В игре
- `dialogue.js` берёт длительность субтитра из `VO_DUR` (+0.4 с), поэтому текст не обгоняет голос и не висит после него; событие `subtitle` несёт `chain` и `audio`.
- `voice.js`: записи декодируются лениво (+ прогрев следующих двух реплик цепочки), играют через `PannerNode` (HRTF) в точке говорящего: спутники — их позиции, Хармат/жрица/страж — фигуры сиетча, **жители** (Торговец, Водоноска, Ткачиха, Мать, Ребёнок, Старик, Юноша, Паломница) — ближайший к игроку житель подходящего архетипа, закреплённый за говорящим на время сцены; если рядом никого — точка 4–7 м от игрока. Голос следует за говорящим, поддерживает паузу/фоторежим (возобновление с позиции).
- **Дакинг**: на время реплики музыка → 0.42, фон → 0.6 (`eng.duck`, `eng.ambDuck`), возврат в конце цепочки.
- **Лай толпы**: безсловесные «бормотания» хашшаны (1–3 слова, ~48 клипов, по архетипам), громкость 0.34, не более двух одновременно, не во время сюжетной реплики; субтитр лая остаётся переводом реплики из `Barks.csv`.
- **Запасные пути** (`voiceMode`): `auto` — запись; нет записи → арабский TTS браузера (если есть голос `ar-*`) или смягчённый синтезатор (×0.6 громкости); `synth` — принудительно синтезатор (отладка); `tts`; `off`. Галах (`[Galach]`) озвучивается переводом голосом TTS браузера.

## Бюджет
Банк ≤ 3 МБ в `vo.js` (data-URI = Opus × 1.33). Контролируется выводом `piper_build.py` и `vo_test.mjs`.
