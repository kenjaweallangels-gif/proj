# Звуковая карта «Rakis: Heretics»

Задача T-014. Данные — `Content/Rakis/Data/AudioEvents.csv` (`DT_AudioEvents`, 58 событий); исполнитель — `URakisAudioDirector` (`SetMusicState`, `PostEvent`). Ассеты: `/Game/Rakis/Audio/{Music,Ambience,SFX,VO,UI,MetaSounds,Mix,Attenuation}`. Инфраструктура (SoundClass/Mix/Submix/Attenuation) — `Tools/unreal_python/audio_setup.py`.

Принцип: **тишина — тоже инструмент.** Пустыня звучит мало и низко; каждый новый слой должен быть заслужен событием.

## 2. Адаптивная музыка
### 2.1 Состояния (`ERakisMusicState`) — `Music.<State>`
| Состояние | Индекс | Инструменты/слои | Темп/лад | Вход | Выход |
|---|---|---|---|---|---|
| `Silence` | 0 | — (только эмбиент) | — | быстрый спад 1.5 с | — |
| `DesertCalm` | 1 | одинокий дудук, тихий дрон баса, редкие удары рамочного барабана | свободный, без метра; фригийский от D | fade 4 с | 6 с |
| `DesertDrone` | 2 | дрон (горловое пение + синт-подклад), обертоновые «ветра», рамочный барабан на краю слышимости | без метра | 6 с | 6 с |
| `WormThreat` | 3 | инфразвуковой бас 18–30 Гц (+ гармоники 40–60 для мелких динамиков), **ломаный ритм** рамочного барабана (5+7/8 с выпадениями), сердцебиение, скрежет струн | нестабильный, ~70 → 95 bpm по `Intensity` | 1 с (стингер «вдох») | 3 с |
| `WormReveal` | 4 | хоровой удар (смешанный хор, кластер), медь-низ, затем — тишина и один дудук | фиксированная композиция под `LS_WormReveal` | синхронно с Sequencer | — |
| `SietchLife` | 5 | уд, канун, рамочный барабан, тихие струнные, женский вокализ издали | 84 bpm, макам-подобный лад (оригинальный) | 4 с, на такт | 4 с |
| `SietchNarrow` | 6 | только канун (тремоло) + низкая струна, вокализ без слов почти шёпотом | 84 bpm, разрежено | 3 с, на такт | 3 с |
| `HallChorale` | 7 | хорал (женский + мужской хор), тянущиеся аккорды, песня жрицы как соло поверх, финальный аккорд | свободный, медленный | 2 с | финальный аккорд → тишина |

### 2.2 Переходы
```
DesertCalm ⇄ DesertDrone ──(Listening)──▶ WormThreat ──(Silence beat)──▶ Silence ──▶ WormReveal ──▶ Silence ──▶ DesertDrone
                                              │ (Pass, нет кат-сцены) ─────────────────────────────────────────▲
A3: DesertCalm → A4: Silence → B1: Silence → B2: SietchLife ⇄ B3/B4: SietchNarrow → B5: HallChorale → (EndDemo)
```
- Переходы внутри одного MetaSound (`MS_Music_Adaptive`) — кроссфейд слоёв по `StateIndex` (а не смена ассета): музыка не «перезапускается».
- Переходы SietchLife ⇄ SietchNarrow — **на долю такта** (Quartz, §5); пустынные — свободно (без метра).
- `WormThreat` поднимается от `WormThreat` (0..1 = `ARakisWorm::GetThreat01()`), а не только от состояния: при Listening играет только инфразвук и сердце, при Approach — полный ломаный ритм.
- Правило тишины: между `WormThreat` и `WormReveal` — обязательные ≥ 1.5 с `Silence` (бит `SB_A2_15_Silence`), ветер тоже дакается (`SM_Duck_Worm`).

## 3. MetaSound-графы
### 3.1 `MS_Music_Adaptive` (MetaSoundSource, stereo, Music bus)
**Входы:** `StateIndex` (int 0..7), `Intensity` (float 0..1 — общая плотность, от AudioDirector: зона/толпа/шум игрока), `WormThreat` (float 0..1), `Interior` (float 0..1 — 1 в B-зонах), `Quartz Clock` (через Quartz-триггеры `OnBar`, `OnBeat`).
**Граф:**
1. 8 «станций» = 8 Wave Player-банков (stem-ы по 2–4 слоя на состояние, зацикленные, длина кратна такту для Sietch-состояний).
2. `StateIndex` → Map → целевые гейны станций; каждая станция — `Interpolate` (время из таблицы §2.1) → `Multiply`.
3. Внутри станции слои включаются по `Intensity` (слой 1 всегда, 2 при > 0.35, 3 при > 0.7).
4. `WormThreat` → (а) гейн инфразвукового слоя станции 3 `pow(x, 0.7)`, (б) Low-pass всей не-угрозной музыки 18 кГц → 2.5 кГц, (в) скорость сердцебиения 60 → 110 bpm.
5. `Interior` → Low-pass 20 кГц → 9 кГц на пустынных станциях и отправка на интерьерный сабмикс (музыка «из-за стены»).
6. Стингеры (`Trigger` входы): `OnBreathIn` (вдох перед WormThreat), `OnChoirHit` (дублируется в Sequencer), `OnFinalChord`.
7. Выход → Submix `SMX_Music` (если есть) / SC_Music.

### 3.2 `MS_Worm_Approach` (MetaSoundSource, 3D, ATT_Worm_Huge)
**Входы:** `Distance` (см, от игрока до головы), `Threat` (0..1), `Speed` (см/с, опционально).
**Слои:**
| Слой | Источник | Управление |
|---|---|---|
| Инфразвук | синус 22 Гц + шум, LP 60 Гц, + гармоника 44 Гц (для ноутбуков) | гейн = `Threat`; частота 18 → 28 Гц по `1 − Distance/120000` |
| Гул тела | гранулярный низкочастотный рёв-грув, 40–200 Гц | гейн по `Distance` (кривая inverse-square, клип на 60 м) |
| Камни (rock rattles) | банк коротких «тук-тук» камней по камню, Random Trigger | частота триггера 0 → 12 Гц по `Threat`, панорама случайная (ощущение «вокруг») |
| Шипение песка | розовый шум → BP 2–6 кГц, AM 0.5–3 Гц (волна) | гейн по `Threat × (Distance < 30000)` |
| Сердце игрока | отдельно (`Worm.Heartbeat`, 2D) | — |
**Выход** + отправка `Threat` в Audio Modulation (`MOD_WormDuck`: дакает Ambience/Music).

### 3.3 `MS_Footstep` (MetaSoundSource, 3D, ATT_Footstep)
**Входы:** `Surface` (int = `ERakisSurface`), `Loudness` (0..1 — StepLoudness из шумовой системы), `SandWalk` (bool).
**Граф:** Switch по `Surface` → банки Wave Player (по 8–12 вариантов на поверхность, Random без повторов) → гейн = `0.4 + 0.6 × Loudness`; `SandWalk` → LP 6 кГц + приглушение атаки (мягкий «шурх» вместо «хруста»); `PackedSand` — добавляется низкий «бум» 80 Гц (барабанный песок, слышно, почему он опасен). Pitch ±4 %. Компаньоны — тот же граф с `Loudness` 0.3 (`Foot.Companion`).
| Surface | Банк |
|---|---|
| Sand | хруст сыпучего песка + осыпание |
| PackedSand | глухой удар + низкий резонанс |
| Rock | сухой щелчок, камешки |
| SietchStone | мягкий удар по отполированному камню + короткий хвост реверба |
| Cloth | ковры, занавеси — почти бесшумно |
| Metal | решётки, ступени шлюза |

### 3.4 Прочие
`MS_Worm_Roar` (рёв: 3 слоя — инфраниз, «горловой» средний регистр из обработанных записей ветра в трубах, высокий скрежет зубов; длина 6 с, хвост 4 с), `MS_Thumper` (пружинный удар + звон металла, приглушённый кожей, 1.6 с цикл от `ThumperInterval`), `MS_SealDoor` (шипение уплотнителей 1.2 с + пневматический «вздох» + капли конденсата), `MS_Amb_Desert` / `MS_Amb_Sietch` (вход `Zone` int, `Wind` = WindSpeed, `Storm` = StormIntensity, `CrowdDensity`).

## 4. Червь: звуковая драматургия
| Состояние | Что слышно | Микс |
|---|---|---|
| Listening | инфразвук входит снизу (ощущается раньше, чем слышится), 2–3 «тук» камней | ветер −6 дБ (`Worm_Tension`), музыка → инфра-слой WormThreat |
| Approach | гул, камни вокруг, шипение песка, сердцебиение (2D), вибрация геймпада (`PlayWormRumble(Threat)`) | `SM_Duck_Worm`: музыка 0.4, эмбиент 0.25 |
| Silence beat | **всё выключено** 1.5 с, кроме дыхания Кайра | Silence |
| Surface | рёв (`Worm.Roar`) после раскрытия пасти, удар выхода (`Worm.Breach`), песок с колец (`Worm.RingSandfall`) | кат-сцена `SM_Cinematic` |
| Pass | гул уходит «в пол» (LP 2 кГц → 200 Гц за 4 с), камни затихают последними | восстановление 3 с |

## 5. Quartz
- Часы `QZ_Music` 84 bpm 4/4 для SietchLife/SietchNarrow; переключение состояний и стингеры — `PlayQuantized` на следующую долю (`Beat`), смена станций на `Bar`.
- Пустынные состояния без метра: Quartz используется только для стингеров с квантованием `None`.
- Барки толпы и `Loom.Clack` в B2 могут квантоваться на 1/8 (едва заметная «музыкальность» рынка) — опция, по умолчанию выкл.

## 8. Озвучка (VO)
Черновая TTS — `Tools/tts/tts_batch.py` (RU по умолчанию, `--lang en`, `--barks`), WAV → `Export/vo/` → `audio_setup.py` → `/Game/Rakis/Audio/VO/<DialogueID>` (= `VO_File`), барки → `/Game/Rakis/Audio/VO/Barks/<BarkID>`. Пение жрицы: TTS читает только выдуманный текст (до `[`), перевод — только в субтитрах. Финальная запись — актёры, те же имена файлов.
