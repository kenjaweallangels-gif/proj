# Задание на мокап (mocap brief)

Связано с `docs/animation/animlist.md`. Студия: оптическая система, 120 fps захват → 30 fps экспорт, FBX с MetaHuman-совместимым скелетом (или исходный скелет студии + ретаргет через `RTG_Mocap_to_MetaHuman`). Файлы — `Export/anim/<Set>/<AssetName>.fbx`, имена = имена из animlist (без `A_` допускается).

## 1. Площадка и реквизит
| Реквизит | Зачем |
|---|---|
| **Песочный бокс 4×6 м**, глубина 15 см (или мягкие маты + насыпанный кварцевый песок) | стопа должна *тонуть и проскальзывать* — без этого походка по песку не получится |
| Наклонная платформа 15° и 25° с ковром-песком | склоны дюн |
| Каменный блок 1×1×0.4 м | переход песок → камень |
| Бочкообразный макет кольца червя Ø 4 м (сегмент 3 м дуги) с пазами под крюки, наклон 30–60° | спуск наездника |
| Два крюка-макета 2.4 м, лёгкие (алюминий, вес 2 кг) | Оссана, наездники |
| Кувшин 6 кг, коромысло, латунная мерка, станок-макет (рама 1.8 м) | ремёсла |
| Посох 1.9 м, скамья, молитвенный коврик | быт |
| Длинная юбка / шаль на актёрах | естественная пластика ткани (для референса, сим — в UE) |

## 2. Актёры
| Роль | Тип | Заметки |
|---|---|---|
| Кайр + проводники | мужчина 20–30, лёгкий, спортивный | основная масса SandWalk |
| Оссана / наездники | атлетичная женщина, опыт паркура/скалолазания | спуск по кольцу, прыжок с перекатом |
| Рэйн | невысокий мужчина, характерный актёр | дрожь, мелкий шаг, суета |
| Жрица / танцовщица | профессиональная танцовщица (контемпорари), вокальный опыт желателен | танец без счёта, жесты пения |
| Старики, дети | актёры старше 60; дети 8–12 лет (присутствие родителей, сессии ≤ 2 ч) | толпа |

## 3. Походка по песку — главное
- **Нельзя считать вслух и нельзя музыку на площадке.** Режиссёр подаёт хлопки *в случайные моменты*: актёр меняет длину шага/делает паузу по хлопку.
- Каждый дубль — 30–40 с непрерывной ходьбы, 6 дублей, разные направления. Затем нарезка на `A_SandWalk_Long/Short/Pause/Drag`.
- Stutter: актёр «спотыкается о мысль» — нога зависает, вес остаётся сзади, нога ставится короче/шире. 10 вариантов L, 10 R.
- Контраст: 3 дубля **ровного «маршевого» шага под метроном 108 bpm** — для Рэйна (`A_Rayn_Walk_Metronome`) и для обучающего бита.
- Ступни: маркеры на носке, пятке, плюсне; дополнительно — видео ступней сбоку (референс проскальзывания).

## 4. Наездник
- Цикл перецепления крюков: 10 дублей на макете с наклоном 30°, 45°, 60°; темп ≈ 1.6 с цикл.
- Съезд по боку с торможением крюком — на наклонной горке с мягким покрытием, 6 дублей.
- Прыжок 1.5–2 м (масштабируется в UE до 6 м с ретаймом) + перекат: 6 дублей, страховка, маты.
- Важно: после приземления актриса **не оборачивается** — встаёт и идёт.

## 5. Ритуал и танец
- Танец в чаше: 3 дубля по 90 с без музыки, по ощущению «песок под ногами горячий и живой»; запрет на повтор комбинаций — хореограф следит. Затем 8 клипов по 5–8 с.
- Жрица: 5 фраз песни (`DLG_B5_P01–P05`) под черновую фонограмму TTS/вокализ — жесты «открыть», «разделить», «опустить». Лицо — head-mounted camera (MetaHuman Animator).
- Хармат: поворот с паузой «суда» — 10 дублей, разные скорости; лицо — HMC.

## 6. Ремёсла
По 3 дубля 20–40 с на каждую операцию (ткачество, продувка трубки, шов, насос, мерка воды, торг, кофе-три-глотка). Мерка воды — крупный план рук (дополнительные маркеры пальцев).

## 7. Технические требования
- T-pose в начале каждого дубля; 30 fps экспорт, root в 0 на старте, ось Z вверх, см.
- Root motion: knockdown, прыжок, starts/stops — с RM; циклы — in-place.
- Имена — как в animlist; длина цикла — целое число шагов; зацикливание проверено.
- Очистка: удаление ступенчатых скольжений **кроме** намеренных на песке (отметить в листе дублей).
- Сдача: FBX + лист дублей (CSV: файл, дубль, заметка, выбранный диапазон кадров).

## 8. Расписание (оценка)
День 1 — локомоция + SandWalk (≈ 70 % объёма P0). День 2 — наездники + спутники. День 3 — ремёсла, ритуал, танец, лица. Резерв — 0.5 дня.
