# Бюджеты производительности: RTX 3060 6 ГБ, 1920×1080, пресет ultra, цель 60 fps

Кадр 16,7 мс. Цель: стабильно ≤ 14 мс на GPU и ≤ 10 мс JS на главном потоке. Запас нужен на пики (стыковка,
смена зоны, подгрузка тайлов).

## GPU по проходам (ориентиры, проверять `EXT_disjoint_timer_query` / регулятор)

| Проход | мс | Примечание |
|---|---|---|
| Дальняя сцена: Земля, облака, атмосфера, сияние | 3–4 | тайлы и шум облаков — главные потребители |
| Небо: звёзды, Млечный Путь, планеты, Луна | ≤ 1 | телескоп может дороже |
| Карта теней Солнца (4096, подогнана под камеру) | 1–1,5 | только крупные меши отбрасывают тень |
| Ближняя сцена: станция, корабли, интерьеры, тело | 4–5 | LOD и дальность деталей |
| AO + постобработка (bloom, блики, грейд, AgX) | 1,5–2 | AO в половинном разрешении |
| Запас | ≥ 2 | |

## Видеопамять (итого ≤ 5 ГБ на ultra)

| Подсистема | ultra | high |
|---|---|---|
| Земля (база 8K, окна тайлов, ночь, рельеф, облака) | ≤ 1,2 ГБ | ≤ 0,6 ГБ |
| Станция + корабли (геометрия, текстуры, атлас надписей) | ≤ 1,5 ГБ | ≤ 0,7 ГБ |
| Небо + Луна + планеты + телескоп (с вытеснением тайлов) | ≤ 0,8 ГБ | ≤ 0,4 ГБ |
| Скафандры и тела | ≤ 0,35 ГБ | ≤ 0,2 ГБ |
| Цели рендера, тени, AO, пост | ≤ 0,5 ГБ | ≤ 0,3 ГБ |

Сжатые текстуры (KTX2: BC7 для цвета, BC5 для нормалей) уменьшают объём в 4–6 раз — пакет 13.

## Сцена

| Вид | Вызовов отрисовки | Треугольников |
|---|---|---|
| EVA у станции | ≤ 1500 | ≤ 6 млн (с тенями) |
| Внутри модуля | ≤ 800 | ≤ 3,5 млн |
| Корабли, все вместе | ≤ 400 | ≤ 2 млн вблизи |
| Тело/скафандр от 1-го лица | ≤ 60 | ≤ 0,3 млн |

## Главный поток (JS)

- Обновление всего мира ≤ 6 мс, рендер-вызовы three.js ≤ 4 мс.
- Ноль аллокаций в покадровых путях; физика предметов, погода и подгрузка — в воркерах (пакет 13).
- Без компиляции шейдеров во время игры (`App.compileAll` прогревает всё заранее).

## Как мерить

```bash
GPU=1 node tools/fps.mjs --quality=ultra --w=1920 --h=1080 --views=eva,overview,inside,interior-ring,cupola-inside --seconds=15 --params="nolock=1&governor=0"
GPU=1 node tools/cpuframe.mjs --quality=ultra --w=1920 --h=1080 --view=eva --seconds=20
```

С `governor=0` видно «честную» стоимость; без него — что держит регулятор (индикатор у счётчика fps в HUD).
