# Проверка перед слиянием пакета

## Обязательно (любой пакет)

1. `npx vite build` — без ошибок.
2. `npm run smoke` — «all checks passed» (на GPU быстрее: `GPU=1 npm run smoke`).
3. Скриншоты затронутых видов на ultra 1920×1080 днём (`--t=600`) и ночью (`--t=2000`):
   `GPU=1 node tools/screenshot.mjs --quality=ultra --w=1920 --h=1080 --views=<виды> --t=600 --out=shots/<пакет>`
4. Производительность до/после: `GPU=1 node tools/fps.mjs ... --params="nolock=1&governor=0"` — не хуже бюджета
   из `BUDGETS.md`; `cpuframe.mjs` — JS на кадр не вырос больше чем на 10 %.
5. В консоли браузера нет ошибок и предупреждений о компиляции шейдеров во время игры.
6. Обновлены `docs/ARCHITECTURE.md` (если менялись контракты), `README.md` (управление/параметры),
   `CREDITS.md` (новые ассеты), `docs/handoff/STATUS.md`.

## Визуальные критерии (сравнивать с фото МКС/НАСА)

| Что | Хорошо | Плохо |
|---|---|---|
| Земля днём | видны горы (тени рельефа у терминатора), реки, береговые линии, мелководья, просветы в облаках | равномерная «вата», размытые пятна |
| Земля ночью | огни точками и цепочками дорог, цвет натрий/LED, свечение атмосферы | круглые кляксы, блочные пиксели |
| Звёзды | стабильные, без мерцания, плотный Млечный Путь с пылевыми прожилками | мигают, редкие, пятнистый фон |
| Станция | нет щелей и просветов, у кромок толщина, стыки с фланцами и болтами | видно фон сквозь стыки, «бумажные» панели |
| Стекло | прозрачное, блик только под углом, видна толщина и рама | мутная серая плёнка |
| Тело | при взгляде вниз видно своё тело, руки берутся за поручни пальцами, рост 1,8 м | «карлик», руки висят, проход сквозь стены |
| Свет | экспозиция как у камеры на МКС, контраст солнце/тень, тёплые/холодные источники внутри | плоско, пересвечено, «серо» |

## Проверочные виды

`overview, eva, closeup, hub, docking, ring, arrays, inside, interior-lab, interior-ring, interior-cabin,
cupola-inside, airlock-inside, free-earth, free-moon, free-moon-orbit, ships` (+ `?shipshow=clean` для кораблей).

## Ручная проверка (5 минут игры)

Старт внутри → проплыть лабораторию (авто-захват поручней) → удариться о стену (торможение руками) →
отсек оборудования, надеть скафандр → шлюзование → EVA, облететь модуль, натянуть фал → вернуться →
снять скафандр → кольцо, пройти коридор, подняться по лестнице → свободная камера (C) к Луне и обратно (B) →
×3600 на минуту → телескоп на Юпитер и M42.
