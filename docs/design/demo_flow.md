#### Постановка величия (для `LS_WormReveal`, ≈ 40 с)
1. **Масштаб через малое.** Первый кадр выхода — не червь, а камень у ноги Кайра, который подпрыгивает; затем — дюна в 80 м, которая *вспухает* как тесто.
2. **Солнце затмевается.** Голова поднимается до 50 м (`SurfaceHeight`) точно между камерой и солнцем: тень накрывает троих, на 3 с кадр становится холодно-синим, по краю тела — ореол пыли с объёмными лучами (`Worm_Reveal`, `NS_Dust_LightShaft`).
3. **Крошечный силуэт.** На спине — три наездника. Сначала их не видно; камера находит их на 12-й секунде: точка на кольце, потом вторая. Зритель *пересчитывает масштаб* — это люди.
4. **Пасть.** Три лепестка раскрываются медленно (`MouthOpen01` 0 → 1 за 2.5 с), кольца кристаллических зубов ловят солнце. Рёв приходит *после* раскрытия, не вместе.
5. **Песок с колец.** С каждого кольца стекает песок водопадами (`NS_Worm_RingSandfall`) — 90 сегментов, видно, как волна изгиба проходит по телу.
6. **Спуск Оссаны.** Наездница перецепляет крюки с кольца на кольцо, съезжает по боку, прыгает последние 6 м на песок, гасит падение перекатом и *не оборачивается* на червя.
7. **Уход.** Червь опускается по дуге; на песке остаётся борозда шириной 40 м; камни ещё 4 с подпрыгивают по затухающей.
Камера — без быстрых склеек: 4–5 планов, длинный телевик снизу (фокус 200 мм) на голову и широкий план с тремя фигурками в нижней трети.

## 4. Договорённости для StoryDirector (`ARakisStoryDirector`)
- Каждый бит срабатывает **один раз**. Несколько битов с одним триггером выполняются параллельно, каждый со своей `Delay`.
- `Beat:<ID>` срабатывает после **завершения** бита: `PlayDialogue` — после конца всей цепочки NextID (`OnLineFinished` последней строки); `PlayCinematic` — после `OnFinished`; `TitleCard` — после показа (4 с); `SetWeather`, `SetMusic`, `ForceWorm`, `CrowdRitual`, `Hint` — сразу после исполнения.
- `CrowdRitual` идемпотентен (три источника: таймер B2, вход в B3, страховка в B5).
- Ранние `WormState:*` биты (`SB_A2_05`–`07`) срабатывают, только если игрок сам разбудил червя до сценарного выхода; они не мешают сценарному выходу.
- `SetWeather` Param = `PresetID,BlendSec`.
- `Ellipsis` (S2) — склейка золотого пути, формат и правила — §5 и `docs/ui/ui_design.md` §12. `Beat:<Ellipsis>` срабатывает **только если склейка состоялась** (в момент возврата картинки); при отказе (свободная игра) зависимые биты не исполняются.
- Первая реплика цепочки, запущенной `PlayDialogue`, играет **без проверки** `Condition` (сценарный `DLG_WRM_L01` звучит, даже если червь спит); реплики по `NextID` — только при выполненном условии.

## 5. Золотой путь (~3:40) и эллипсисы

Скрипт сценария — 3:40, а уровень — 1.87 км пешком (~14 мин, `docs/level/layout.md` §4). Разрыв закрывают две **склейки**
(действие `Ellipsis`, точки `Rakis.Ellipsis.A2/A3` из `level_markup.py`): как монтажный переход — затемнение, титр-время на
