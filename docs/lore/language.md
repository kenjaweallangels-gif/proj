# Язык Ракиса: хашшана (Ḥaššāna)

Внутренний документ нарратива. Язык **оригинальный** (◆ допущение проекта): не канонический язык книг, не чакобса и не арабский. Он *звучит* как потомок арабского, потому что так и задуман: это язык, у которого были арабские предки, но он прожил свои полторы тысячи лет. Ни одна реплика в игре не является цитатой из книг и не является готовым арабским предложением.

## 0. Откуда он взялся (легенда для команды)
1. **Караванный язык.** Задолго до Кина по пустыне ходили торговцы пряностью. Их речь была смесью старого пустынного языка и жаргона перевозчиков: короткие слова, повелительные формы, счёт и меры воды.
2. **Имперские века.** Жречество писало на галахе, а на караванном языке говорили. Галах дал ему слова для машин, денег и чинов; язык упростился: исчезли падежные окончания, слились межзубные звуки (θ → t, ð → z, ẓ → ḍ), 2-е лицо перестало различать род.
3. **После Голода и Рассеяния** караванный язык стал языком всего Ракиса. Звучит он сухо и глухо: в пустыне громкий голос считается дурным тоном и плохой приметой. Отсюда и самоназвание — «приглушённая речь».
4. **Возрожденцы** Табр-ан-Нура снова вытаскивают архаику из резьбы на стенах и песен стариков. Так появился **литургический регистр** (§7.3): обращение *ō*, протяжные окончания *-an*, рефрен **rū**.

Чего мы сознательно **не** делаем: не берём слова чакобсы и фрименские слова из книг (никаких *usul*, *tau*, *sihaya*, *subakh…*, *mu zein*, *bi-la kaifa*, *ibad* и т. п.) и не собираем реплики из готовых арабских фраз. Канонические термины проекта (наиб, сиетч, Шай-Хулуд, Шайтан, Кин, Шиана) входят в язык как **имена и заимствования**.

### 1.3 Слог и стык
- Слоги: CV, CVC, CVV, CVVC, CVCC (последний — только в конце слова: *ʿajj*, *jamm*).
- В начале слова нет стечений согласных: императив получает протетическое *i-* (*iṭmun!* «замри!»).
- Удвоение согласного (*šadda*) — полноценная длина: *ḥass* ≠ *ḥas*.
- Артикль **an-** не ассимилируется (в отличие от арабского): *an-tirb*, *an-ṣalt*, *an-Nāʾib*.
- Клитики **bi-, li-, fu-, ka-, wa-** перед артиклем теряют гласный: *b-an-Ḍafr*, *l-an-Nāʾib*, *f-an-ṣaḥr*.

### 1.4 Ударение
1. Ударение падает на **последний долгий слог** среди трёх последних (CVV, CVVC, CVC с удвоением): *musárrib*, *qātíbat → qā́tibat* (см. п. 3), *ʿuqū́f*, *Šay-Ḥulū́d*.
2. Если долгих нет: на предпоследний, если он закрыт (*taḍbúṭ → táḍbuṭ*); иначе на третий от конца: *ḥádaqat*.
3. Слог с ā/ī/ū всегда «тянет» ударение на себя, если он не дальше третьего от конца: *qā́tibat*, *bayyínū*.
4. Клитики (*wa-, bi-, li-, fu-, ka-*) и артикль безударны.

### 1.5 Интонация
- Утверждение: ровная линия, падение на последнем слове. Пустынники почти не повышают голос.
- Вопрос с *kay*: подъём на последнем ударном слоге. Вопрос со словом *šāl / mūn / tayn*: ударение на вопросительном слове, к концу падение.
- Обрыв (—) в данных — настоящая оборванная фраза: голос обрывается на полуслове, без падения.

## 2. Латиница (Line_Native): правила записи
- Диакритика: ā ī ū ṭ ḍ ṣ ḥ š ġ ʿ ʾ; диграф **kh**.
- Дефис отделяет артикль и клитики: *an-tirb*, *wa-fu-Kīn*, *b-an-falq*. Почтительные префиксы — тоже через дефис: *bā-Rayn*.
- Многоточие «…» — пауза, «—» — обрыв или резкая смена мысли.
- Имена собственные с заглавной: *Kīn, Šiyāna, Ossāna, Kayr, Rayn, Ḥarmāt*.
- Акцент инопланетника (Рэйн) **записан прямо в реплике**: где он произносит неправильно, там и написано неправильно (*lakatū* вместо *laqatū*). Так TTS воспроизводит акцент сам.

## 3. Арабица (Line_NativeScript): соответствие для TTS
Цель — чтобы любой арабский голос (ar-SA, ar-EG, ar-XA и т. п.) прочёл придуманное слово так, как оно задумано. Поэтому пишем **с полной огласовкой**.

| Латиница | Арабица | Пример |
|---|---|---|
| согласный + a / i / u | буква + ـَ / ـِ / ـُ | *ḥadaq* → حَدَق |
| ā / ī / ū | ـَا / ـِي / ـُو | *nūr* → نُور |
| согласный без гласной внутри слова | буква + ـْ (сукун) | *tirb* → تِرْب |
| последний согласный слова | без знака (TTS читает паузальную форму) | *ṣalt* → صَلْت |
| удвоение | буква + ـّ (шадда) + гласный | *musarrib* → مُسَرِّب |
| начальный a / i / u / ā | أَ / إِ / أُ / آ | *adwās* → أَدْوَاس, *iṭmun* → إِطْمُن |

## 4. Грамматика (кратко)

### 4.1 Корни и шаблоны
Слово = **корень** из трёх согласных (значение) + **шаблон** гласных и аффиксов (функция).
| Шаблон | Функция | Пример (корень) |
|---|---|---|
| CaCaC | глагол, совершённое (3 л. ед. м.) | *ḍabaṭ* «стучал» (Ḍ-B-Ṭ) |
| ya-CCuC / ya-CCiC / ya-CCaC | глагол, несовершённое (3 л. ед. м.) | *yaḍbuṭ* «стучит» |
| i-CCuC | повелительное | *iḍbuṭ!* «стучи!» |
| CaCC / CuCC / CiCC | действие, отвлечённое имя | *ḍabṭ* «такт, ритм» |
| CāCiC | деятель (причастие действ.) | *qātib* «наездник» (Q-T-B) |
| maCCūC | претерпевающий (причастие страд.) | *mašṭūr* «разделённый» (Š-Ṭ-R) |
| miCCaC | орудие | *miḍbaṭ* «тампер, „стучалка“» |
| maCCaC | место | *masrab* «тропа» (S-R-B) |
| CaCCāC | ремесленник, кто делает постоянно | *daššān* «торговец», *ʿaššār* «десятинщик» |
| CaCCaC / muCaCCiC | понудительная основа и её деятель | *sarrab* «вести (заставлять идти)» → *musarrib* «проводник» |
| muCCiC | «тот, кто вызывает» | *muqšiʿ* «пугающий» (Q-Š-ʿ) |
| aCCaC | сравнение («больше всего») | *aqdam* «старше», *aḍkham* «огромнее» |
| iCCaCC | становиться цветом | *iṣfarr* «пожелтеть» → *yaṣfarr* |
| -ī | происхождение (нисба) | *Kīnī* «кинский», *qaṣbī* «городской» |
| -at | женский род, единичность | *qātibat* «наездница», *nuṭfat* «капля» (от *nuṭf* «вода») |

### 4.2 Существительное
- **Род:** мужской (без показателя) и женский (*-at*). Неодушевлённые — чаще мужского рода.
- **Число:** единственное; двойственное **-ān** (*ṭullān* «две тени»); множественное:
  - «целое» — *-īn* для людей (*barriyyīn* «чужаки», *ʿaššārīn*), *-āt* для женщин и вещей (*raqbāt* «горловины»);
  - «ломаное» (внутренняя перестройка): CuCūC (*ʿaqf → ʿuqūf* «крюки», *ḥazz → ḥuzūz* «насечки», *ṣalt → ṣulūt*), aCCāC (*daws → adwās* «ступни», *qinʿ → aqnāʿ*, *ḥadq → aḥdāq*), CiCāC (*ṣuġ → ṣiġāġ* «дети»), CaCāCiC (*ḥanbān → ḥanābin* «жрецы»).
- **Артикль** **an-** делает слово определённым: *ṣalt* «камень (какой-то)», *an-ṣalt* «этот, известный камень».
- **Сопряжённое состояние (родительный):** обладаемое без артикля + обладатель: *tabr an-nūr* «укрытие света» (отсюда Табр-ан-Нур), *ʿuqūf an-Ḥūl* «крючья червя» = крючья творца, *ʿušr an-nuṭf* «десятина воды».
- **Прилагательное** стоит после существительного и согласуется по определённости: *an-ṣalt an-qadm* «старый камень».

### 4.3 Местоимения
| | Самост. | Притяж./объектный суффикс | После предлогов |
|---|---|---|---|
| 1 ед. | **ānu** | -ī (мой) / **-nī** (меня) | lī, ʿadī, ladī |
| 2 ед. | **tū** | -ak | lak, ladak |
| 3 ед. м. | **hū** | -uh (после гласной -h) | lah, ladayh |
| 3 ед. ж. | **hī** | -ah | lahā, ladayhā |
| 1 мн. | **naḥ** | -nā | lanā, ladnā, funā, munnā |
| 2 мн. / вежл. | **tūm** | -kum | lakum, ladkum |
| 3 мн. | **hum** | -hum | lahum, ladhum, munhum |

- **Вежливое «вы»:** *tūm* и глагол 2-го лица мн. ч. при обращении к одному человеку. Так говорят Илва (ко всем) и кинские чиновники. Пустынники «тыкают» всем, кроме наиба.
- Подлежащее-местоимение обычно опускают (глагол и так показывает лицо). *Ānu* в начале фразы — подчёркивание: «*я* (а не ты)».
- После согласного перед суффиксом *-kum* может вставляться *u*: *tamm + kum → tammukum*.
- *dīlī* «моё» (букв. «то, что моё»), *dīlak* «твоё».

### 4.4 Глагол
**Совершённый вид** (прошедшее, законченное): основа CaCaC + суффиксы лица.
| | ḍabaṭ «стучать» | tāl «прийти» (полый) | zamm «затянуть» (удвоенный) | baġā «хотеть» (слабый) |
|---|---|---|---|---|
| 1 ед. | ḍabaṭ**ku** | tul**ku** | zamam**ku** | baġay**ku** |
| 2 ед. | ḍabaṭ**ka** | tul**ka** | zamam**ka** | baġay**ka** |
| 3 м. | ḍabaṭ | tāl | zamm | baġā |
| 3 ж. | ḍabaṭ**at** | tāl**at** | zamm**at** | baġ**at** |
| 1 мн. | ḍabaṭ**nu** | tul**nu** | zamam**nu** | baġay**nu** |
| 2 мн. / вежл. | ḍabaṭ**kun** | tul**kun** | zamam**kun** | baġay**kun** |
| 3 мн. | ḍabaṭ**ū** | tāl**ū** | zamm**ū** | baġ**ū** |

**Несовершённый вид** (настоящее, привычное, будущее с *ġad*): приставка + основа CCuC (гласный основы i или a задан в словаре: *yanfil*, *yaʿhad*).
| | ḍabaṭ | tāl | zamm | baġā |
|---|---|---|---|---|
| 1 ед. | **a**ḍbuṭ | **a**tūl | **a**zumm | **a**bġī |
| 2 ед. | **ta**ḍbuṭ | **ta**tūl | **ta**zumm | **ta**bġī |
| 3 м. | **ya**ḍbuṭ | **ya**tūl | **ya**zumm | **ya**bġī |
| 3 ж. | **ta**ḍbuṭ | **ta**tūl | **ta**zumm | **ta**bġī |
| 1 мн. | **na**ḍbuṭ | **na**tūl | **na**zumm | **na**bġī |
| 2 мн. / вежл. | **ta**ḍbuṭ**ū** | **ta**tūl**ū** | **ta**zumm**ū** | **ta**bġ**ū** |
| 3 мн. | **ya**ḍbuṭ**ū** | **ya**tūl**ū** | **ya**zumm**ū** | **ya**bġ**ū** |

- **Повелительное:** *iḍbuṭ!* / мн. *iḍbuṭū!*; у полых *tūl!*, *ḥūf!*, *jūf!*, *dūr!*; у удвоенных *zumm!*, *ṣukk!*; понудительная основа — *bayyin!* / *bayyinū!*
- **Запрет:** **ḥā** + несовершённый 2-го лица: *ḥā tafšul!* «не беги!», *ḥā tafšulū!* «не бегите!».
- **Страдательный залог** (только несов.): *yu-CCaC*: *yuḥṣar* «считается, его считают».
- **Будущее:** **ġad** + несов.: *ġad yatūl* «придёт». Сослагательное («сказали бы») — тоже *ġad*.
- **Уже:** *qad* (после глагола в устной речи пустыни: *ḥaṭam qad* «уже бы съел»).
- **Модальные:** *ṭāq* «можно, могу» (неизменяемое: *maš ṭāq aṣbun* «не могу найти»; *hun — ṭāq* «здесь — можно»); *ḥatm* «надо, должен».
- **Связка:** в настоящем её нет (*An-ṭull nuṭf* «Тень — вода»). В прошедшем — *bāt* (*maš bāt ladayhā* «у неё не было»).
- **Бытие:** *tamm* «есть, имеется», *maš tamm* «нет».
- **Обладание:** *lad-* «у»: *ladnā balh jamm* «у нас много глупости».

### 4.5 Отрицание, вопрос, порядок слов
- **maš** отрицает всё, кроме приказа: *maš ʿalaš* «не знал», *maš tamm* «нету», *maš ṣalt* «не камень». Ответ «нет» — тоже *maš*. «Да» — *hay*.
- **Общий вопрос:** частица **kay** в начале: *Kay taṣnutū?* «Слышите?».
- **Вопросительные слова:** *mūn* кто, *šāl* что, *tayn* где/куда, *matūn* когда, *lišāl* зачем/почему, *kufa* как, *qaddi* сколько, *ayy* который. Ставятся в начало.
- **Порядок слов:** в глагольной фразе **VSO** (*Šaḥanū an-ʿaššārīn tinā* «послали десятинщики двоих»). Вынос подлежащего вперёд (**SVO**) — это смысловое выделение… или кинский акцент: горожане ставят подлежащее первым почти всегда (*Tū taḍbuṭ*, *Kīn yalqut jamm*). Это главный маркер речи Кайра.
- **Прямое дополнение** может выходить в начало для акцента: *Ṣulūt aḥṣur* «*камни* я считаю».

### 4.7 Обращения и почтительность
- **ay** + имя — обращение: *ay Rayn*, *ay Ossāna!*
- **bā-** — почтительно к мужчине-чужаку или мастеру (*bā-Rayn* «мастер Рэйн», *bā-Kayr*). **mā-** — к женщине.
- **ḥalīt** — «сестра (по вере)», обращение к паломнице и послушнице.
- **Rāʿim** — «досточтимый»: к наибу и старейшинам. Оссана называет наиба только так.
- **qaṣbī** «городской» — в устах пустынника почти ругательство. **ʿaššār** «десятинщик» — презрительное слово для жрецов Кина; нейтральное — *ḥanbān*.
- Литургическое **ō** вместо *ay* — только в песнях и молитвах.

## 7. Регистры

### 7.1 Пустынный (основной)
Короткие фразы, VSO, повелительные формы, опущенные местоимения, метафоры воды и тени. Без вежливого *tūm*.

### 7.2 Кинский городской (*kīniyya*)
SVO; подлежащее почти всегда вынесено (*Kīn yalqut jamm*); полные местоимения; слова *ḥanbān* (а не *ʿaššār*), *Šayṭān* (а не *Ḥūl*); вежливое *tūm* к незнакомым; длиннее, с «канцеляритом веры». В пустыне кинский выговор узнают с первой фразы.

### 7.3 Литургический (песни жрицы, резьба)
Вокатив **ō**; «протяжное» окончание **-an** у имён (*dawsan*), повтор слова дважды в середине строки, рефрен **rū** в конце. Многое здесь — архаика, которую возрожденцы восстановили по резьбе; говорят, что старики находят в их песнях ошибки. Старый «чакобса-подобный» ритуальный набор слов из прошлой версии библии мира заменён этим регистром.

### 7.4 Акцент инопланетника
Эмфатические → простые (ṭ→t, ḍ→d, ṣ→s), q→k, ḥ→h, ʿ и ʾ выпадают; долгие гласные путаются; лицо глагола «съезжает» в 3-е (*Ānu… yasrub* вместо *asrub*); всё это записано прямо в `Line_Native` и `Line_NativeScript`.

## 8. Галах и правило `[Galach]`
Галах — общий язык Империи (и Рассеяния). Его мы **не изобретаем**: в субтитрах галах представлен **языком игрока**.
- Реплика на галахе: `Line_Native = [Galach]` (ровно так, с квадратными скобками), `Line_NativeScript` — пусто.
- UI: над субтитром ничего не показывать (или маленькую пометку «галах / Galach»); озвучивать **перевод** (`Line_RU`/`Line_EN` по языку игры) обычным голосом TTS.
- Когда в срезе звучит галах: Илва и Рэйн говорят между собой о том, что не для чужих ушей (`DLG_WRM_P03–P04` — допрос о «чанах»; `DLG_B3_001–003` — у цистерны). Переход на галах — сам по себе сигнал: «это между нами, инопланетниками». Сейчас таких строк 5 из 117 озвучиваемых.

## 12. Что нужно движку и браузеру
1. **Субтитр:** крупно — перевод (`Line_RU`/`Line_EN`), над ним мелко — `Line_Native`. Арабицу не показывать: это служебная строка для голоса.
2. **Голос:** арабский TTS читает `Line_NativeScript`; если голоса нет — формантный синтезатор читает `Line_Native` (§3.1). Высота голоса — из таблицы PITCH по говорящему, как сейчас.
3. **`[Galach]`:** нет нативной строки → озвучить перевод голосом языка игры, над субтитром ничего (или пометка «галах»).
4. **Лор (Speaker `Lore`):** `Line_Native` — сама надпись на камне; показывать её стилизованной строкой над описанием, **не озвучивать**.
5. **Лай толпы (`Barks.csv`)** не озвучивается словами: только перевод в субтитре и неразборчивый гул (по желанию — формантный «мурмур» без текста).
