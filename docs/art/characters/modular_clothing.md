# Модульная одежда (герои и толпа)

Задача T-012. Одежда собирается из слоёв на общем скелете MetaHuman (тела `f_/m_ med/tal/srt`, нормальный/худой вес). Источник ткани — Marvelous Designer → симуляция в UE через Chaos Cloth только на внешних слоях (накидка, шаль, полог капюшона). Мастер-материал — `/Game/Rakis/Materials/Master/M_Cloth_Worn` (параметры `ClothTint`, `AccentTint`, `Wear`, `SunBleach`, маска износа по UV2).

## 3. Правила сочетаний (исполняет `char_crowd_variants.py`)
1. Из одного слота — не более одного модуля.
2. Обязательные модули: WaterCarrier — `Mod_Jar_Shoulder`; Guard — `Mod_Kris_Sheath` + `Mod_Hood_Mask`; Weaver — `Mod_Bracer_Weaver`; Pilgrim — `Mod_Shawl_Pilgrim`; Elder — `Mod_Staff_Walking`; Artisan — `Mod_Apron_Leather`.
3. Взаимоисключения: `Mod_Jar_Shoulder` × `Mod_Yoke_Carry`; `Mod_Cloak_Long` × `Mod_Apron_Leather`.
4. 2–4 модуля на персонажа (+ заплаты при `Wear > 0.8`). Силуэт должен читаться с 30 м: у каждого архетипа один «силуэтный» модуль (кувшин, посох, шаль, маска, фартук).
5. **Синий** (`#2C3E57`, `#3F5E7A`) — акцент максимум в одном слое; исключение — ткачихи (синий — их ремесло) и зал B5 (ритуальные синие шарфы надеваются при `CrowdRitual`, модуль `Mod_Scarf_Blue` включается скриптом).
6. Кинская ткань (паломники) — светлее и наряднее, но пыльнее; у местных — выгоревшая охра и бурый.

## 4. Износ и цвет
| Параметр MI | Диапазон | Правило |
|---|---|---|
| `ClothTint` | из `ClothPalette` ± 1.5 % hue | основной цвет робы |
| `AccentTint` | из `ClothPalette` | кайма, пояс, шарф |
| `Wear` | дети 0.35–0.65, взрослые 0.45–0.95, старики +0.1 | истончение по швам, дырки по маске альфы, грязь по подолу |
| `SunBleach` | 0.1–0.6 | плечи и капюшон светлее, ниже насыщенность (выгорание сверху вниз, маска по нормали Z) |
| Пыль | глобально из `MPC_RakisWeather.DustDensity` | в пустыне — сильнее; в сиетче — только подол |
Текстуры: атласы 2K (толпа), 4K (герои). Плотность 512 px/м толпа, 1024 px/м герои.

## 5. Глаза ибад
Материал глаз MetaHuman: склера `#8FB4E6` → к краю `#5E86C4` (не неоновый!), радужка `#1E3A8A` с тёмным лимбом. Интенсивность по персонажу: `IbadAmount 0..1` (местные 0.8–1.0, паломники 0–0.4, Кайр 0.5, Илва 0, Рэйн 0 — линзы-контактные «под ибад» 0.6 с заметным краем, деталь для внимательных).
