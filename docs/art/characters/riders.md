# Наездники ×2 (Rider1, Rider2)

**Роль:** патруль Оссаны, массовка с репликами; на спине червя в `LS_WormReveal`, затем идут рядом в A3, в B1/B2 — у стойки крючьев. ID: `Rider1`, `Rider2`.

| | Rider1 | Rider2 |
|---|---|---|
| Характер | молчаливый, докладывает | язвительный, не любит жрецов |
| Тип | мужчина 40, высокий, сухой (`m_tal_nrw`) | женщина 23, невысокая (`f_srt_nrw`) |
| Силуэт | один длинный крюк за спиной, длинный хвост капюшона | два коротких крюка на бёдрах, обрезанная накидка |
| Отличие | маска всегда поднята (говорит через неё — приглушённый голос) | маска опущена, на шее — синий шарф |
| Палитра | `#4A3B2C #6B5A44 #3B302A #8C7355` | `#5E4B3C #9C7C52 #3B302A #2C3E57` |
| Ибад | 1.0 | 0.9 |

## Общие слои
Дистикомб наездника (накладки на коленях/предплечьях как у Оссаны, но новее) · туника · обвязка наездника · капюшон-обмотка · крис-нож · крюки (`SM_Maker_Hook`).

## Модульность
Наездники собираются из модулей толпы (`Mod_Hood_Mask`, `Mod_Bracer_Leather`, `Mod_Kris_Sheath`, `Mod_Scarf_Blue`) + уникальная обвязка `SK_Rider_Harness` — чтобы в кат-сцене их можно было дублировать (третий наездник на черве — копия Rider1 с другим MI).

## Бюджет
60k каждый, 2K атлас одежды + 4K лицо, Chaos Cloth: хвост капюшона / накидка.
