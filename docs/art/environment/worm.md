# Арт-бриф: Шай-Хулуд, червь Ракиса (T-010)

Меши-заготовки: `blender -b -P Tools/blender/env_worm.py -- --out Export [--detail 1.0]` →
`SM_Worm_Segment`, `SM_Worm_Head`, `SM_Worm_MouthPetal`, `SM_Worm_Teeth` → импорт `env_import.py` в `/Game/Rakis/Worm/`.
Сборка в игре — `ARakisWorm` (gameplay-programmer): сплайн + ISM колец (`SM_Worm_Segment` × 90) + голова; Control Rig/анимация —
animator. Параметры контракта: длина **360 м**, диаметр **40 м**, 90 сегментов по 4 м, всплытие 50 м, зарывание 60 м.

## 1. Анатомия
| Часть | Размер | Форма и смысл | Заготовка |
|---|---|---|---|
| Кольцо тела | 4 м × Ø40 м | мягкая трубка + **36 хитиновых пластин-черепиц** по окружности (перекрытие ~28 %), задний козырёк 0.4 м налегает на соседнее кольцо (при изгибе сплайна — не видно щелей); продольные борозды между пластинами, тонкие гребни (22 на пластину), центральный желобок, поперечные валики «мышцы» | `SM_Worm_Segment`: pivot x=0 (задняя кромка), X — вперёд; ≈44 тыс. тр. |
| Голова | 30 м (= `HeadLength`), Ø40 → Ø36 у губы | «воротник» из складок, три шва-борозды между лепестками, толстая губа, **глотка Ø28 → Ø20 м** уходит внутрь, мышечные кольца и продольные складки | `SM_Worm_Head`: pivot — середина головы; ≈59 тыс. тр. |
| Пасть-цветок | 3 лепестка по 120°, хорда 23 м (1.15 R) | закрытая — тупой бутон-конус; раскрытая (≈100°) — «цветок» Ø50+ м; снаружи хитин, внутри — плоть с рядами мелких зубов, зубчатые кромки | `SM_Worm_MouthPetal` (один): поза «прямо вперёд», pivot — центр по X, шарнир на −X-торце, ось вращения — локальная Y |
| Зубы | 5 колец × 48–64 кристалла, 1.2–2.6 м | **кристаллические** (полупрозрачный кварц/кость), шестигранные, наклонены «в горло» (назад) — внутрь не выйдешь; передние кольца длиннее; дочерние кристаллы | `SM_Worm_Teeth`: pivot = pivot головы; ≈9 тыс. тр. |

### Сборка пасти (совместимо с `ARakisWorm::SetupHead/UpdateHeadAndMouth`, проверено рендером)
```
HeadPivot ── HeadMesh = SM_Worm_Head (pivot — середина головы, губа на +15 м; масштаб = D / max(size.Y,size.Z) ≈ 0.97)
          ├─ PetalPivot k (k = 0,1,2): позиция (HeadLength/2, 0, 0.9 R) = (1500, 0, 1800) см, roll = 120°·k
          │     └─ Petal = SM_Worm_MouthPetal: смещение (+PetalLength/2, 0, 0), масштаб PetalLength/size.X ≈ 1.0
          │        pitch опоры: PetalClosedPitch −62° → «бутон» (кончики сходятся на оси), PetalOpenPitch +42° → «цветок»
          └─ Teeth = SM_Worm_Teeth: тот же трансформ, что HeadMesh (C++ пока его не ставит — добавить компонент/сокет)
Segment = SM_Worm_Segment: pivot на задней кромке (контракт), длина по X 4 м (+0.4 м козырёк назад)
```

## 2. Масштаб — с чем сравнивать (для кадра и для звука)
| Сравнение | Значение |
|---|---|
| Человек 1.8 м рядом с кольцом | кольцо в 22 раза выше; пластина 3.5 × 4 м — «стена дома» |
| Всплытие 50 м над песком | 16-этажный дом; из точки P4 (80 м) верх тела под углом 31° — **закрывает солнце** (28°) |
| Длина 360 м | на 1/3 длиннее скалы-седла по высоте ×1.8; вся длина не видна никогда — только дуга |
| Пасть раскрыта | Ø ≈ 55 м — в неё поместится вся галерея B2 (60 × 15 м) |
| Скала | коготь 290 м = 7 диаметров червя |

## 3. Материалы (`M_Worm_Chitin` → `MI_Worm_Chitin`, `MI_Worm_Flesh`, `MI_Worm_Throat`; `M_Worm_Teeth` → `MI_Worm_Teeth`)
- Хитин: тёмная охра → ржаво-коричневый, кромки пластин стёрты песком до светлого (маска по кривизне), на верхней стороне —
  налёт песка (маска по мировому Z, MPC `WormThreat01` для осыпания); 4K тайлинг + макро-шум на тело (нет повторов на 90 колец).
- Плоть в бороздах: тёмно-розовая/фиолетовая, влажный блеск только в глотке (`MI_Worm_Throat`, SSS).
- Зубы: кварц с внутренним свечением спайс-синего на кромках (очень слабо), преломление — фейк через Fresnel (Nanite не любит
  полупрозрачность → материал Opaque/Masked с «ложной» глубиной).
- Пряность: оранжевая пыль осыпается с колец при всплытии (`NS_Worm_RingSandfall`), запах-марево у пасти.

## 4. Шот-лист «грандиозность» (LS_WormReveal, 30 с; geometry → `layout.md` §6)
| # | Длит. | Кадр | Задача |
|---|---|---|---|
| 1 | 3 с | крупно: камешек подпрыгивает на песке у ног Кайра, глубина резкости | «песок слушает» |
| 2 | 3 с | общий, 3-е лицо из-за спины: на горизонте СВ — волна песка идёт к тропе | масштаб угрозы |
| 3 | 2 с | Рэйн — крупно, дыхание; Илва кладёт руку ему на плечо | человеческий масштаб |
| 4 | 5 с | низкий ракурс от земли, 15 м от игрока: песок вздувается в 80 м, **тело выходит против солнца**, солнце закрыто — объёмные лучи сквозь пыль (`Worm_Reveal`) | главный кадр |
| 5 | 4 с | медленный подъём камеры по кольцам: пластины, ссыпающийся песок, на спине — крюки и три наездника | детали + люди на звере |
| 6 | 3 с | пасть раскрывается (лепестки −100°), кольца кристаллических зубов, горловой рёв → **хоровой удар** | грандиозность |
| 7 | 4 с | Оссана спускается по кольцам на крюке, спрыгивает в песок в 20 м | персонаж |
| 8 | 4 с | червь уходит: дуга тела «переливается» в песок, хвоста не видно | недосказанность |
| 9 | 2 с | тишина, позёмка, следы — возврат управления | пауза |
Правила: не показывать весь червь целиком; всегда в кадре есть объект человеческого масштаба; камера ниже глаз героя.

## 5. Бюджет
Сегмент 30–45 тыс. × 90 (ISM, Nanite) + голова 60–150 тыс. + 3 лепестка + зубы ≈ стандарт «300–500k + сплайн-деформация»
считается на видимую часть (обычно 15–30 колец). Финальный скульпт: пластины — 4–6 вариантов (UV-острова на атласе 4K), сегмент
делается из них в Blender, не трогая pivot и длину 4 м.
