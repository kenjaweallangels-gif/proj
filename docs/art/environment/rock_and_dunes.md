# Арт-бриф: «Коготь Шайтана» и дюны Ракиса (T-010)

Для человека-художника окружения и tech-artist. Процедурные заготовки уже генерируются:
- дюны → `Tools/blender/env_dunes.py` → `Export/heightmap_desert_r16.png` (4033², 16 bit) + `heightmap_desert.json`;
- скала → `Tools/blender/env_rock.py` → `Export/SM_Rock_ShaitanClaw.fbx` (+ `SM_Rock_FalseSlab.fbx`).
Координаты/размеры — `docs/level/layout.md` и `Tools/unreal_python/level_layout.py` (одни и те же функции формы `claw_*`
используют heightmap, меш скалы и блокаут — не менять их по отдельности).

## 1. Скала-доминанта «Коготь Шайтана»
### Силуэт (главное)
- Единственная вертикаль на 2 км. Читается со старта (1.5–1.8 км) как **изогнутый коготь**: длинная меса 1 км, вогнутая сторона
  к игроку (запад), **северный конец поднимается до 290 м и нависает на запад на 60 м** (остриё когтя), середина — седло
  200 м, южный «кулак» 250 м, широкий (400 м) и скруглённый.
- Линия горизонта плато зазубрена (уступы, седловины ±7 %), но без «зубочисток»: читается как одна масса.
- Масштаб для глаза: человек — 1.8 м, червь — 40 м в диаметре; скала в 7 раз выше червя.
- Угловой размер со старта 6–9.5° по высоте, ~30° по ширине: на 16:9 при FOV 90° — треть ширины кадра.

### Морфология (как в генераторе; доводить скульптом)
| Элемент | Параметры | Зачем |
|---|---|---|
| Осыпь (талус) | 8–18 м от грани, до 10–20 м высотой, вогнутый профиль, валуны 1–10 м | посадка в песок, граница «камень безопасен» |
| Ветровой подрез | на высоте 10–30 м, глубина 3–8 м, навес | тень S4 в полдень, «грибовидный» рельеф ветровой эрозии |
| Стена | почти отвес с «завалом» 8–14 % к вершине | масштаб |
| Страты | слои 3–9 м, твёрдые выступают на 0.5–1 м, слегка волнистые | горизонтальный ритм, читается с 1 км |
| Желобки | горизонтальные борозды ветра, шаг ~2.5 м | детализация средней дистанции |
| Трещины | вертикальные (voronoi), сетка ~26 м | ритм контрфорсов |
| Шапка | почти плоская, лёгкий купол, скруглённая бровка 6–10 м | силуэт сверху «стёсан ветром» |
| Расщелина A4 | 6 м по низу, 3 м на высоте 50 м, выше — трещина 0.8 м; зигзаг ±1.4 м; 40 м вглубь до фальшивого камня | «скрытый вход» (см. layout §5) |
| Вырезы | шлюз B1 (наземная камера), световая шахта Ø4 м над чашей зала | стыковка с сиетчем |

### Материалы (`M_Rock_Master` → `MI_Rock_Claw`, `MI_Rock_Talus`)
- Палитра: выбеленная охра на свету, пыльный терракот в стратах, холодная фиолетово-синяя тень; песок, наметённый на все
  горизонтали (маска по нормали + мировая высота из MPC `SandTint`, `WindDirection` — наветренная сторона чище).
- Слои: тайлинг 4K песчаник (2 варианта) + макро-маски (2–3 уникальные, 4K на всю скалу: страты/потёки/выветривание) + деталь-нормаль.
  Трипланар/мировые UV (меш имеет блочные UV 4 м как запасной вариант).
- Текстурная плотность: 512 px/м — стены выше 10 м; **1024 px/м** — нижние 10 м, осыпь, расщелина (игрок трётся о них).
- Фальшивый камень (`SM_Rock_FalseSlab`, 4.4×1.6×5 м) — тот же материал + тонкая тёмная щель по периметру и стёртые края от
  рук (единственная «подсказка»).

### Megascans / Fab — что искать (фиксировать источник в `sources.csv`)
| Поиск в Fab/Quixel | Для чего |
|---|---|
| «Desert Sandstone Cliff» / «Sandstone Rock Wall» (сканы стен) | стены, тайлинг 4K |
| «Layered Sandstone» / «Sedimentary Rock» | страты, макро-маски |
| «Sandstone Boulder», «Desert Rock» (3D-ассеты, 1–6 м) | осыпь, острова A2, плиты A3 (PCG) |
| «Desert Rubble» / «Small Desert Rocks» | щебень (PCG, `SM_Rock_Debris_*`) |
| «Rippled Sand», «Desert Sand Dune», «Fine Sand» (поверхности) | ландшафт: рябь, сухой/влажный песок |
| «Desert Pebbles Ground», «Cracked Desert Ground» | такыры, плиты A3 |
Только лицензии Fab Standard/Quixel для UE. Импорт в `/Game/Rakis/Environment/Rock/` и `/Game/Rakis/Environment/Props/`.

### Бюджет
Nanite, источник 5–20 млн треугольников: генератор `--preset default` ≈ 2.2 млн (блокаут+), `--preset hero` ≈ 12–16 млн.
Скульпт делать поверх `--save-blend Export/rock_hero.blend` (сохранить исходную форму основания и вырезы!).

## 2. Дюны (ландшафт 4×4 км)
### Что моделирует генератор
| Форма | Где | Параметры |
|---|---|---|
| Барханы-полумесяцы | ядро эрга A2 | клетки 180×160 м, высота до 14 м, рога **по ветру** (yaw 60°), ~25 % клеток пусты |
| Поперечные гряды | ядро | длина волны 140 м, высота до 9 м, извилистый рваный гребень |
| Профиль склонов | везде | наветренный ~10° (выпуклый к гребню), подветренный (склон осыпания) ~32°, межбарханные такыры плоские |
| Сейфы (продольные) | внешнее кольцо 0.6–1 км за ядром | шаг 380 м, до 42 м, одна сторона 30°, другая 12°, змеящийся гребень |
| Стартовый гребень A1 | (−150…240 м, −60…96 м) | 35 м в точке старта, наветренная (север) 12°, подветренная (юг) 30° |
| Коридор тропы | ±50–220 м от золотого пути | высоты ×0.25…×1 — скала видна, тропа читается |
| Плиты A3 | X > 960 м у тропы | ступени-террасы 1.5–4.5 м |
| Осыпь / выдувная котловина у скалы | 0–45 м / 30–90 м от грани | +6 м / −7 м (сильнее на наветренной стороне) |
| Под скалой | > 15 м вглубь от грани | −80 м (не пересекает сиетч, закрыто мешем) |
| Термоэрозия | всё (numpy) | 12 итераций, угол естественного откоса 33° |

### Материал ландшафта (`M_Landscape_Sand` → `MI_Landscape_Sand`) — для tech-artist
- Слои: сухой рыхлый (гребни, подветренные склоны) · плотный «барабанный» (такыры — PhysMat `PackedSand`, шум ×1.4!) ·
  каменистый (A3, PhysMat `Rock`) · влажноватый тёмный (тень у скалы). Авто-маски: уклон > 25° → рыхлый; высота < 1 м и
  уклон < 3° → плотный; расстояние до скалы < 60 м → каменистый.
- Рябь: микро-нормаль 10–20 см, ориентация по `WindDirection` (MPC), анимация позёмки — `NS_Sand_Drift`.
- RVT + деформация следов (стандарт); плотность 1024 px/м вблизи (детальные тайлы 2 м), макро-вариация 200 м против повторов.
- Physical Material слоя «плотный песок» — `PackedSand` (контракт: SurfaceMultiplier 1.4) — **геймплейно важно**: такыры в A2
  громче, обходить их — часть «песок слушает».

## 3. PCG-граф `/Game/Rakis/Environment/Desert/PCG_DesertScatter` (спецификация для человека)
`env_scatter_desert.py` сам ставит PCGVolume, если граф существует; иначе делает детерминированный Python-скаттер.
1. Surface Sampler по ландшафту (0.02 точки/м²) → фильтры: уклон < 20°, дистанция до тропы > 6 м, не в радиусе 40 м от устья A4.
2. Ветки: (a) щебень у «островов» и плит — Distance to actor tag `blockout:A2`/`blockout:A3` < 25 м, плотность ×8;
   (b) осыпь у скалы — SDF/дистанция до `SM_Rock_ShaitanClaw` < 60 м, ×12, масштаб 0.5–3; (c) редкая галька по эргу ×0.3;
   (d) метёлки сухой травы — только в тени (A3/A4), ×0.5.
3. Ориентация: yaw случайный, но вытянутые камни — по ветру (yaw 60° ± 25°), погружение 20–40 % высоты.
4. Static Mesh Spawner → `SM_Rock_Debris_A/B/C` (Megascans), HISM, Nanite, cull 300 м (кроме осыпи).

## 5. Порядок работы человека
1. Сгенерировать: `python3 Tools/blender/env_dunes.py` (или в Blender), `blender -b -P Tools/blender/env_rock.py -- --preset hero --save-blend Export/rock_hero.blend`.
2. Скульпт скалы поверх `rock_hero.blend` (не трогать основание −12…+20 м у расщелины и вырезы) → экспорт тем же именем.
3. Импорт в UE: `env_import.py`; ландшафт — вручную (`layout.md` §13), затем снова `env_import.py`.
4. Megascans → `sources.csv`, PCG-граф по §3.

## 6. Проверка осей (один раз после первого импорта)
Генераторы строят модели в «UE-координатах с переворотом Y» (Blender Y = −UE Y) и экспортируют с `axis_forward=X, axis_up=Z`.
Проверка: в UE у `SM_Rock_ShaitanClaw` (pivot (150000, 60000, 0), yaw 0) **северный высокий коготь должен быть у Y ≈ 10000…25000**,
расщелина — на западной грани при Y ≈ 72500. Если скала зеркальна по Y — перегенерировать с `-- --axis-forward=-Y`
(или в FBX Import Options включить *Force Front X Axis*) и записать вывод в handoff.
