# AGENTS.md — общие правила проекта «Rakis: Heretics»

Эти правила обязательны для всех агентов (Claude Code, Codex, Kimi, Cursor) независимо от роли.

## Проект
- Вертикальный срез иммерсивного экшен-квеста от 1-го и 3-го лица, Unreal Engine 5.x, мир «Дюны» во время «Еретиков Дюны» (Ракис, ~1500 лет после смерти Лето II).
- Источник правды по дизайну: `docs/00_GDD.md`, по сценарию: `docs/01_scenario.md`, по стандартам: `docs/04_standards.md`.
- Если задача противоречит этим документам — остановись и напиши вопрос в handoff, не выдумывай.

## Роли и границы
- Каждый агент работает только в своей зоне файлов (см. `docs/02_agent_roster.md`). Чужие файлы — только чтение.
- Изменение общих файлов (`AGENTS.md`, `docs/00_GDD.md`, `orchestrator/tasks.yaml`) — только роль `orchestrator`.
- Автор кода не ревьюит сам себя: ревью делает агент другого движка.

## Формат результата (handoff)
Каждая задача заканчивается файлом `orchestrator/handoffs/<TASK_ID>.md`:
```
## Итог
<что сделано, 3–6 предложений>
## Изменённые файлы
- path — что изменено
## Как проверить
<команды, шаги в редакторе>
## Открытые вопросы / риски
## Следующему агенту
<что нужно знать тому, кто продолжит>
```

## Технические правила
- Unreal: C++ модуль `Source/Rakis`, контент в `Content/Rakis/...`, нейминг по `docs/04_standards.md`.
- Редакторные скрипты Unreal — Python в `Tools/unreal_python/`, идемпотентные (повторный запуск не дублирует объекты).
- Blender-скрипты — `Tools/blender/`, запуск `blender -b -P script.py -- args`.
- Бинарные ассеты (.uasset, .umap, .fbx, .blend, .wav, .png, .exr) — только через Git LFS. Агенты бинарники не редактируют, а генерируют скриптами.
- Никаких секретов и ключей в репозитории.
- Коммиты: `<role>(<TASK_ID>): кратко`, например `gameplay(T-012): worm noise sensing`.
- Не запускай разрушительные команды (`rm -rf`, `git push --force`, очистку LFS) без явного указания в задаче.

## Канон и стиль
- Термины: Ракис, Кин, Церковь Шай-Хулуда (Разделённый Бог), сиетч, дистикомб, светошар, крис-нож, тампер, крючья творца, походка по песку.
- Сиетч «Табр-ан-Нур» — община «возрожденцев» (творческое допущение: классическая фрименская культура к этому времени почти исчезла).
- Не цитируй тексты книг дословно; все реплики — оригинальные.
- Визуальный ориентир: обжитая старина Арканума + живой город Невервинтера, в AAA-исполнении.
