# CLAUDE.md

Прочитай `AGENTS.md` — там все правила проекта. Дополнительно для Claude Code:

- Перед правкой кода прочитай файлы целиком, а не выдержки.
- Для Godot подключи MCP-сервер (по желанию): `claude mcp add godot -- npx @coding-solo/godot-mcp` — он запускает проект и показывает вывод отладки.
- Тесты: `cd pkg1-sim-vm && make test`, `cd pkg2-demo-web && npm test`. Не заканчивай задачу с красными тестами.
- Если задача из `*/prompts/NN_*.md` — в конце ответа перечисли выполненные критерии приёмки и команды, которыми их проверил.
- Неуверенность в API SDK очков — останавливайся и спрашивай, приложив ссылку на место в документации.
