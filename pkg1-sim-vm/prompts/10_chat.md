# 10. Чат по шагам: очки ↔ сервер ↔ мастер/технолог

Контекст: `server/app.py` (WS `/ws/chat/{run_id}`), промпт 02 (пульт мастера, очередь), `godot/scripts/main.gd` (панель).

Задача:
1. Ядро держит соединение WebSocket с сервером (`io/chat.py`, websockets), пересылает сообщения клиенту (`type: chat`).
2. Быстрые ответы голосом: «сборка вопрос» → шаблоны («нет детали», «не подходит крепёж», «нужен технолог»), шаблон
   выбирается голосом «один/два/три». Свободный текст — только с пульта/планшета (в цеху диктовка ненадёжна).
3. Офлайн: исходящие копятся в очереди промпта 02; входящие при восстановлении связи догружаются `GET /api/runs/{id}`.
4. Уведомление в очках: новое сообщение — короткая подпись в углу окна на 5 с + звук; панель не открывается сама,
   если идёт критичный шаг.

Критерии приёмки: тест с TestClient: сообщение мастера доходит до клиента ≤ 1 с; при обрыве 30 с ни одно сообщение
не теряется и не дублируется; голосовой шаблон уходит на сервер с `step_id`.
