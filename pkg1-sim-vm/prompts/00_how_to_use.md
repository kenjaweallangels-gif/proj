# Как работать с промптами

1. Один промпт = одна задача = одна ветка/коммит. Копируйте текст промпта в чат Cursor (Agent) или Claude Code целиком.
2. Перед первым промптом ассистент должен прочитать `AGENTS.md`, `docs/01_architecture.md`, `docs/02_hal_contracts.md`.
3. Ассистент заканчивает работу только с зелёными `make test` (и `npm test` для pkg2) и перечисляет выполненные критерии.
4. Если критерий не выполнен — не принимайте «почти готово»: попросите показать вывод команды проверки.
5. Порядок по дорожной карте (`docs/07_roadmap.md`): 01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09 → 10 → 11.
   02–04 (сервер и данные) и 01, 05 (симулятор) можно вести параллельно двумя людьми.

Шаблон любого своего промпта:
```
Контекст: прочитай <файлы>. Задача: <что сделать>. Ограничения: <что не трогать>.
Критерии приёмки: <проверяемые пункты с числами>. Проверка: <команды>. Не выдумывай API — если не уверен, спроси.
```
