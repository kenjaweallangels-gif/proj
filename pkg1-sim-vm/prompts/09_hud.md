# 09. HUD и голограммы: режимы, КД, анимация, эталонные кадры

Контекст: `godot/scripts/main.gd` (HUD сейчас — подписи и угловая панель), эталон вида — `pkg2-demo-web/reference/*.html`.

Задача:
1. Режимы HUD: «кратко» (шаг, момент, крепёж) / «подробно» (+ указания технолога, норма времени, таймер) / «скрыт»;
   голос «панель» и клавиша Tab. Панель в углу окна дисплея, не перекрывает центр (зона 20° вокруг взгляда свободна).
2. Лист КД: PNG листа в панели с подсветкой рамки позиции текущей детали (`kd_sheets[].positions`), зум по «покажи кд».
3. Анимация шага: путь «тара → место» по дуге над изделием (не сквозь детали), скорость из `step.speed`, повтор;
   крепёж — по порядку затяжки (если в ТП задан порядок, иначе — как в списке).
4. Подсказка «вне окна»: если цель шага вне окна 45×29°, стрелка у края окна в сторону цели.
5. Эталонные кадры: `make sim-shot` для шагов 1–6 операций 040 и 070 → сравнение с `godot/screenshots/ref/*.png`
   (допуск 2 % пикселей), тест в pytest вызывает Godot через xvfb (пропускается, если нет godot).

Критерии приёмки: эталонный тест зелёный; при цели вне окна стрелка видна на снимке; текст читается при окне 1280×800.
