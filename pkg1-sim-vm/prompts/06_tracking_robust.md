# 06. Устойчивая привязка: выбросы, одна метка, ручная привязка, масштаб

Контекст: результаты промпта 05 (`out/eval/report.md`), `tracking/aruco.py`, `tracking/registration.py`, `steps/engine.py`.

Задача:
1. Отбраковка: метка с ошибкой репроекции > 2 px исключается и решение пересчитывается; при 1 метке поза не принимается,
   а фильтр держит прошлую (не дольше 1 с) с качеством ≤ 0,3; при 2 — качество ≤ 0,6.
2. Предсказание по движению головы (позы из PoseSource/IMU, если есть) между кадрами — фильтр учитывает скорость.
3. Проверка `check_distance` из пакета (две точки, номинал, допуск) — сообщение `scale_check` с `check_distance_mm`.
4. Ручная привязка: в состоянии `MANUAL_ALIGN` клиент показывает 3 точки на изделии; сборщик смотрит на каждую и говорит
   «точка» — ядро по лучам взгляда решает позу (Umeyama по 3+ точкам). Протокол сообщений — дописать в 02_hal_contracts.md.
5. Ужесточить `test_disturbed_accuracy`: p95 ≤ 4 мм (цель из 06_testing.md).

Критерии приёмки: p95 ≤ 4 мм на синтетике с помехами (seed 0–9), привязка ≥ 90 % кадров; тест на ручную привязку
с шумом 5 мм в точках даёт позу с ошибкой ≤ 5 мм; `make test` зелёный.
