# 01. SimRig: параметры очков из конфига, сценарии головы, IMU

Контекст: прочитай `core/arcore/hal.py`, `core/arcore/rigs/sim_synthetic.py`, `docs/09_hardware_glasses.md`
(раздел «Параметры для SimRig»), `docs/06_testing.md` (раздел «Помехи в синтетике»).

Задача:
1. Вынеси параметры камеры, дисплея, головы и IMU в `config/sim_viture_luma_ultra.yaml` (значения из 09_hardware_glasses.md).
   `make_sim_rig(config=...)` читает YAML; аргументы функции переопределяют YAML.
2. Сценарии головы `HeadTrajectory`: `orbit` (есть), `lean_in` (наклон к изделию 0,4 м), `look_away` (отвернулся на 90° и
   вернулся — метки пропадают на 2 с), `walk` (подход с 2 м). Выбор — параметром `scenario`.
3. `SyntheticImu` (ImuSource): угловая скорость и ускорение из производных траектории + шум и дрейф из YAML.
4. Довести помехи до целевых диапазонов из 06_testing.md (размытие до 3 px, гамма 0,7–1,4, расстояние 0,4–1,5 м).

Ограничения: не менять контракты в `hal.py`; не трогать трекер. Детерминизм по `seed`.

Критерии приёмки:
- `make test` зелёный; новые тесты: сценарий `look_away` даёт ≥ 30 кадров подряд без меток; IMU на `orbit` интегрируется в
  угол рыскания с ошибкой ≤ 2° за 10 с без шума.
- `make sim-cli` по-прежнему печатает медиану ошибки ≤ 2 мм на `orbit`.
Проверка: `make test`, `make sim-cli`.
