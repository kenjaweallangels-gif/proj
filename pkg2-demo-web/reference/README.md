# Эталонные страницы

Самодостаточные HTML-страницы, сделанные на этапе обзора. Это эталон **вида и поведения** для демо (`src/`) и Godot-клиента.
Открываются двойным щелчком (нужен интернет: three.js с CDN jsdelivr/cdnjs, шрифты Google).

| Файл | Что показывает |
|---|---|
| `ar_overview.html` | Обзор системы: очки в пространстве, поворот головы, примеры сборки, алгоритм, чат, КД, дорожная карта |
| `vzglyad_sborshchika.html` | Реалистичный вид двумя глазами: поле зрения, оправа, нос, затемнение, окно 52° против полного поля |
| `montazh_fuzelyazh.html` | Монтаж полки в секции фюзеляжа: шпангоуты, стрингеры, подъёмник, тяги, крепёж, контровка |
| `varianty_ar.html` | Сравнение вариантов: очки, гарнитура, лазерная/видеопроекция, планшет — вид сбоку и глазами |

Правило для ИИ (`.cursor/rules/30-web.mdc`): переносить идеи и шейдеры по частям в модули `src/engine`, `src/scene`,
не копировать монолит целиком. Шейдер вида глазами уже перенесён в `src/engine/composite.js`.
