# 01. Операции из списка и с сервера участка

Контекст: `src/main.js` (таблица `OPS`), `src/engine/package.js`, `../pkg1-sim-vm/server/app.py` (`GET /api/operations`).

Задача:
1. Убрать жёсткую таблицу `OPS`: `scripts/sync-data.mjs` пишет `public/data/index.json` (id, title, файл); меню строится из него.
2. Режим «с сервера»: параметр `?server=http://ip:8080` — список и пакет берутся из API сервера, GLB и листы — `/files/...`.
   Токен устройства — `?token=` (заголовок `X-Device-Token`). Ошибки сети — понятным текстом в `#notes`, без падения.
3. Кэш последнего пакета в IndexedDB (try/catch): без сети открывается последняя загруженная операция.

Критерии приёмки: vitest — построение меню из index.json и разбор ответа сервера (fetch замокан); `npm run smoke` зелёный;
с запущенным `make server` (pkg1) и загруженным пакетом 070 демо открывает её по `?server=`.
