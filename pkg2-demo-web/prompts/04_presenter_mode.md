# 04. Режим презентации: сценарий, запись видео, субтитры

Задача:
1. `?present=1`: полноэкранный автопоказ операции с подписями «что сейчас происходит» внизу экрана (не в окне очков),
   паузы на ключевых шагах, переключение видов по сценарию (`src/present_script.js`: шаг → вид, длительность, подпись).
2. Запись ролика: кнопка «Записать» → `canvas.captureStream(30)` + `MediaRecorder` (WebM), файл скачивается.
3. Сравнение «без очков / с очками»: одна и та же операция, слева бумажная карта ТП и лист КД, справа вид в очках.

Критерии приёмки: ролик операции 040 длиной 60–90 с записывается в Chrome; сценарий описан данными, не кодом.
