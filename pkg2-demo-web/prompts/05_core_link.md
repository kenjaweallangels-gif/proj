# 05. Связь с ядром: демо как пульт и как второй экран

Контекст: протокол `../docs/02_hal_contracts.md` (UDP JSON 47100/47101), `../pkg1-sim-vm/core/arcore/app.py`.

Задача:
1. Мост UDP ↔ WebSocket: `../pkg1-sim-vm/tools/ws_bridge.py` (FastAPI, `/ws/core`) — пересылает сообщения ядра в браузер
   и команды браузера в ядро.
2. Демо с `?core=ws://localhost:8090/ws/core`: шаги и состояние приходят от ядра (как в Godot), кнопки шлют `input`.
   Поза `anchor` показывается в виде «со стороны» как отдельная полупрозрачная копия изделия (сравнить с истиной).
3. Мастер на планшете видит, на каком шаге сборщик, без очков.

Критерии приёмки: `make sim-cli` (pkg1) + мост + демо: шаги в демо меняются по командам ядра ≤ 300 мс;
тест моста в pytest; smoke демо без ядра по-прежнему зелёный.
