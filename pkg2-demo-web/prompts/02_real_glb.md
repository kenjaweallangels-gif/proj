# 02. Реальная модель: GLB из NX, материалы, производительность

Контекст: `src/scene/parts.js`, `../docs/04_cad_kd_tp_pipeline.md`, `../pkg1-sim-vm/tools/step_to_glb.py`.

Задача:
1. Поддержать сжатые GLB: `DRACOLoader` и `MeshoptDecoder` (декодеры положить в `public/` — без CDN).
2. Окружение из GLB: если в пакете есть модель оснастки/секции (`models[]` с `role: "environment"` — предложить поле в
   схеме отдельным сообщением), показывать её вместо процедурного верстака/фюзеляжа.
3. Материалы: металл/пластик/ткань по имени материала CAD (таблица соответствий в `src/scene/materials.js`).
4. Производительность: ≥ 30 к/с в виде «оба» на ноутбуке с встроенной графикой при модели 200 тыс. треугольников;
   счётчик к/с по клавише `?`. Голограммы крупных деталей — только контур (заливка слепит окно).

Критерии приёмки: демо открывает GLB 30 МБ с Draco; к/с замерен и записан в README; smoke зелёный.
