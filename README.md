# Орбитальная станция — выход в открытый космос

Интерактивная 3D-сцена в браузере (WebGL2, three.js r186, Vite): большая многомодульная станция на
околоземной орбите (высота 410 км, наклонение 51.6°), кольцо искусственной гравитации, стыковочный узел
с множеством портов и живым трафиком кораблей, вид на Землю с реальными текстурами NASA, звёздное небо
по каталогу, и играбельный персонаж от первого лица, который выходит из шлюза в скафандре в открытый космос
с физикой невесомости (трастеры SAFER, страховочный фал, поручни, столкновения).

Осторожно с кольцом: его обод движется со скоростью около 12 м/с, и касание увлекает космонавта за собой.

## Запуск

```bash
npm install
npm run dev        # http://127.0.0.1:5173/
npm run build      # сборка в dist/ (статический сайт)
npm run preview    # просмотр сборки
npm run smoke      # автотест игрового процесса в headless Chromium
```

### Компьютер с видеокартой: 1080p и 60 кадров в секунду

Пресет выбирается сам: `ultra` на машинах с 8 и более ядрами, `high` на остальных настольных, `medium` на мобильных.

**Разрешение.** Во всех пресетах для видеокарт сцена рендерится не ниже 1080 строк, даже если окно меньше
(для окна 1280×720 внутреннее разрешение 1920×1080, картинка сглаживается суперсэмплингом).

**Детализация ultra и high:**
- Земля: дневная текстура 8K по сезону, облака, ночные огни и маска воды 8K, рельеф 4K, сфера до 512×256 сегментов;
  на ultra вокруг подспутниковой точки подгружаются снимки с разрешением 500 м;
- процедурные текстуры станции удвоенного разрешения, геометрия станции и кораблей детальнее в 1,6 раза (ultra) и в 1,3 раза (high);
- тени 4096 с подгонкой под камеру, MSAA 4×, анизотропия 16×, отражения окружения раз в 1–2 с.
- **детализация корпуса вблизи:** болтовые фланцы и стыковочные узлы между модулями (кольца с уплотнением,
  защёлки, вестибюли в ЭВТИ), сварные пояса с заклёпками, изогнутые панели противометеоритной защиты с
  загнутыми кромками, стёжка и пуговицы на ЭВТИ, поручни на болтовых опорах, гнёзда для якорей (WIF),
  захваты манипулятора, камеры и прожекторы на поворотных узлах, разъёмные панели, вентиляционные решётки,
  хомуты и муфты на магистралях фермы, узлы фермы с косынками, болтовые кольца спиц и кольца, шарниры панелей
  батарей и радиаторов, предупредительные надписи. Мелочь (болты, заклёпки) видна в пределах ~30 м, фурнитура
  средних размеров — ~100 м; дальше эти ячейки не рисуются, поэтому обзорные виды не дорожают;
- **затенение стыков (SSAO):** экранное ambient occlusion по глубине ближней сцены (ultra, high, medium);
  Земля и небо не затемняются. `?ao=0` выключает его, `?detaildist=<k>` меняет дальность мелких деталей.

**Регулятор качества** держит 60 кадров в секунду. При нехватке производительности он по очереди снижает
суперсэмплинг (но не ниже 1080 строк), MSAA, размер карты теней, дальность мелких деталей станции,
частоту обновления отражений, SSAO и bloom.
Когда запас появляется, качество возвращается. Если браузер даёт таймер GPU (`EXT_disjoint_timer_query_webgl2`),
регулятор поднимает качество только при реальном запасе по времени кадра.
Текущее состояние видно справа вверху рядом со счётчиком fps.

Сцена на ultra занимает около 330 МБ видеопамяти. Кадр ultra в 1080p (вид из скафандра у шлюза) — около 470 вызовов отрисовки и 4,1 млн
треугольников. По оценке (измерить здесь нельзя: в контейнере нет видеокарты) для 60 кадров в секунду этого хватает
видеокарте уровня GTX 1660 / RX 5600 и выше; на более слабых регулятор сам снимет эффекты, не опуская разрешение ниже 1080p.

Параметры: `?governor=0` выключает регулятор, `?minh=<строк>` меняет нижнюю границу разрешения (`?minh=0` выключает её).

### Компьютер без видеокарты

Если WebGL работает на процессоре (SwiftShader, llvmpipe), сцена сама включает пресет `lite`:
- **Упрощённая графика:** материалы Ламберта, без теней и прожекторов, мелкие детали видны только вблизи.
- **Пакетирование:** статичная геометрия станции склеивается в пакеты.
- **Дальняя сцена:** Земля и небо рисуются в пониженном разрешении.
- **Динамическое разрешение** держит не меньше 25 кадров в секунду.

В облачном контейнере на 4 ядрах без GPU сцена даёт в среднем около 30 кадров в секунду. Для запуска в таком окружении:

```bash
npm run demo -- --out=demo-out --w=800 --h=450 --video=640x360   # записанная игровая сессия + журнал fps
```

Chrome без видеокарты лучше запускать с `--disable-gpu-compositing`. В headless-режиме захват указателя мыши
замедляет кадры, поэтому для таких сессий есть параметр `?nolock=1`: обзор мышью работает без захвата.

Параметры URL: `?quality=ultra|high|medium|low|lite`, `?pr=<масштаб>` (внутреннее разрешение), `?autostart=1` (без меню), `?observer=1&view=overview`
(камера обзора), `?view=free-station|free-earth|free-moon` (свободная камера у станции, над Землёй, у Луны),
`?t=<сек>` (момент на орбите: 600 — день, 1165 — закат, 2000 — ночь, 3200 — восход), `?utc=2026-12-31T23:00Z` (дата старта),
`?timescale=<n>` (ход времени при старте, от 0.1 до 1000000).

## Управление

Игра начинается внутри станции (`?start=inside`, по умолчанию) или в шлюзе в скафандре (`?start=airlock`);
выбор — в меню, строка «НАЧАЛО».

**Внутри станции**

| Клавиша | Действие |
|---|---|
| Мышь | Обзор |
| W / A / S / D | Плыть, отталкиваясь руками (в кольце — идти) |
| Space / Ctrl | Вверх / вниз (в кольце Space — прыжок); у стены Space — оттолкнуться |
| Shift | Быстрее |
| G | Схватить / отпустить поручень; на поручне W/S, A/D — перехват, Space — оттолкнуться |
| E | Надеть / снять скафандр у стойки, открыть / закрыть внутренний люк шлюза, начать шлюзование, встать на лестницу |
| X | Выравнивание по «потолку» модуля вкл/выкл |
| V | Затормозить |
| Q / E | Крен |

**В открытом космосе**

| Клавиша | Действие |
|---|---|
| Мышь | Обзор (поворот скафандра) |
| W / S, A / D | Трастеры вперёд/назад, влево/вправо |
| Space / Ctrl | Трастеры вверх / вниз |
| Q / E | Крен |
| Shift | Форсаж трастеров |
| X | Режим стабилизации (AAH) / свободный момент |
| V | Гашение движения и вращения |
| G | Схватить / отпустить поручень; Space — оттолкнуться |
| R | Подтянуть фал (Shift+R — отстегнуть) |
| E | Шлюз: разгерметизация и открытие люка / возвращение |
| L | Фонари шлема |
| F | Камера обзора (облёт станции) |
| C | Свободная камера (см. ниже) |
| Z | Телескоп (см. ниже): в куполе, в открытом космосе, в камере обзора и в свободной камере |
| N | Подсказки неба: созвездия → + границы, названия звёзд и планет → выкл. |
| P | Пауза · H — помощь · M — звук · Esc — меню |

**Ход времени** (клавиши работают в любом режиме, кнопки — в панели камеры обзора, свободной камеры и в меню паузы)

| Клавиша / кнопка | Действие |
|---|---|
| P, кнопка ❚❚ / ▶ | Пауза / продолжить |
| [ / ], кнопки « / » | Медленнее / быстрее: ×0.1 … ×1 … ×10 … ×3600 … ×86400 … ×10⁶ |
| \, кнопка ×1 | Реальное время |
| T | По кругу ×1 / ×10 / ×60 / ×600 / ×3600 |
| Кнопки ×1 ×10 ×60 ×600 ×3600 ×86400 ×10⁶ | Быстрый выбор хода времени |
| Кнопки −1 ч / +1 ч / +1 сут / +30 сут, поле даты | Переход по времени (UTC) |

Панель показывает дату и время UTC и текущий ход («×600 · 1 с = 10 мин»). При ходе быстрее ×10 космонавт
«на рельсах»: он зафиксирован относительно станции (или пола кольца), физика и ресурсы скафандра стоят, мышью
можно только осматриваться — на шлеме горит «ФИКСАЦИЯ». Корабли при больших ускорениях и переходах по времени
проходят этапы полёта скачком (стыкуются и улетают по расписанию), Земля, Луна и Солнце — точно по дате.

**Свободная камера** (C; кнопка «СВОБОДНАЯ КАМЕРА» в меню и в панели обзора)

| Клавиша | Действие |
|---|---|
| Мышь | Обзор (щёлкните по сцене, чтобы захватить мышь) |
| W / A / S / D, Space / Ctrl | Полёт вперёд / влево / назад / вправо, вверх / вниз |
| Q / E | Крен |
| Колесо, + / − | Скорость: от 0,1 м/с до 30 000 км/с (логарифмическая шкала) |
| Shift | Скорость ×10 |
| B | Вернуться к станции |
| O | Ориентация: инерциальная (звёзды неподвижны) / местная вертикаль (горизонт следует за камерой) |
| C / F | Выйти (к космонавту) / камера обзора |

Панель показывает высоту над Землёй, расстояние до станции и до Луны (и высоту над Луной), скорость и систему
отсчёта: у станции камера движется вместе со станцией, дальше 2000 км — относительно центра Земли, ближе 60 000 км
к Луне — вместе с Луной. Кнопки «К станции», «К Земле», «К Луне» переносят камеру, «На …» — поворачивают к цели.
Луна (виды `free-moon`, `free-moon-orbit`) — та же детальная Луна, что и в телескопе. Начало координат сцены следует за камерой, поэтому у Луны (400 000 км) ничего не дрожит; станция дальше 300 км не рисуется.
Камера не проходит сквозь станцию, корабли и стены отсеков (останавливается и скользит вдоль поверхности), не уходит
под поверхность Земли и Луны; камера обзора тоже не заходит внутрь корпуса.

**Телескоп** (Z или кнопка «ТЕЛЕСКОП (Z)»; 300 мм, экваториальная монтировка: север вверху, звёзды не уплывают)

| Клавиша | Действие |
|---|---|
| Колесо, + / −, кнопки 60° … 6′ | Увеличение: поле зрения от 60° до 3′ (0,05°) |
| ЛКМ (перетаскивание), стрелки | Наведение |
| Поиск / каталог справа | Солнце, Луна, планеты, спутники Юпитера, яркие звёзды, 200 туманностей, галактик и скоплений (M, NGC, IC; русские названия). Щелчок — навести и сопровождать |
| Центр | Вернуть объект в центр поля |
| N | Подписи созвездий и объектов в поле |
| Z / Esc | Выйти |

Справа — координаты (α, δ J2000), расстояние, блеск, видимый размер, фаза и элонгация объекта; слева вверху — поле,
увеличение, выходной зрачок и предельная звёздная величина. При большом увеличении планеты видны дисками с фазой,
полосами и кольцами (тень планеты на кольцах и колец на планете), рядом — спутники Юпитера; Луна — рельеф 8K/16K с
длинными тенями у терминатора; туманности и галактики — по снимкам ESO, ESA/Hubble и NOIRLab в их настоящем
положении и размере, слабые звёзды Tycho-2 и Gaia появляются по мере увеличения. Экспозиция подстраивается под
поле. При наведении на Солнце автоматически ставится солнечный фильтр. Для скриншотов: `?telescope=M42&fov=1.5`
или вид `tele-<объект>-<поле в градусах>` (например `node tools/screenshot.mjs --views=tele-jupiter-0.06`).

## Что в сцене

* **Интерьеры всех отсеков** — четырёхстенная стоечная компоновка как на МКС (стойки ISPR с ящиками, панелями,
  дисплеями), угловые стойки с лампами, поручнями, кабелями и воздуховодами; квадратные люки CBM и круглые люки
  в российском сегменте, переходные тамбуры со стыковочными кольцами; сумки CTB на резинках, ноутбуки на
  кронштейнах, огнетушители, ПБА, таблички на русском и английском. Лаборатория «ИСТОК» (перчаточные боксы,
  морозильники, микроскоп), грузовой «ЛАРЕЦ», жилой «МЕРИДИАН» (каюты экипажа, камбуз с подогревателем и водой,
  стол), «ГОРИЗОНТ» (беговая дорожка, велоэргометр, силовой тренажёр, санузел), медицинский «ПУЛЬС», служебный
  «ВЕКТОР» (СОЖ: «Электрон», «Воздух», СРВ, центральный пост), оранжерея «ФЛОРА» (камеры роста с розовыми
  светодиодами и растениями), узлы, купол с видом на Землю, кладовая, стыковочный узел «ГАВАНЬ».
* **Шлюз** — отсек оборудования (два скафандра на стойках, зарядка батарей, панель фалов, насос откачки) и
  шлюзовая камера с наружным люком. Выход: надеть скафандр (E у стойки), перейти в камеру, E — закрыть
  внутренний люк, сброс давления, открытие наружного люка. Возвращение — в обратном порядке.
* **Кольцо искусственной тяжести** — ступица с вращающейся частью и люками спиц, шахты-спицы с лестницами
  (тяжесть растёт с радиусом), залы секторов (пост управления, спортзал, кают-компания), изогнутые коридоры
  с каютами, санблоком, салоном и мастерской. Пол изогнут, «вниз» — от оси; при ходьбе и подъёме
  проявляется сила Кориолиса.

* **Орбита и время** — настоящая круговая орбита (период 92.6 мин), вращение Земли, положение Солнца и Луны
  по дате, тень Земли (затмение ~35 мин на виток), терминатор, восходы и закаты каждые 46 минут.
* **Земля** — снимки NASA Blue Marble за месяц даты полёта (снег, растительность, морской лёд NSIDC), реки и озёра
  Natural Earth, цвет океана по глубине, солнечные блики по модели Кокса — Манка с ветром, шейдер атмосферы
  с рэлеевским и Ми-рассеянием. Погода меняется: облака растут и распадаются, днём над сушей вырастают кучевые,
  тропические циклоны октября (Тихий и Атлантический океаны, Бенгальский залив, Аравийское море) движутся по своим
  траекториям, грозовые ячейки вспыхивают молниями. Ночью — огни городов (натриевые и светодиодные), подсвеченные
  снизу облака, лунные блики, полярные сияния и свечение верхней атмосферы.
* **Небо** — 2,5 миллиона звёзд Hipparcos и Tycho-2 (HYG + фотометрия Gaia DR3) и ещё 0,9 миллиона звёзд Gaia
  для телескопа; яркость по физической модели (звёздная величина → поток, цвет по B−V, функция рассеяния точки без
  мерцания и «зубцов»), глаз адаптируется: на ночной стороне вдали от Земли видны тысячи звёзд и Млечный Путь
  (карта NASA Deep Star Maps 8K, пылевые прожилки и звёздные облака), над освещённой Землёй — только самые яркие
  светила. Зодиакальный свет и противосияние. Планеты — по эфемеридам JPL на дату (звёздная величина и фаза),
  Луна — по теории ELP (Meeus) с либрацией, фазой и пепельным светом. Подсказки созвездий на русском (N).
* **Луна** — поверхность LRO: цвет LROC 8K (и тайлы 16K для телескопа и полёта), рельеф LOLA, сфера с уровнями
  детализации (видна с Земли, из телескопа и с орбиты высотой 100 км), тени гор и кратеров у терминатора.
* **Станция** — ферма, кластер герметичных модулей, купол, вращающееся жилое кольцо (0.37 g), стыковочный
  узел на 8–10 портов, солнечные батареи, следящие за Солнцем, радиаторы, антенны, навигационные огни,
  прожекторы, поручни, шлюз с анимированным люком.
* **Корабли** — несколько типов (капсула, грузовик, космоплан, танкер, дрон-инспектор), стыковки и отстыковки
  по расписанию, факелы двигателей ориентации, раскрытие панелей, стыковочные механизмы.
* **Игрок** — скафандр от первого лица с перчатками и визором, физика 6 степеней свободы с сохранением
  импульса, столкновения, фал, HUD шлема с телеметрией, процедурный звук (дыхание, вентиляторы, трастеры, радио).
