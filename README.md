# proj — AR-сборка интерьеров ВС

Стартовый пакет системы пошаговой AR-сборки (см. `AGENTS.md`, `docs/`) с **фотореалистичным веб-демо**:
`pkg2-demo-web/` — вид «глазами сборщика» в очках 52° и «со стороны», PBR-материалы, окружение цеха, мягкие тени, AO.

| Часть | Что это |
|---|---|
| `pkg1-sim-vm/` | имитация очков, ядро (трекинг, шаги, голос), сервер цеха, конвейер CAD → GLB, клиент Godot |
| `pkg2-demo-web/` | веб-демо Vite + Three.js, фотореалистичный рендер — `pkg2-demo-web/README.md` |
| `pkg2-demo-web/galley.html` | **симулятор участка**: приход сборщика, AR-очки, сборка кухонного модуля КМ-2 на стапеле, окна КД/ТП/чата, модель зрения, голосовое управление |
| `pkg2-demo-web/tablet.html` | **планшет сборщика** — пульт к очкам (переход, контроль, КД, чат, настройки); связь через сервер участка `/ws/remote/{стапель}` |
| `data/examples/` | пакеты операций 040 (верстак) и 070 (полка в фюзеляже), GLB, листы КД |

## Быстрый старт демо
```bash
cd pkg2-demo-web && npm install && npm run dev      # http://localhost:5173/?op=070&view=split
npm test && npm run build && npm run smoke          # 56 тестов + 9 сценариев в Chromium
# симулятор: http://localhost:5173/galley.html
```

## Развёртывание
`.github/workflows/pages.yml` собирает демо и публикует `pkg2-demo-web/dist` на GitHub Pages
(включить: Settings → Pages → Source: GitHub Actions). `dist/` — статический сайт, его можно выложить
на любой веб-сервер цеха (nginx, IIS) без Node.js.

# AR-сборка: стартовый пакет для разработки с ИИ-ассистентом

Пакет для разработки системы пошаговой AR-сборки интерьеров ВС в Cursor, Claude Code или другом ИИ-ассистенте.
Система показывает сборщику 3D-последовательность сборки поверх реального изделия, ведёт по шагам
техпроцесса (ТП), даёт голосовое управление, чат с технологом и мастером, листы КД, пишет журнал на сервер цеха.

Пакет состоит из двух частей с общими документами и форматом данных.

| Часть | Что это | Кому | Результат |
|---|---|---|---|
| `pkg1-sim-vm/` | Имитация очков на ПК или ВМ Ubuntu и разработка настоящего ПО | Разработчик системы | Ядро (трекинг, шаги, голос), сервер, конвейер CAD → 3D, клиент Godot. Всё тестируется без очков |
| `pkg2-demo-web/` | Веб-демо с 3D-видом «глазами сборщика» и «со стороны» | Показ руководству, технологам, обучение | Страница в браузере: цех, изделие из GLB, шаги из JSON, голограммы, HUD |

Обе части читают один и тот же **пакет операции** (`schemas/operation.schema.json`):
операция → шаги → детали (узлы GLB) → крепёж → листы КД. Технолог заполняет таблицу шагов,
скрипт превращает её в JSON, и этот JSON одинаково работает в демо, симуляторе и на очках.

## С чего начать

1. Прочитайте `docs/01_architecture.md` и `docs/03_data_model.md` (15 минут).
2. Откройте папку пакета в Cursor или Claude Code. Ассистент прочитает `AGENTS.md`, `CLAUDE.md` и правила в `.cursor/rules/`.
3. Выберите часть:
   - Демо для показа: `pkg2-demo-web/README.md`, первый запуск — 5 минут (`npm install && npm run dev`).
   - Разработка системы: `pkg1-sim-vm/README.md`, установка на Ubuntu 24.04 — скрипты в `pkg1-sim-vm/setup/ubuntu/`.
4. Ведите разработку по промптам из `*/prompts/` по порядку: каждый промпт — один законченный срез с критериями приёмки.

## Состав

```
AGENTS.md                 правила для любого ИИ-ассистента (Cursor, Claude Code, Codex, Aider)
CLAUDE.md                 то же для Claude Code + ссылки
.cursor/rules/*.mdc       правила Cursor по областям (Python, Godot, Web)
docs/                     архитектура, HAL, данные, конвейер CAD/КД/ТП, алгоритмы, тесты, дорожная карта, риски, очки
schemas/                  JSON Schema пакета операции
data/examples/            примеры: операция 040 (верстак), 070 (полка в фюзеляже), таблицы ТП/BOM в CSV (op040_csv), GLB-заглушки
pkg1-sim-vm/              имитация очков + ядро + сервер + инструменты + тесты + Godot-клиент + промпты
pkg2-demo-web/            веб-демо Vite + Three.js + эталонные страницы + промпты
```

## Быстрый старт

```bash
# Ubuntu 24.04 (ПК или ВМ): установка и тесты пакета 1
cd pkg1-sim-vm && bash setup/ubuntu/00_check_system.sh && bash setup/ubuntu/01_install_base.sh \
  && bash setup/ubuntu/02_install_godot.sh && bash setup/ubuntu/03_install_python.sh && bash setup/ubuntu/04_install_models.sh
make test && make sim

# Демо (любая ОС с Node 22+)
cd pkg2-demo-web && npm install && npm run dev
```
