## Итог
Составлен анимационный список с приоритетами P0/P1/P2: локомоция на Motion Matching, отдельный пул неритмичной походки по песку со stutter step, спутники, ремёсла и быт под Smart Objects (ткачество, починка дистикомба, отмеривание воды, торг, кофе, детская игра, ссора, похоронная сценка), молитва и ритуал (танец в чаше без повторов, жесты жрицы, поворот Хармата), спуск наездника по кольцам червя. Описан сплайновый Control Rig червя `CR_Worm_Spline`: 90 колец, лепестки пасти, слои волны и «дыхания» колец, параметры, совпадающие с C++ (`MouthOpen01`, `Threat01`, `Length`/`Diameter`/`SegmentCount` из `DA_WormTuning`). Написано задание на мокап и скрипт пакетного импорта FBX с подключением IK Retargeter.

## Как проверить
```
python3 Tools/unreal_python/anim_import.py   # вне UE печатает план (сейчас FBX нет — сообщает об этом)
```
В редакторе: положить FBX в `Export/anim/SandWalk/` и запустить скрипт; повторный запуск реимпортирует, не дублирует.

## Открытые вопросы / риски
- `MouthOpen01`, `UndulationAmp`, `UndulationSpeed`, `LookTarget` должны быть свойствами `ARakisWorm` (C++), чтобы Control Rig и Sequencer их читали — согласовать с gameplay-programmer (core).
- Сокеты `Ring_##_Hook` на кольцах — нужны в `SM_Worm_Segment`/`SK_Worm_Giant` (environment-artist).
- API IK Retargeter в Python меняется между версиями — скрипт обёрнут проверками `hasattr`; цепочки IKRig настраиваются вручную.
- Таймер-фоллбек шагов без AnimNotify должен давать неритмичные интервалы при SandWalk (mechanics.md §1.5).
