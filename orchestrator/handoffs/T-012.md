## Итог
Сделаны карточки всех героев (Кайр, Илва, Рэйн, Оссана, наездники ×2, наиб Хармат, жрица + танцовщица): силуэт, слои костюма, палитра hex, подсказки по MetaHuman-пресетам, материалы, глаза ибад (с индивидуальной интенсивностью, у Рэйна — «линзы»), бюджеты. Описана модульная система одежды: 6 слоёв, каталог из 26 модулей `Mod_*` (это имена в колонке Accessories), правила сочетаний, износа и выгорания, бюджеты. Описаны 8 архетипов толпы с поведением и распределением по зонам. Скрипт вариаций толпы по сиду пишет `Export/crowd_variants.json` вне UE и создаёт `MI_Cloth_Crowd_*` внутри UE.

## Изменённые файлы
- docs/art/characters/kair.md, ilva.md, rayn.md, ossana.md, riders.md, harmat.md, priestess.md — карточки героев
- docs/art/characters/modular_clothing.md — слои, модули, правила, износ/цвет, ибад, бюджеты
- docs/art/characters/crowd.md — 8 архетипов, реакции, распределение по зонам
- Content/Rakis/Data/CrowdArchetypes.csv — 8 архетипов (BaseMesh пуст на блокауте)
- Tools/unreal_python/char_crowd_variants.py — сидовый генератор (сид 1517, ≈ 64 варианта), guard `import unreal`

## Как проверить
```
python3 Tools/unreal_python/char_crowd_variants.py --seed 1517 --total 64   # → Export/crowd_variants.json (64 варианта)
python3 Tools/validate_data.py   # проверит SmartObjectTags, палитры, модули против modular_clothing.md
```
В редакторе: запуск того же скрипта создаёт/обновляет `/Game/Rakis/Materials/Instances/MI_Cloth_Crowd_<Archetype>_<NN>` (если есть `M_Cloth_Worn`).

## Открытые вопросы / риски
- `M_Cloth_Worn` (tech-artist) должен иметь параметры `ClothTint` (vector), `AccentTint` (vector), `Wear`, `SunBleach` (scalar) — иначе MI создаются без эффекта.
- Пути баз толпы `SK_Crowd_*` — предложение; в CSV BaseMesh оставлен пустым до появления мешей.
- MI кладутся в `/Game/Rakis/Materials/Instances` по контракту §2.5 — при желании orchestrator можно перенести в `Characters/Crowd/Materials`.
