## Итог
Написаны процедурные генераторы дюн, скалы и червя и импорт в UE. `env_dunes.py` строит 16-bit heightmap 4033² (4×4 км, 1 м/px) чистым Python (zlib+struct PNG; с numpy — быстро, без — ~20–40 мин на 4033², `--res 1009` для превью): барханы с рогами по ветру (yaw 60°), поперечные гряды и сейфы с асимметричными склонами 10°/32°, такыры, стартовый гребень A1 35 м, коридор тропы, плиты A3, осыпь и выдувная котловина у скалы, дно расщелины 0, провал −80 м под скалой; пишет JSON с параметрами Landscape. `env_rock.py` строит «Коготь Шайтана» (лофт сечений с осыпью, ветровым подрезом-навесом, «завалом», наклонным когтем 290 м; булевы вырезы расщелины, шлюза и световой шахты; страты, желобки, voronoi-трещины, Displace-модификаторы; валуны осыпи; пресеты 0.13/2.2/12–16 млн тр.) и плиту фальшивого камня. `env_worm.py` — кольцо 4 м × Ø40 с 36 пластинами-черепицей, голова 30 м с глоткой, лепесток пасти и 5 колец кристаллических зубов; пивоты головы/лепестка подогнаны под уже написанный `ARakisWorm` (проверено рендером: −62° бутон, +42° цветок). `env_import.py` импортирует FBX в пути контракта с Nanite, назначает MI по слотам, настраивает Landscape или строит фолбэк. Все Blender-скрипты реально прогнаны (bpy 4.2 как модуль) и экспортируют FBX без ошибок.

- Tools/blender/env_dunes.py — heightmap + JSON (работает и в Blender, и в python3)

- docs/art/environment/rock_and_dunes.md, worm.md, sources.csv (шаблон)

## Как проверить
```
python3 Tools/blender/env_dunes.py --res 1009 --out Export/heightmap_desert_r16.png   # превью; без --res — 4033²
blender -b -P Tools/blender/env_rock.py -- --preset preview          # ~2 мин; default ≈ 2.2 млн тр.
blender -b -P Tools/blender/env_worm.py -- --out Export
python3 -m py_compile Tools/blender/env_*.py Tools/unreal_python/env_*.py
```
В UE: `env_import.py` → `/Game/Rakis/Environment/Rock`, `/Game/Rakis/Worm` (Nanite включён). Ландшафт: ручной шаг layout.md §13, затем снова `env_import.py`. `env_scatter_desert.py` → `Rakis/Desert/Scatter`.

## Открытые вопросы / риски
- **Оси FBX:** модели строятся с переворотом Y (Blender Y = −UE Y), экспорт `axis_forward=X, axis_up=Z`. Проверить один раз (rock_and_dunes.md §6): коготь на севере (Y≈10000–25000), расщелина на западной грани Y≈72500. Если зеркально — `--axis-forward=-Y`.
- Имя плиты — `SM_Rock_FalseSlab` (так её ищет `ARakisFalseRock::SlabMeshAsset`).
- `ARakisWorm` не ставит `SM_Worm_Teeth` — нужен компонент с трансформом HeadMesh (gameplay-programmer). Сегмент оставлен с pivot на задней кромке (контракт); C++ масштабирует по габариту — непрерывность цепочки не страдает.
- Ландшафт: Python UE 5.6 не импортирует heightmap → ручной шаг; без него — фолбэк-плиты и ~200 дюн-эллипсоидов.
- PCG-граф `PCG_DesertScatter` не создаётся скриптом (спецификация — rock_and_dunes.md §3); до него — детерминированный HISM.
- LoreID `LORE_Harvester_Wreck`, `LORE_Dead_Maker`, `LORE_Worm_Throat` — новых строк нет в данных (game-designer).
