## Итог
Спринт S3 (браузерная версия `Web/`) закрывает обратную связь по демо: производительность, стабильность, свободное движение,
переход в сад, грохот, песок, звук/голоса/диалоги, персонажи, харвестер, червь, скалы, тропа, первое лицо.
Работа шла параллельными агентами в git worktree; всё слито в `claude/awesome-thompson-bhzg03`. Подробности — handoff-ы
`S3-music.md`, `S3-vo.md`, `S3-npc.md` и README модулей (`Web/src/*/README.md`). Развёртывание на ПК — `docs/07_local_deploy.md`.

## Изменённые области
- **Ядро/игрок** — профайлер (F3), коллайдеры на пространственной сетке, фиксированный шаг 60 Гц с интерполяцией, прыжок/падение,
  прогрев шейдеров, динамическое разрешение; вид только от первого лица (покачивание по шагам, сфера столкновения головы,
  руки только при действиях); «шаг пустыни» больше не останавливает игрока на ходу.
- **Пустыня** — потоковая подгрузка рельефа без рывков; рябь — только рельеф (блуждающие гребни, развилки, без муара);
  слои дымки на горизонте, небо; гряда ~3 км из 9 массивов + реалистичный камень; исправлен NaN тумана при камере выше ~450 м.
- **Тропа** — петляющая, площадки и марши ступеней, швы со скалой закрыты, S-образная щель.
- **Сиетч** — туннель к саду, большие комнаты, подвал воды B6, PVS; навигационная сетка, A*, распорядок по ролям, разговоры.
- **Сад** — скрытая котловина на 36 м в кольце стен 46–112 м, единственный вход из сиетча, без воды/пальм/выхода, мелкие растения.
- **Харвестер** — насыпи в материале песка по ветру; твёрдые предметы, потолки и перекрытия; нет выброса из кабины; закрытый корпус.
- **Червь** — 3.6 км тела (~1.35 км над песком у приползающего), LOD по телу, пасть-кольцо ~92 м в сцене поглощения.
- **Персонажи** — LOD по экранному размеру с растворением, дальняя толпа одним BatchedMesh, силуэтные детали, облик по ролям;
  исправлена «походка вприсядку».
- **Звук** — музыка волнами в эстетике фильма (оригинальные мелодии), 105 SFX-сэмплов, слоистый ветер, без постоянного гула;
  голоса Piper по персонажам (женские — женскими голосами), просодия, акустика по пространству, 337/337 реплик озвучено,
  встроенный TTS браузера удалён; 17 сцен и сад C1 переписаны (68 реплик переозвучены).

## Как проверить
```bash
cd Web && npm ci && npm run build && npm run serve      # http://localhost:8080
npm run check                                           # свободное движение (A–E)
node tools/garden_phys_test.mjs                         # сад
node tools/sietch_route.mjs --file=rakis_demo.html --from=hall --leg=both
node tools/harvester_collide_audit.mjs                  # коллизии харвестера (node)
node tools/vo_coverage.mjs                              # покрытие озвучки
```
Результаты на финальной сборке (SwiftShader, без GPU): route_free — все PASS; сад — ALL PASS; зал↔сад — 0 сбоев;
озвучка — 337/337; аудит харвестера — 0 проходов сквозь предметы, 0 выбросов.

## Открытые вопросы / риски
- Ничего не проверялось на реальной видеокарте: FPS, время прогрева шейдеров, рывки компиляции — неизвестны.
- Звук, музыка и голоса оценены только измерениями (F0, ASR, спектр), на слух не слушались.
- NPC: скольжение ног 12.6% (цель <5%), 9 резких разворотов за 90 с (цель 0); выход торговцев к ритуалу не смотрели.
- Камера: 0.4% случаев «в столе» в столовой харвестера при взгляде строго вниз.
- Гряда: не обойдена ботом целиком (возможны невидимые стены/висящие камни); тень гряды только через карту теней.
- Тропа: одна щель 0.2 м у (641.5, 36.8, 271.3).
- Лица NPC вблизи слегка «пластиковые»; базовые меши тела/лица не перелеплены.
- Сборка 22.9 МБ — больше лимита публикации Artifact (16 МБ); для локального запуска ограничений нет.
