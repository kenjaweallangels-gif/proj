## Итог
Реализованы Narrative/ и UI/ по контракту §1.4 и §2.2 (UE 5.6, C++20, чистый Slate, без UMG-ассетов). `URakisDialogueSubsystem` — очередь цепочек реплик (NextID, Condition-флаги, авто-длительность, VO 2D/на акторе говорящего), лай с кулдаунами и глобальным ограничителем, надписи-лор, RU/EN (культура ОС, консоль `Rakis.Lang`, сохранение в GameUserSettings.ini). `ARakisStoryDirector` исполняет DT_StoryBeats (все триггеры и действия схемы) и содержит встроенный сценарий по `01_scenario.md` вместе со встроенными репликами — блокаут проходится от начала до конца без CSV. `ARakisHUD` создаёт `SRakisHUDRoot`: рябь шума, засечки ритма, капля, подсказка взаимодействия, субтитры S/M/L, позиционный лай, титры, подсказки, надписи, затемнение, леттербокс 2.35:1, меню паузы (размытие), фоторежим со свободной камерой (DOF/FOV/экспозиция/крен), концовка демо. Компилятора здесь нет — код написан и проверен вручную по сигнатурам UE 5.6 и по реальным заголовкам других агентов на момент сдачи.

## Как проверить
1. Собрать RakisEditor (Development Editor). Новых модулей не нужно: Slate, SlateCore, UMG, LevelSequence, Engine, InputCore, ApplicationCore уже есть в Rakis.Build.cs.
2. Открыть L_Rakis_Persistent (или любую карту с GameMode = ARakisGameMode, он подхватывает ARakisHUD по пути /Script/Rakis.RakisHUD) и запустить PIE.
   - Старт: выход из чёрного за 2.5 с; через 3 с — титр «Ракис. Гребень Шайтана. Рассвет»; через 11 с — Илва → Кайр (субтитры), затем подсказка про походку.
   - На песке при ходьбе появляется рябь; при Alt/LB — засечки; на солнце капля мигает каждые 5 % ниже 70 %.
   - Esc / Start — пауза (размытие, ↑↓/D-pad, Enter/A, ←→ на «Язык»/«Субтитры»); P — фоторежим.
3. Консоль: `Rakis.Story.List`; `Rakis.Story.Fire ZoneEnter:A2_Erg` (через 45 с — «Стоять. Не бежать.» → титр «Шай-Хулуд» + кат-сцена/фоллбек триггера); `Rakis.Story.Fire ZoneEnter:B5_Hall` (финал → Хармат → «Конец демо» → меню «Начать заново»); `Rakis.Lang EN`.
4. Без DT_StoryBeats / DT_Dialogue_S1 в логе одно предупреждение `LogRakis: ... using built-in ...`, игра идёт.

## Открытые вопросы / риски
- Код не компилировался в этой среде. Самые вероятные места правок при первой сборке: перегрузки `FSlateDrawElement::MakeLines` (используется `TArray<FVector2f>`), `FGeometry::ToPaintGeometry(FVector2f, FSlateLayoutTransform)`, `FSlateRoundedBoxBrush` (шаблонный конструктор), `FSlateApplication::RegisterInputPreProcessor`.
- Имена типов делегатов с префиксом (`FRakisOnSubtitle`, `FRakisOnLineFinished`, `FRakisOnTitleCard`, `FRakisOnHint`), чтобы не было коллизий в модуле; имена членов (`OnSubtitle`, `OnLineFinished`, `OnTitleCard`, `OnHint`) и параметры — как в контракте. Нужно подтверждение orchestrator (в §2.2 указаны `FOnSubtitle` и т.п.).
- Фоторежим замораживает время глобальным замедлением 0.0001 (а не паузой), чтобы камера и пост обновлялись надёжно. Звук мира при этом продолжает играть. Если нужна тишина — добавить приглушение через саб-микс (audio-designer).
- Экспозиция фоторежима считается относительно `APostProcessVolume` с тегом `Rakis.PP.Global` (если в нём включён override AutoExposureBias), иначе относительно 0.
- `EndDemo` → «Начать заново» перезагружает текущую карту через `OpenLevel(GetCurrentLevelName)`. Отдельной титульной карты нет; меню «конец демо» заменяет возврат в титульное меню.
- Встроенный сценарий запускает кат-сцену червя по таймеру (через 45 с после входа в A2), а не по шуму. Так «золотой путь» гарантирован. Если game-designer хочет выход червя только по системе — задать это в DT_StoryBeats.
- Ритуал (`CrowdRitual`) защищён от повторного запуска на стороне директора (B2 + 240 с, B3, B5 — сработает только первый).

### Остаточные риски
- Сборки по-прежнему не было. Не подтверждены справкой (справка отдаёт пустые страницы): `FCoreStyle::GetDefaultFontStyle(FName, float)` (используется так же, как в движке), квалификация `const` у `IInputProcessor::GetDebugName` (поэтому не переопределяем), публичность `AHUD::bShowHUD` для чтения из директора (в 5.x — public UPROPERTY).
- Точка `Ellipsis_A3` (138800, 73550) лежит в боксе зоны **A4** (138500…144500), а не A3 — поэтому склейка «проглатывает» биты A3 и играет титр/Оссану отдельными битами. Если level-designer сдвинет точку внутрь A3, A3-биты перестанут «проглатываться» и сработают по зоне — тогда `SB_A3_G0/G1` надо удалить, иначе титр «Коготь» и диалог Оссаны прозвучат дважды.
- Золотой путь ≈ 5:15 из-за последовательного финала B5 (~80 с) и 7-строчного диалога Оссаны; до 3:40–3:50 — решение game-designer (demo_flow §5.2).
