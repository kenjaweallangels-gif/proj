## Итог
Составлена звуковая карта: эмбиент по 9 зонам, 8 состояний адаптивной музыки с переходами и правилом «тишины перед рёвом», спецификации MetaSound-графов `MS_Music_Adaptive` (StateIndex/Intensity/WormThreat/Interior), `MS_Worm_Approach` (Distance/Threat: инфразвук, дребезг камней, шипение песка), `MS_Footstep` (switch по поверхности, SandWalk), микс и дакинг, реверб по зонам, синхронизация Quartz. Написано ТЗ композитору (только оригинальная музыка, без имитации треков Arcanum/NWN). Таблица событий — 58 строк. Готовы скрипт черновой TTS-озвучки с подключаемыми бэкендами и скрипт инфраструктуры звука в UE.

## Изменённые файлы

## Как проверить
```
python3 Tools/tts/tts_batch.py --backend plan          # план озвучки
python3 Tools/tts/tts_batch.py                         # WAV, если есть espeak-ng или piper (+ PIPER_MODEL_RU)
python3 Tools/validate_data.py                         # Music.<State> на каждый ERakisMusicState, Amb.<Zone> на каждую зону
```
В редакторе: `Tools/unreal_python/audio_setup.py` → `/Game/Rakis/Audio/{Mix,Attenuation,VO}`.

## Открытые вопросы / риски
- В этом окружении нет ни espeak-ng, ни piper — проверен только режим plan.
- Колонка `Trigger` в AudioEvents — свободный FName; использованы префиксы `Music:`, `ZoneEnter:`, `Footstep:`, `WormState:`, `Worm:`, `Thumper:`, `Door:`, `SmartObject:`, `Interact:`, `Weather:`, `UI:`, `Anim:`, `Actor:`, `Crowd:`, `Mask:`, `MoistureBelow:` — `URakisAudioDirector` либо разбирает их, либо вызывает `PostEvent(EventID)` напрямую (рекомендация: по EventID).
- `Is2D` записан как `True`/`False` (формат импорта bool в UE CSV).
- Пресеты реверба сабмиксов и цепочки Audio Modulation через Python нестабильны — настраиваются вручную по soundmap §6–7.
- Ассеты `SC_*`/`SW_*` под `/Game/Rakis/Audio/SFX|Ambience|UI` пока не существуют — C++ обязан переживать их отсутствие (контракт §2.5).
