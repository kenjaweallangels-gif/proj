## Итог
Написаны спецификации механик среза: шум шагов и походка по песку, червь, жара/вода, тампер, спутники — в формате «цель → правила → параметры → состояния → граничные случаи → телеметрия». Имена полей и дефолты в таблицах совпадают с контрактом `06_demo_contract.md` §2.6; дополнительные параметры помечены «предложение». Добавлен поминутный дизайн демо (15–20 мин) с эмоциональной кривой, постановкой величия червя, погодой как драматургией, 12 микросценками сиетча и онбордингом «реплика спутника + одна подсказка». Сценарий закодирован в `StoryBeats.csv` (60 битов). `data_import.py` создаёт `DA_WormTuning`/`DA_NoiseTuning`/`DA_HydrationTuning` с дефолтами §2.6.

## Изменённые файлы
- docs/design/mechanics.md — спецификации механик, словарь Condition для диалогов, сводка «ждёт плейтеста»
- docs/design/demo_flow.md — бит за битом, кривая/темп (ASCII), постановка `LS_WormReveal`, микросценки, правила StoryDirector
- Content/Rakis/Data/StoryBeats.csv — 60 битов (только словарь триггеров/действий из `FRakisStoryBeatRow`)
- Tools/unreal_python/data_import.py — импорт всех CSV в `DT_*` + DataAsset-ы настроек (идемпотентно)
- Tools/validate_data.py — валидатор данных (stdlib)

## Как проверить
```
python3 Tools/validate_data.py --strict           # 0 ошибок, 0 предупреждений
python3 Tools/unreal_python/data_import.py --dry-run
```
В редакторе: Tools → Execute Python Script → `Tools/unreal_python/data_import.py`; в `/Game/Rakis/Data` появятся `DT_*` и `DA_*`. Повторный запуск не плодит дубликатов.
