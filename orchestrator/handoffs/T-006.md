## Итог
Реализованы системы шума и червя. `URakisNoiseSubsystem` — кольцевой буфер событий шума с затуханием по дистанции и времени (`SampleNoise`, `GetLoudestRecent`, `GetRecentEvents`), `URakisNoiseComponent` — персональный метр игрока со спадом по таймеру, `URakisSandWalkComponent` — мини-механика ритма (регулярность = 1 − нормированный CV интервалов, «сбивка» полушагом/паузой). `ARakisWorm` — 360-метровый червь Ø 40 м: тело следует за головой «как поезд» по истории её точек + синусоида, сплайн + 90 колец ISM, голова с тремя лепестками пасти (`MouthOpen01`), автомат Dormant→Listening→Approach→Surface→(Ridden|Pass)→Dormant с порогами из `URakisWormTuning`, взвешиванием тампера и безопасностью камня, Niagara/MetaSound/MPC/тряска/вибрация, `ForceSurface` для кат-сцены. `ARakisThumper` — тампер (удар каждые 1.6 с, 30 с, можно забрать). Три DataAsset-а тюнинга с дефолтами §2.6.

## Как проверить
1. Тесты `Rakis.Noise.*` и `Rakis.Worm.*` (см. T-005).
2. PIE: поставить `ARakisWorm` (или пустой актор с тегом `Rakis.Worm.Spawn` — GameMode заспавнит червя) на плоскости в 200–400 м от игрока. Бег по песку → в логе `RakisWorm: Dormant -> Listening -> Approach -> Surface -> Pass`; появляется тряска камеры и вибрация. Походка по песку со «сбивками» (Alt + Space) — червь не просыпается. Встать на актор с тегом `Rakis.Surface.Rock` — червь проходит мимо (Pass).
3. Консоль/BP: `ForceSurface(Location, Facing)` — голова пробивает песок ровно в `Location`.
4. В редакторе червь показывает тело в полный размер прямо за актором (превью масштаба).

## Открытые вопросы / риски
- Задача упоминает StateTree: логика автомата сделана на C++ (чистая функция `ARakisWorm::ComputeNextState`, покрыта тестами), без ассета `ST_Worm` — так блокаут играется без ассетов. При необходимости StateTree-задачи могут вызывать те же функции.
- `docs/design/mechanics.md` отсутствует — параметры взяты из контракта §2.6; дополнительные поля (SurfaceTriggerDistance, SurfaceDuration, SampleScale, MeterGainPerStep и др.) помечены как «Расширение» в DataAsset-ах.
- Тело червя без коллизии (иначе дорого на 30 Гц) — солнце телом червя для гидратации не перекрывается; «закрытое солнце» в Worm_Reveal решается светом/кат-сценой.
- Высота песка под телом берётся по голове (эрг считается плоским): на сильном рельефе часть колец может «висеть» или тонуть.
- `SM_Worm_Segment`/`SM_Worm_Head` ожидаются вытянутыми по оси X с пивотом в центре (иначе флаги `bSegmentMeshAlongX/bHeadMeshAlongX`).
- Компиляция не проверялась (см. риски T-005).

## Следующему агенту
- Технический художник: Niagara читает `User.Intensity`; кольца ISM получают per-instance custom data #0 (0 — шея, 1 — хвост); у авторской головы — скаляр материала `MouthOpen`.
- Звук: `MS_Worm_Approach` получает `Distance` (метры) и `Threat` (0..1); `MS_Footstep` — `Surface` (int ERakisSurface), `Speed`, `Loudness`.
- Мир/кат-сцены: `ARakisWorm::ForceSurface`, `SetRidden`, `SetSensingEnabled(false)` в сиетче; `OnWormStateChanged`, `OnBreach(Location)`; `GetHeadLocation()` для деформации песка.
- Только один червь управляет тряской/вибрацией (`ApplyWormThreat` вызывается каждым червём).
