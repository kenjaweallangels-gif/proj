## Итог
Сделана схема уровня `docs/level/layout.md` и блокаут пустыни со скалой. Все координаты вынесены в единый чистый модуль `Tools/unreal_python/level_layout.py` — его читают блокаут, разметка, генератор heightmap и генератор скалы (одна функция формы «Когтя» для всех). `level_blockout_desert.py` создаёт Persistent + подуровни Desert/Sietch (LevelStreamingDynamic) и строит: землю (Landscape → иначе плиты 200 м + дюны-эллипсоиды по гребням той же процедурной функции, что heightmap), скалу (`SM_Rock_ShaitanClaw` → иначе 50 полос-боксов по оси когтя с наклонным когтем и разрывом под расщелину/шахту), 6 камней-«островов» A2, плиты A3 и плиту-навес, стены расщелины A4, «плавник», `ARakisFalseRock`, дальние силуэты и BlockingVolume границы. `level_markup.py` размечает Persistent (игрок, спутники, червь, зоны, кат-сцены, толпа, ритуал, Smart Objects, светошары, POI, NavMesh, звук). Золотой путь ≈ 1.87 км (14 мин ходьбы) — для 3:48 сценария нужны 2 эллипсиса (титр + перенос), для свободной игры ≈ 17–21 мин.

## Изменённые файлы
- docs/level/layout.md — карта (ASCII + Mermaid), таблицы зон/точек/островов/теней/маркеров/объёмов/стриминга/кат-сцен, темп (золотой путь и 15–20 мин), линии видимости, геометрия червя, параметры ландшафта, ручные шаги
- Tools/unreal_python/level_layout.py — единый источник координат (чистый Python; `python3 level_layout.py` печатает сводку)
- Tools/unreal_python/level_common.py — стриминг подуровней, make_current, box/obox/stairs, трасса земли, маркеры, enum по имени, HISM-помощник, фолбэк-земля и дюны
- Tools/unreal_python/level_blockout_desert.py — блокаут A1–A4 и скалы
- Tools/unreal_python/level_markup.py — разметка Persistent (общая с T-004)

## Как проверить
```
python3 Tools/unreal_python/level_layout.py          # длины по зонам, точка выхода червя
python3 -m py_compile Tools/unreal_python/level_*.py
```
В редакторе (после `env_import.py`): Execute Python Script → `level_blockout_desert.py`, затем `level_markup.py`. Открыть L_Rakis_Persistent: подуровни Desert (загружен) и Sietch; Outliner `Rakis/Desert/*`, `Rakis/Markup/*`. Повторный запуск не плодит акторов (удаление по `gen:<script>`). PIE: со старта (0,0,35 м) скала видна прямо по курсу; вход в расщелину открывается только при обходе «плавника» с юга. Сухой прогон всех UE-скриптов на мок-модуле `unreal` (оба режима: с C++ и без) — без исключений, повторный прогон идемпотентен (2055 → 2055 акторов).

## Открытые вопросы / риски
- **Эллипсисы золотого пути** (layout §4.1): 1.6 км до скалы не проходятся за 3:40; предлагаю титр+затемнение+перенос группы в точки `Rakis.Ellipsis.A2/A3` (уже стоят). Нужен бит/действие в StoryDirector (`StoryBeats.csv`) — решение orchestrator/game-designer. Теги `Rakis.Ellipsis.*`, `Rakis.FX.SandTrout/DustDevil/StormWall` — предложение, не контракт §2.4.
- Ландшафт из PNG Python в UE 5.6 не создаёт — ручной шаг (layout §13); до него работает фолбэк-земля.
- `ARakisFalseRock`: для этого экземпляра `OpenOffset` переопределён на (0,0,−520) — плита уходит в пол, т.к. по бокам 4.2-метровой плиты стены расщелины (дефолт C++ сдвигает её на 4 м вбок, в скалу).
- Солнце для `Morning_Erg` должно быть азимут 20°, высота 28° (rotator pitch −28, yaw 200) — иначе червь не закроет солнце (tech-artist, `WeatherPresets.csv`/`light_setup.py`).
- Трасса `ground_z` в редакторе требует коллизии ландшафта/блокаута — если маркеры пустыни висят/утонули, перезапустить `level_markup.py` после блокаута.
