## Итог
Реализован C++ каркас игрока: `ARakisCharacter` (3-е лицо на SpringArm и 1-е лицо на сокете `head` с фоллбеком на высоту глаз; бесшовный переход — TP-камера плавно «влетает» в голову за 0.45 с, затем включается FP-камера и прячется кость головы), `ARakisPlayerController` (Enhanced Input целиком в рантайме через `NewObject`: клавиатура/мышь + геймпад, делегаты Pause/PhotoMode, вибрация и тряска камеры от червя), `ARakisGameMode` (HUD по пути `/Script/Rakis.RakisHUD`, автоспавн червя у `Rakis.Worm.Spawn`). Определение поверхности (Physical Material SurfaceType1..6 + теги `Rakis.Surface.*`), шаги по AnimNotify с таймер-фоллбеком, скорости 220/520/160 см/с, тампер, блокировка ввода для кат-сцен. Добавлены взаимодействие (`IRakisInteractable`, `URakisInteractionComponent`), двери-уплотнители, фальшивый камень, POI и 4 Automation-теста.

## Как проверить
1. Сборка: `Engine/Build/BatchFiles/Build.sh RakisEditor Linux Development -Project=$PWD/Rakis.uproject` (или по `docs/05_install.md`). В этой сессии компилятора не было — сборка не запускалась.
2. Тесты: `UnrealEditor-Cmd Rakis.uproject -ExecCmds="Automation RunTests Rakis.;Quit" -unattended -nullrhi -log` → 4 теста зелёные.
3. PIE на любой карте с полом: виден цилиндр-блокаут игрока; WASD/мышь, Shift — бег, Alt — походка по песку, Space в походке — «сбивка», V — переход FP/TP без скачка, E — взаимодействие, T — тампер на песке (из лога видно удары шума), Esc/P — делегаты (их обрабатывает `ARakisHUD`).
4. Геймпад: левый/правый стик, L3, LB, A, X, RS, Y, Start, View.

## Открытые вопросы / риски
- Код не компилировался в этой среде: возможны мелкие расхождения API UE 5.6 (наиболее вероятные места: `UCameraShakePattern::*Impl` сигнатуры, `APlayerController::PlayDynamicForceFeedback` (нативная перегрузка), `UInstancedStaticMeshComponent::BatchUpdateInstancesTransforms`, `UInputMappingContext::MapKey`).
- `UPerlinNoiseCameraShakePattern` не использован: он в плагине/модуле `EngineCameras`, которого нет в `Rakis.Build.cs`; написан эквивалентный паттерн. Если оркестратор добавит `EngineCameras` — можно перейти на штатный.
- Глаголы взаимодействия — `LOCTEXT` с английским исходником; русский требует локализации (или переопределения `FText` в BP).
- Добавлена клавиша геймпада для фоторежима (View/Back) — в контракте её нет.

## Следующему агенту
- UI уже использует `GetNoise/GetSandWalk/GetHydration/GetInteraction`, `OnFocusChanged`, `OnPauseRequested/OnPhotoModeRequested`, `SetInputLocked` — сигнатуры совпадают с контрактом.
- Аниматору: AnimNotify шага должен вызывать `ARakisCharacter::OnFootstep(bool bLeftFoot)` (BlueprintCallable); сокеты `foot_l/foot_r/head` используются, если есть.
- Нарративу: подписаться на `ARakisInspectable::OnInspected` (`AddUObject(this, &URakisDialogueSubsystem::ShowLore)`) — см. `docs/tech/gameplay_core.md` §7.
- Level-дизайнеру: блокаут-камень пометить тегом `Rakis.Surface.Rock` (или Physical Material SurfaceType2), иначе он считается песком.
