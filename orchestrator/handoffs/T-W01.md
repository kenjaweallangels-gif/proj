## Итог
Реализованы мировые системы среза: погода/время суток (`URakisWeatherSubsystem`), зоны со стеком приоритетов и стримингом (`ARakisZoneVolume` + `URakisZoneSubsystem`), кат-сцены с фоллбеком для блокаута (`ARakisCinematicTrigger`) и адаптивный звук-директор (`URakisAudioDirector`). Погода смешивает все поля `FRakisWeatherPresetRow`, ставит солнце по астрономической формуле (восход на востоке, полдень на юге), управляет SkyLight/туманом/облаками/атмосферой/PostProcess (`Rakis.PP.Global`)/WindDirectionalSource и пишет MPC_RakisWeather строго по контракту (кроме `WormThreat01`). Звук-директор работает через MetaSound `MS_Music_Adaptive` (параметры `StateIndex/Intensity/WormThreat/Interior`) или кроссфейдом по DT_AudioEvents, ведёт эмбиент по зонам, погодный слой, порывы, реверб зон, сам переключается в `WormThreat`/`WormReveal` по угрозе червя. Все ассеты null-safe с однократным предупреждением; встроенные пресеты погоды на случай отсутствия DT. Подробно — `docs/tech/world_systems.md`.

## Как проверить
1. Сборка: `RakisEditor` Development (новых модулей не требуется — всё в текущем `Rakis.Build.cs`).
2. PIE в `L_Rakis_Persistent`, Output Log, фильтр `LogRakis`: «Weather: -> …», «Zone: активный объём …», «Audio: музыка … -> …».
3. Консоль: `Rakis.Weather Storm_Horizon 5` — ветер 14 м/с, туман гуще, небо белеет; `Rakis.Weather Dawn_Ridge 0` + `Rakis.TimeOfDay 6.5` — низкое солнце с востока; `Rakis.TimeOfDay 18` — с запада.
4. В Material Editor/`stat` — параметры MPC_RakisWeather меняются (WindSpeed «дышит» порывами).
5. Подойти к червю (или `ForceSurface`): музыка → WormThreat при угрозе > 0.35, обратно через ≥ 6 с после < 0.2.
6. Без ассета `LS_WormReveal`: триггер кат-сцены блокирует ввод/HUD на 12 с, червь выходит у `Rakis.Worm.Reveal`, затем `OnFinished`.

## Открытые вопросы / риски
- **Данные vs. бриф:** `WeatherPresets.csv` расходится с ТЗ по фотореализму: Dawn_Ridge = 75 000 лк (ожидалось 10–20 тыс.), Sietch_Interior = 40 000 лк (ожидалось ≈ 0, наружный свет только через колодцы). Встроенные фоллбек-пресеты сделаны по ТЗ (16 000 / 1 500 лк) — нужно решение game-designer/tech-artist, чьи значения каноничны.
- `Hall_Ritual` = 17.75 ч → солнце ≈ 8°, в вертикальную шахту зала не попадёт. Нужен отдельный источник для «божественного луча» или время ≈ 15:00 (фоллбек использует 15:00).
- В DT_AudioEvents триггеры записаны как `Music:<State>` / `ZoneEnter:<Zone>`, а EventID — `Music.<State>` / `Amb.<Zone>`; директор принимает оба варианта (сначала по имени строки, затем по Trigger).
- Строки `Music.*` указывают на сам `MS_Music_Adaptive`: в режиме MetaSound их `Volume` используется как громкость состояния (Silence = 0).
- Поле `Bus` не маршрутизируется в сабмиксы; AudioModulation/SoundMix не используются (интерьер — параметр `Interior` и реверб зоны).
- Типы делегатов названы с префиксом во избежание коллизий UHT: `FRakisOnZoneChanged`, `FRakisOnCinematicFinished` (имена членов `OnZoneChanged`/`OnFinished` и сигнатуры — по контракту).
- Солнце должно быть Movable, SkyLight — желательно с Real Time Capture (иначе RecaptureSky с троттлингом 2 с).
- Синхронная загрузка ассетов (DT, MPC, звуки, LS) — допустимо для среза; для релиза перевести на `FStreamableManager`.
