# Сад сиетча (`Web/src/garden`)

Модуль `game.garden` (создаётся из `level/all.js`). Защищённая котловина за восточной гранью «Когтя», центр `GARDEN.center`=(840, 395), дно `GARDEN.floorY`=4.
В сиетче её выход — туннель к устью в грани Когтя (x≈799.5, z=392; `MOUTH` в `layout.js`), снаружи — каменная рамка входа, ступени и двор.
Это скрытая посадка сиетча: каменные желоба (qanat) от ветроловушек на северном гребне и перелива цистерны, чаша-распределитель, пруд,
ступенчатые грядки, финиковые пальмы у перелива, тамариск у воды, низкие акации, креозот и соляной куст, «бедная» трава, дюнная трава на краях, цветы после полива.
Живность: кенгуровые мыши (муад'диб), два ястреба, сыч на полке, ящерицы, жуки, ночью — кит-лисица. Садовники: водонос, ухаживающий за грядками, ребёнок.

## Файлы
| Файл | Что |
|---|---|
| `layout.js` | Константы и чистые функции: центр, `ringIn(θ)`/`ringH(θ)` (внутренний радиус и высота гребней), `floorHeight(x,z)` (дно с террасами и пандусом от устья), каналы `CHANNELS`, чаша `BASIN`, пруд `POND`, `BEDS`, `PLAZA`, `FACE(z)` (линия грани Когтя), позиции ветроловушек и полки совы. |
| `rim.js` | SDF-кольцо гребней (карта высот гребня + 3D-шум/страты/карниз, валуны, полка совы, проём устья в массе стены) → surface nets (`level/sdf.js`). |
| `structures.js` | Желоба (лоток + вода), чаша, пруд, грядки (почва + каменная кромка), двор, рамка входа (косяки/перемычка/ступени/знаки), носик перелива со струёй, башни-ветроловушки с качающимися флюгерами, капли и круги на воде, влажная земля вдоль каналов. |
| `plants.js` | Геометрия растений (карточки с альфой + стволы), материал с ветром в вершинном шейдере (`GWIND`: направление погоды, амплитуда ≈ ¼ пустынной), `InstGroup` — инстансы с чанковым LOD. |
| `flora.js` | Посев (seed), допуски (канал/грядка/двор/пруд/стена), коллайдеры стволов и камней (`owner:'garden'`). |
| `fauna.js` | Звери: прыжки по дуге, испуг/прятки, парение по кругу, сыч (голова за игроком, перелёт), ящерицы (бег-«рывок»), жуки (на рассвете встают «на голову»), лисица ночью. |
| `people.js` | Садовники `makeFigure` с маршрутами и остановками. |
| `textures.js` | Все canvas-текстуры (трава, листва, пальмовый лист, кора, цветы, почва, плитка, саман, нормаль воды, жалюзи башен). |

## API `game.garden`
- `zoneAt(pos)` → `'C1_Garden'` | `null` (для `core/zones.js`), `shelterAt(pos)` 0..1, `sheltered` (0..1 для игрока), `walkable(x,z)`, `ground(x,z)`, `faceAt(z)`.
- `flora`, `fauna` (`mice[]`, `hawks[]`, `owl`, `lizards[]`, `beetles`, `fox`), `people`, `structures`, `rim`, `volume`, `stats`.
- Шина: `garden:enter {x,z}` / `garden:leave {x,z}`; `garden:animal {kind, event, x, y, z}` — для звука (`hawk call`, `owl hoot|wings`, `mouse alarm`, `lizard scurry`, `fox bark`).
- Мир: `world.addGroundPatch` — дно котловины (радиус 56 + плавный переход 15 м); без него сад следует рельефу пустыни (пол не плоский, устье «утоплено»).
  `world.addRockHole` — отверстие в шейдере Когтя у устья; `world.addPassage` — проход через контур Когтя (без родного API ставится запасная обёртка и тёмная заглушка).
  `world.collide` — гребни (SDF-сетка), страховочный круг, контур Когтя; `world.surfaceAt` → `'packed'` на грядках, `'rock'` на дворе.

## Производительность
`med`: ~62 тыс. треугольников кольца, ~1.9 тыс. инстансов растений в ~28 draw-call (LOD по расстоянию до камеры, чанки 12–40 м), ~50 вызовов на зверей/людей/воду.
`low`: счётчики ×0.45, сетка гребней 1.0 м, дальности LOD ×0.7, без теней растений.

## Проверка
`node tools/build.mjs --out=level.html && node tools/level_shots.mjs --q=med --only=garden` → `dist/shots/level/*.png` (общий вид с двора, с гребня, вблизи звери, сумерки, ночь).
