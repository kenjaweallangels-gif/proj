# Сад сиетча (`Web/src/garden`)

Модуль `game.garden` (создаётся из `level/all.js`). Защищённая котловина за восточной гранью «Когтя», центр `GARDEN.center`=(840, 395), дно ≈ 4 м (террасы вниз к востоку до ≈ 2.7 м).
В сиетче её выход — штольня к устью в грани Когтя (`MOUTH` в `layout.js`: x≈801.2, z=395.8, пол y=5, арка 3.0 × 3.1 м), снаружи — каменная рамка, пологий спуск на площадь.
Из котловины наружу ведёт **овраг-выход** через седловину гребня (юго-восток, ≈ 15°; ломаная `RAVINE.pts`), по нему можно уйти в пустыню и вернуться; с гребней можно спрыгнуть.
Это скрытая посадка сиетча: каменные желоба (qanat) от ветроловушек на северном гребне и перелива цистерны, чаша-распределитель, пруд,
ступенчатые грядки, финиковые пальмы у перелива, тамариск у воды, низкие акации, креозот и соляной куст, «бедная» трава, дюнная трава на краях, цветы после полива.
Живность: кенгуровые мыши (муад'диб), два ястреба, сыч на полке, ящерицы, жуки, ночью — кит-лисица. Садовники: водонос, ухаживающий за грядками, ребёнок.

## Земля: одна поверхность
- `ground.js` (чистый JS) — аналитическая высота `G(x,z)` (дно с террасами и «подошвой» осыпи → овраг → пустыня) и **сетка** 1 м (`GRID`: x 788…956, z 336…460). Треугольники режутся одной диагональю, `grid.sample(x,z)` — ровно высота меша.
- `groundmesh.js` — меш пола из этой же сетки; материал: земля / утоптанная тропа / влажное / наносы песка по карте-сплату 0.4 м (`buildSplat`: тропы `PATHS`, влага у желобов и пруда), микрорельеф нормали, туман пустыни.
- `physics.js` — `world.heightAt(x,z,yФ)`: клетка пола есть → сетка + низкие стенки (`ground.bump`: желоба 0.3 м, кромка грядок 0.26 м, почва грядок 0.2 м — те же числа `WALL` рисует `structures.js`), выше пола берётся скала гребней
  (SDF-колонки) только если лежит заметно выше и достижима (ступени, наружный склон гребня). Нет клетки — как у подхода (`max(колонка скалы, пустыня)`).
  `world.surfaceAt` → `'soil'` (земля, грядки, овраг, трава) / `'stone'` (площадь, устье, чаша) / `'rock'` (скала); песка в котловине нет.
- Ландшафт пустыни внутри котловины опущен на 0.3 м (`world.addGroundPatch`), пол — с `polygonOffset`: пустыня не торчит и не мерцает. Сад хранит снимок «чистой» пустыни (1 м) и считает всё от него (до заплаток).
- Расхождение «вижу / стою»: в узлах сетки и внутри треугольников — 0 (тест `tools/garden_phys_test.mjs`); в браузере — raycast по мешу против `heightAt` на 200 точках (`tools/level_garden_walk.mjs --only=mismatch`).

## Устье (`mouth.js`)
Арочная облицовка-штольня (8 м вглубь, внутренний конец x = 793.2 — туннель сиетча кончается в x ≈ 793.5, тёмная к концу, не чёрная), каменная рамка (косяки, перемычка, порог вровень с полом), знаки на косяках, коллайдеры косяков и стенок штольни,
торцевая «тьма» — запасная, по умолчанию выключена (`setCap(true)`). Контракт с сиетчем: ось туннеля у устья — +X по `z = MOUTH.z`, пол `MOUTH.y`, сечение не больше `MOUTH.w × MOUTH.h`;
штольня свободно проходима в обе стороны (боковые стенки — коллайдеры, торца нет). Сад виден и из штольни (ближе 70 м к устью), а не только в пространстве `desert`.
Отверстие в шейдере Когтя (`addRockHole`) — сфера чуть больше арки; `addPassage` отключает контур Когтя на штольне.

## Файлы
| Файл | Что |
|---|---|
| `layout.js` | Константы и чистые функции: центр, `ringIn(θ)`/`ringH(θ)` (внутренний радиус и высота гребней; седловина у оврага), `floorHeight(x,z)` (дно: террасы, подошва осыпи, котлован пруда, пол устья), `RAVINE`, `PATHS`/`pathAt`, `polyDist`, каналы `CHANNELS`, чаша `BASIN`, пруд `POND`, `BEDS`, `PLAZA`, `MOUTH`, позиции ветроловушек и полки совы. |
| `ground.js` / `groundmesh.js` / `physics.js` | см. выше. |
| `rim.js` | SDF-кольцо гребней (карта высот от подошвы + 3D-шум/страты — шум гасится у земли, валуны, полка совы, проём устья, вырез оврага) → surface nets (`level/sdf.js`). |
| `mouth.js` | Устье: облицовка, рамка, знаки, коллайдеры. |
| `structures.js` | Желоба (лоток + вода), чаша, пруд (котлован + вода + галька), грядки (почва + низкая кромка, повторяющая землю), площадь, носик перелива со струёй, башни-ветроловушки, капли и круги на воде, влажная земля. |
| `plants.js` | Геометрия растений (карточки с альфой + стволы), материал с ветром в вершинном шейдере (`GWIND`), `InstGroup` — инстансы с чанковым LOD. |
| `flora.js` | Посев (seed), допуски (канал/грядка/двор/пруд/стена/тропа/овраг), коллайдеры стволов и камней (`owner:'garden'`). |
| `fauna.js` | Звери: прыжки по дуге, испуг/прятки, парение, сыч, ящерицы, жуки, лисица ночью. |
| `people.js` | Садовники `makeFigure` с маршрутами и остановками. |
| `textures.js` | Canvas-текстуры (трава, листва, пальма, кора, цветы, почва, плитка, саман, нормаль воды, жалюзи). |

## API `game.garden`
- `zoneAt(pos)` → `'C1_Garden'` | `null`, `shelterAt(pos)` 0..1, `sheltered`, `walkable(x,z)`, `groundAt(x,z)` (земля без стенок), `faceAt(z)`, `surfaceKind(x,z)`.
- `field`, `grid`, `ground(x,z)` (= `groundAt`), `groundMesh` (меш пола), `mouth`, `flora`, `fauna` (`mice[]`, `hawks[]`, `owl`, `lizards[]`, `beetles`, `fox`), `people`, `structures`, `rim`, `volume`, `perf {ms, avg, max}` (CPU мс `update()`), `stats`.
- Шина: `garden:enter {x,z}` / `garden:leave {x,z}`; `garden:animal {kind, event, x, y, z}`.
- Мир: `world.heightAt`, `world.surfaceAt`, `world.collide` (контур Когтя + SDF гребней; **без** страховочного круга — выйти из котловины можно по оврагу или по гребню), `world.addGroundPatch` (дно −0.3 м), `world.addRockHole`, `world.addPassage`.

## Производительность
`med`: пол ≈ 18 тыс. треугольников (1 draw), кольцо ≈ 90 тыс., ≈ 3.7 тыс. инстансов растений в ~28 draw-call (LOD по расстоянию до камеры, чанки), ~50 вызовов на зверей/людей/воду. `update()` садa — см. `garden.perf`.
`low`: счётчики ×0.45, сетка гребней 1.0 м, дальности LOD ×0.7, без теней растений. Шейдеры прогреваются асинхронно при создании.

## Проверка
- `node tools/garden_phys_test.mjs` — физика сада в node: боты (устье → овраг → пустыня и обратно, петля, грядки), совпадение сетки и меша, подъём на гребень.
- `node tools/build.mjs --out=garden.html && node tools/level_garden_walk.mjs` — прогон в браузере + расхождение земли в 200 точках.
- `node tools/level_shots.mjs --file=garden.html --scenes=garden_scenes.mjs --tag=garden2` → `dist/shots/garden2/*.png`.
