# Подход к скрытому входу (`Web/src/level`)

Модуль `game.approach` (создаётся из `level/all.js` вместе с садом; в `main.js` — один импорт и один шаг `level` после `harvester`).

Тропа ведёт от `ENTRY.trailStart` (A3/A4, у подножия) по осыпи западной грани «Когтя» к скрытой щели `ENTRY.cleft` (y≈30 м).
Маршрут (~210 м, 60–90 с): песчаный подход с каирнами → 4 зигзага по осыпи с валунами и уступами-полками →
ветровая арка (проход под плитой) → узкая полка над обрывом (кайма из камней) → вход в «щель» между плавником и стеной
(ступени, сужение зубом) → ниша-вход, скрытая нависающим плавником. Метки: три зарубки (знак пути), «крюк творца»,
неуклюжая роспись возрожденцев (три слоя истории). С верхних звеньев — вид назад на эрг (червь, харвестер).

## Устройство
| Файл | Что |
|---|---|
| `sdf.js` | 3D-шум, `Volume` (сетка расстояний 0.5 м, блочный пропуск пустоты), surface nets, `sample/grad`, колонки ходимых поверхностей `surfaceY(x,z,yФ)`, `collide(pos,r)`. Без THREE. |
| `scene.js` | Раскладка: звенья тропы (`LEGS`), карта высот осыпи (IDW по высотам звеньев + уступы + врезка/насыпь), валуны (хэш-сетка), арка, плавник/слот/зуб/пробка/ниша, масса стены. Без THREE (запускается в node). |
| `wall.js` | `wallX(z,y)` — положение мешa стены по лучам в реальной геометрии Когтя (`buildWallTable`, сторона west/east). |
| `physics.js` | `makeHeightAt` / `makeCollide` — обёртки `world.heightAt(x,z,yФ)` / `world.collide` (тестируются в node). |
| `rockmat.js` | материал: шейдер Когтя + атрибут `aMark` (протоптанная тропа светлее и менее песчаная). |
| `marks.js` | canvas-текстуры меток на камне. |
| `index.js` | сборка: меш, обёртки мира, декали, каирны, россыпь камней, коллайдеры (`owner:'approach'`), события. |

## API `game.approach`
- `trail` — массив `Vector3` (с полями `s`, `leg`), `trailLength`, `start`, `cleftPos`, `inZone(x,z)`, `progress(pos)` 0..1, `hiddenFrom(p)` — скрыт ли вход от точки.
- `volume` — сетка (для отладки), `stats {tris, verts, stones, boulders, buildMs}`.
- Шина: `approach:cleft {x,z}` — игрок дошёл до ниши (вход в сиетч дальше делает `game.sietch`/`zones`).
- Мир: `world.heightAt(x,z,yФ)` (в зоне — поверхность сетки не выше ступней+1.1 м), `world.surfaceAt` → `'rock'` на скале, `world.collide` (контур Когтя + сетка; внутри щели контур отключён — через `world.addPassage`, если есть, иначе локальная обёртка).
- `world.addRockHole` вызывается на нише (если нет — запасной вариант: `discard` в шейдере Когтя). Без `addPassage` перед нишей ставится тёмная заглушка.
