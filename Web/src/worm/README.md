# Шай-Хулуд (`src/worm/**`)

Модуль `game.worm` (создаётся после sietch, до player). Длина 360 м, Ø 40 м, 90 колец по 4 м.
Три режима: **дикий** червь (слух, не смертельный), **укрощённый** червь сцены «Встреча» (наездники, Оссана) и сценарий **«Червь пожирает харвестер»**.
**Всё идёт в реальном времени, управление игроком не отбирается**: нет кинокамеры, леттербокса, `game.cinematic.active=true`, блокировки ввода.
Внимание игрока привлекает мир: дрожь земли, пыль, песчаная волна на горизонте, спутники поворачивают головы и кричат.

| Файл | Что делает |
|---|---|
| `index.js` | Дикий червь: Dormant → Listening → Approach → Pass; сценарное `Ridden`; слух, кинематика головы, цепочка капсул-коллайдеров, API, шкала качества |
| `encounter.js` | Сцена «Встреча»: маршрут с обходом препятствий, 5 наездников, замедление и обессиленное падение, спуск по канатам, Оссана идёт к игроку, диалог, отдых |
| `riders.js` | Пять наездников: цепляются крючьями за швы колец (шест у рук, страховочный канат туго к крюку впереди, откинутый корпус, качка), передний рулит рычагом-крюком; позы спуска/сидения |
| `devour.js` | Сценарий пожирания харвестера: хронология, путь головы (подход → дуга → колонна), переносчик с тросами и капсулой, воронка, эффекты, безопасность игрока |
| `vortex.js` | Песчаная воронка (накладка на рельеф: вал, крутящиеся спиральные гребни, тёмный зев) → кратер |

| `spine.js` | История пути головы → 91 точка тела, перенос нормали, подъём головы, дыхание, оседание (`sag`), раструб шеи (`flare`), откат истории (`retract`) |
| `shaders.js` | Хитин/плоть/зубы (`MeshStandardMaterial` + `onBeforeCompile`), защита от NaN, `guardPostHaze` |
| `body.js` | Труба (шкала качества low/med/high), голова: 3 лепестка со складками губ, зубы-гребёнка, глотка; `headScale` (раструб пасти) |
| `gear.js` | Крючья творца в швах колец, канаты, сёдла (`RopeChain` — общий канат) |
| `fx.js` | Пул частиц, песчаная «юбка», носовая волна, шлейф, холм-волна дикого червя, тень-лента |

## Твёрдость (общий реестр `game.colliders`)
- Тело червя — цепочка из 45 капсул (`owner: 'worm'`, по одной на 2 кольца, радиус = радиус тела); `solid` только пока капсула над песком.
  Игрок и спутники выталкиваются автоматически (`game.collide`). Список: `game.worm.colliders`.
- Харвестер — 2 повёрнутых бокса (`owner: 'harvester'`: корпус и ковш), обновляются по ходу движения. Харвестер сам останавливается, если корпус
  (сейчас или через ~5 с по дуге петли) заденет тело червя (`harvester.blockedByWorm`).
- Маршрут червя обходит препятствия: каждая точка пути прогоняется через `game.collide(pos, R+запас, {ignore:'worm'})` (харвестер, Коготь через `world.collide`,
  валуны), смещение сглаживается (`path.js: relaxPath`); голова дополнительно тормозит, если впереди `colliders.segmentBlocked(...)`.
- Исключение — само проглатывание в сценарии пожирания: коллайдеры харвестера выключены (`harvester.setCollidersEnabled(false)`).

## API (`game.worm`)
- `state`: `Dormant | Listening | Approach | Pass | Ridden`. `threat` 0..1, `headPos`, `noise`, `exposed`, `tamed`, `resting`.
- `playReveal()` ≡ `playEncounter()` → `Promise<{skipped}>`: выполняется, когда **закончилась цепочка диалога** `DLG_A2_RIDER_01…10`. Червь остаётся лежать (фаза `rest`);
  уйти ему нечем. `isBusy()` — идёт ли сцена (после диалога — `false`, но червь на месте); `dismiss()` — тихо убрать лежащего червя (его же убирает `playDevour`).
- `playDevour(opts?)` → `Promise<{skipped, devoured}>` — сценарий «Червь пожирает харвестер» (см. ниже). `isDevouring()`, `devourPhase()`,
  `setAutoDevour(сек)` — автозапуск после N с непрерывной работы харвестера (0 = выключен, по умолчанию выключен), `devourTuning` — все числа сценария.
- `forceSurface(x?, z?)` — далёкая песчаная волна идёт к группе (state `Ridden`), подходит не ближе ~260 м и отворачивает, если `playReveal()` не вызван (~24 с).
- `setSensing(b)`, `foreshadow()`, `speakerPos('Ossana'|'Rider1'|'Rider2'|'Rider3'..'Rider5')` → Vector3 | null, `distanceToPlayer()`, `ossanaLanding`.
- `setQuality('low'|'med'|'high')`, `autoQuality` (понижает по FPS, когда червь на экране), `look` — uniform-ы шейдеров.
- Отладка: `debugEncounter({stage:'arrive'|'stop'|'dismount', u})`, `debugUnfreeze()`.

### Шина
- `worm:encounter {phase}`: `omen → arrive → stop (+collapse) → dismount → talk → rest` (+ `stir` на реплике `DLG_A2_RIDER_09`, `dismissed` при `dismiss()`).
  Фаз `depart` и `gone` **больше нет**, `cinematic` не эмитится.
- `worm:reveal {phase: start|erupt|end}`, `worm:breach {x,z}`, `worm:state {from,to}`.
- `worm:devour {phase}`: `wormsign → alarm → carryall-pod → erupt → swallow → retreat → aftermath → end` (затем `done`).
- Синхронизация по `bus 'subtitle' {id}`: `DLG_A2_RIDER_09` — червь шевелится; `DLG_A2_RIDER_10` — Оссана уходит от игрока.
- Необязательные внешние вызовы (через `?.`): `world.addFootprint`, `audio.event('Worm.Breach'|'Worm.Roar'|'Worm.Pass'|'Worm.RingSandfall'|'Worm.Heartbeat', pos)`.

## «Встреча» (реальное время)
1. `omen`: червь стартует далеко (≈420 м) на глубине под песком, курс — со стороны взгляда игрока и поперёк; видна песчаная волна, земля дрожит, камни-прыгуны,
   спутники поворачивают головы к червю (перехват `figure.lookAt`) и кричат (субтитры-барки).
2. `arrive`: всплытие (≈150 м пути), пять наездников на кольцах цепляются крючьями (шесты в швах, канат от пояса к крюку впереди, откинутые тела, качка в такт
   волне); передний вскрывает кольцо рычагом. Червь «устаёт»: к концу дуги ползёт всё медленнее.
3. `stop`/`collapse` (≈9.5 с): голова опускается, тело оседает (`spine.sag`, `sagHead`, `spread`), долгий вздох песка вдоль тела, дыхание замедляется (виртуальное время),
   пасть чуть приоткрыта.
4. `dismount`: наездники отцепляют шесты и один за другим спускаются по канатам; Оссана идёт туда, где стоит игрок (в любую точку, ускоряется вдали, зовёт).
5. `talk`: `DLG_A2_RIDER_01…10` в 4 м от игрока. 6. `rest`: промис выполнен; Оссана возвращается к телу, остальные сидят у червя и ухаживают за ним.

## «Червь пожирает харвестер» (реальное время)
`worm.playDevour({teleport?})`: дикий червь слышит работающий харвестер → волна из-за горизонта (≈25 с), клаксон и ракета экипажа, переносчик заходит и цепляет 4 троса
(струны, двигатели ревут, харвестер приподнят на 7 м), капсула экипажа взлетает к переносчику, песок оседает вихрем, харвестер наклоняется носом вниз (подвес за корму),
червь выныривает из воронки колонной с гигантской пастью (раструб ×2, кольца зубов), тросы рвутся, переносчик уходит с капсулой, харвестер соскальзывает в пасть с обломками,
пряной пылью и фонтанами; пасть смыкается, голова втягивается (`spine.retract`); остаются кратер, обломки и пятно пряности. Затем `harvester.isDevoured === true`.
Безопасность: коллайдеры харвестера выключаются только на время проглатывания; игрок, оказавшийся ближе 165 м к оси, мягко выносится ударом песка.
Повторный запуск возвращает харвестер на место (`harvester.restore()`), лежащий червь «Встречи» убирается.

## Причина «чёрного экрана» и защита
HDR-буфер — полу-float, `UnrealBloomPass` размазывает **один** NaN-пиксель на весь кадр. Источники NaN в старых шейдерах: `pow(1-abs(dot(n,v)), 2.2)` на зубах,
`normalize(0)` (нулевые нормали кончика лепестка/хвоста), производные внутри `if(gl_FrontFacing)` и после `discard`.
Теперь: `wnrm/wpow/wss`, проверка NaN/Inf по битам на выходе фрагмента, `guardPostHaze`, безопасные нормали, начальная поза позвоночника; в кинематике и
в сценариях — проверки `Number.isFinite` позиций.

## Тесты
- `node tools/build.mjs --out=worm.html && node tools/worm_realtime_shots.mjs [--views=player,riders,aerial --harvester=1]` — «Встреча» шагами 1/30 с: снимки с точки зрения игрока,
  проверка управления (W во время сцены), отсутствие cinematic/блокировки ввода, NaN в HDR-буфере, пересечение червя с харвестером.
- `node tools/worm_devour_shots.mjs [--views=player,side,aerial --only=erupt1,maw]` — сценарий пожирания: ключевые кадры, пересечения, безопасность.
- `node tools/worm_look.mjs`, `node tools/worm_probe.mjs` — осмотр вида и NaN-проба на позах.
