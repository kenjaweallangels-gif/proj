# Сиетч «Табр-ан-Нур» (браузерная версия) — пещерное поселение в живой скале

Модуль `game.sietch` (`index.js`). Сиетч — **лабиринт пещер, вырубленных в скале «Коготь»**: низкие неровные ходы с следами инструмента и
видимыми слоями породы, жилые комнаты семей за подвязанными занавесями из пряного волокна, двери-уплотнители (мембраны, сворачивающиеся в рулон),
парящие светошары, ветроловки, цистерна за печатью, **водяной погреб** (нижний уровень), зал собраний с «глоткой» червя. Никаких колонн, арок,
кирпича и настенных светильников.

## Бесшовность (без телепортов и затемнений)
* Сиетч лежит ВНУТРИ скалы в мировых координатах: `core/layout.js` → `SIETCH_ORIGIN {x:656,y:30,z:250,yaw:0}`, `ENTRY.cleft`
  (скрытая расщелина на западной грани), `GARDEN.portal` (**устье на восточной грани = (801.2, 5, 395)**, совпадает с `garden/layout.js: MOUTH`).
* Проектная система сиетча (все числа в коде/данных): +X вглубь, +Z вправо, Y вверх. Мир = `ORIGIN + R(ORIGIN.yaw + CAVE_YAW) · local`
  (`cave/layout.js: CAVE_YAW = 60°`). `game.sietch.root` повёрнут, `ctx.toWorld(x,y,z)` / `ctx.toLocal(v)` — преобразования.
* `contains(pos)` — «внутри пещер» (входная расщелина + выходной туннель **до плоскости устья**); `core/zones.js` по нему переключает `game.space`.
* Свет/туман/экспозиция плавно смешиваются по расстоянию до проёмов (обёртка `game.render`: `k = smoothstep(1, 22, d)` — на последних ~22 м туннеля
  к саду дневной свет нарастает плавно). Мировой солнечный свет вообще не попадает на материалы сиетча (`noSun`). Глубоко (> 40 м от проёмов)
  мир скрывается `world.setVisible(false)`.
* **Выход в сад** (`cave/layout.js: EXIT`) строится ОТ МИРОВОЙ ТОЧКИ УСТЬЯ: три галса-«змейки» с дугами R 3.8–6 м (уклон ≤ 14°, ступеней нет),
  затем 14 м строго на восток с ровным полом на уровне сада (y = 5 м) и раструбом под раму устья (3.0×4.3 м). За устьем SDF продолжается ещё на
  8 м («хвост»), но меш обрезается плоскостью `EXIT.cut` (открытый торец, без «крышки»), `contains()` там false → дальше работают мир/сад.
  Хаков `collide()` для конца туннеля больше нет: сетки пола/стен у устья непрерывны.

## Как устроена геометрия (подход: запекание на этапе сборки)
1. **SDF** (`cave/sdf.js`, `cave/field.js`, форма — `cave/layout.js`): туннели — эллиптические капсулы по ломаным, камеры — смешанные эллипсоиды,
   глобальный пол — функция высоты `floorY(x,z)` (ярусы, чаша, лестницы, нишевые «спальные платформы» +0.16 м), твёрдые тела (мост, парапеты,
   плита карниза, колонны) вычитаются, поверх — многооктавный шум (следы инструмента).
   **Подуровневые объёмы** (`buildSubs`): выход в сад и водяной погреб — примитивы с СОБСТВЕННЫМ полом (плоскость вдоль оси / функция ступеней / бассейн);
   поле остаётся честным SDF (Липшиц ≈ 1), без «траншей» в глобальном поле — поэтому нет дыр в меше. Проверка: `node tools/sietch_mesh_check.mjs`
   (граничные рёбра = дыры; `--box=x0,y0,z0,x1,y1,z1` для быстрой проверки области).
2. **Запекание** `node tools/sietch_bake.mjs` (~2.5 мин): surface nets (ячейка 0.37 м) → ~180k вершин / ~360k треугольников, нормали по градиенту SDF,
   **вершинное AO трассировкой по SDF**, **свет светошаров/шахт с тенями по SDF**, цвет (охры, копоть, полировка ладонями, сырость погреба), конформные
   декали трёх слоёв истории (+ «Книги водяных долгов» в погребе), сетки пола и расстояния до стен (два слоя), объём зондов света/AO 1 м,
   **PVS** (видимость чанков из ячеек 8 м). Упаковка (`cave/pack.js`): квантование каналов, дельта + байтовые плоскости + zlib → `src/assets/sietch_cave.js`
   (base64, цель ≤ 4 МБ; `node tools/sietch_sections.mjs` — размеры секций). `npm run build` запускает запекание только если исходники `cave/*` изменились.
3. **Рантайм** (`cave/runtime.js`): распаковка, меш режется на чанки 16 м, материал `M.rock` (процедурные слои породы + триплапланарные текстуры;
   нормаль-карты только ближе 26 м). **PVS-отсечение** (`index.js: updatePVS`): из ячейки камеры включаются только видимые чанки пещеры, их
   декали и реквизит (реквизит и декали разбиты по ячейкам 16 м и привязаны к чанкам) — в типичной точке рисуется ~1/3 сцены.
4. **Земля из SDF**: `heightAt` и `collide` (выталкивание по расстоянию до стен + блоки реквизита + `game.colliders`) соответствуют видимой скале.

## Комнаты и эркеры
* **B3**: 7 жилых комнат семей (`NICHES` в `cave/layout.js`): эллипсоид 6×4…7×9 м (площадь пола 21–45 м², потолок до 3.3 м) + вестибюль 2.3 м с подвязанной
  занавесью; 3 комнаты открытые. В комнатах: спальные тюфяки на коврах, низкий стол с набором для пряного кофе, стойки водяных колец, дистикомбы на вешалках,
  кладовые ниши с большими кувшинами, детский уголок с игрушками, крючья творца, сандалии у порога; профили: ткацкая (станок), кладовая-пантри, мастерская
  дистикомбов, комната старших.
* **B2 карниз**: 12 спальных эркеров 5×6 м (`SHELF_BAYS`, `BAY`) с постелями, сундуками, крючьями и подвязанными занавесями.
* **Занавеси** (`rooms.js: tiedCurtain`): ламбрекен + две створки, собранные подхватами к краям; без коллизии. В шейдере ткани (`mats.js`) вокруг капсул
  персонажей — гладкое раздвижение по горизонтали (радиус ~1 м) + жёсткий минимальный толчок; «рука отодвигает занавесь» — слабый (≤ 0.35) и
  отключаемый жест: `game.settings.curtainHand = false`.

## Водяной погреб B6 (`B6_Cellar`)
Лестница (50 ступеней по 0.18 м, верёвочный поручень) от южной ветки B3 → тамбур со стражей → **уплотнитель `cellar`** → сводчатый неф 35×15 м с тёмным
бассейном (отражения светошаров, рябь от капель), восемью колоннами, десятью нишами-кладовыми с запечатанными сосудами, водосборными тазами под трубками-
воронками, станцией измерения (весы, мерные столбики, эталон, книга долгов) и стеной «долгов воды» (декаль `tally`). Прохладный влажный воздух:
туман (`ctx.mist`), капли с ударами в воду и звуком `Water.Drip` (`ctx.drips`), конденсат на камне (атрибут `par.z`), холодный оттенок. Стража (3), писец, водоносы.
`zoneAt(pos)` возвращает `'B6_Cellar'` по локальной высоте (`plan.zoneAtLocal(x,z,y)`).

## Атмосфера (`life.js`, `crowd.js`)
Кухня с очагом (угли, мерцающий свет, дым вверх), ритуал пряного кофе (пар/аромат, bus `sietch:coffee`), музыкант с удом и слушатели в галерее
(bus **`sietch:music`** `{on, id, level 0..1, position, tempo, mood}` при смене и каждые 0.5 с пока слышно; состояние в `game.sietch.music`),
спящие в комнатах/эркерах (поза «лёжа», дыхание), дети (догонялки по B3, игры в комнатах и у лестницы), ткачи (`Loom.Clack`), тени людей на стенах
от ближайшего светошара (пул 3–8 квадов), пыль в лучах, сандалии у порогов, кольца и крючья на стенах.

## API
| Метод | Что делает |
|---|---|
| `contains(pos)` | `pos` (мир) внутри пещер (до плоскости устья выхода) |
| `heightAt(x,z[,yFeet])`, `surfaceAt(x,z)`, `collide(pos,r)`, `zoneAt(pos)` | мировые координаты; зоны `B1_Airlock…B5_Hall`, **`B6_Cellar`**, `'sand'` в чаше |
| `enter([point])` | ТОЛЬКО отладочный телепорт: `'B1'..'B6'`, `'bowl'`, `'exit'`, `'exitStart'`, `'cleft'`, `'cellar'`, `'pool'`, `'station'`, `'room'`, `'room2'`, `'bay'` |
| `exitPath` | массив Vector3 (мир): ось выходного туннеля от зала до плоскости устья; `mouths.cleft/portal` — мировые точки проёмов |
| `music` | `{playing, level, position, id, tempo}` |
| `startRitual()`, `playFinale({hold})`, `endFinale()`, `speakerPos(id)` | как раньше |
| `toWorld`, `toLocal`, `crowd`, `doors`, `lighting`, `finale`, `poi`, `cave`, `probes`, `pvsStats` | внутренние подсистемы |

События bus: `sietch:music`, `sietch:coffee {position}`, `interact {tag:'Rakis.SealDoor', id}` (id: outer|inner|cellar), `sietch:ritualStart`, `sietch:seated`.

## Двери-уплотнители (`doors.js`)
Изогнутые полупрозрачные мембраны в эластомерном ободе, сворачиваются в рулон к краям проёма; карманы вырезаны в скале. Автооткрытие при приближении,
`Door.SealHiss`. Уплотнитель #3 (цистерна) сдвинут навсегда (кованая решётка). Уплотнитель `cellar` — обычный (подуровневый, пол −9 м).

## Твёрдость
Реквизит — блоки в `plan.addBlock` и боксы `game.colliders` (owner `'sietch'`); каждый житель — капсула `game.colliders`. Занавеси, ковры, постели, игрушки — без коллизии.

## Производительность
PVS-отсечение чанков/декалей/реквизита; пул PointLight 3/5/8 (low/med/high) вместо 6/10/14; шейдер породы ~вдвое дешевле (однооктавный шум, нормаль-карты
вблизи); толпа: дальние жители тикают реже (0.12/0.3/0.6 с), капсулы дальних — раз в 0.4 с; светошары-ореолы дальше 62 м не рисуются.

## Инструменты
* `node tools/sietch_bake.mjs [--cell=0.37] [--if-stale]` — запекание; `node tools/sietch_mesh_check.mjs [--box=…]` — дыры в меше; `node tools/sietch_slice.mjs` — ASCII-срезы SDF;
  `node tools/sietch_sections.mjs` — размеры секций бейка; `node tools/sietch_walk.mjs [--dump]` — проходимость зон/спотов/комнат/погреба/устья + профиль пола туннеля;
  `node tools/sietch_walktest.mjs` — сценарный проход в игре (headless), туда и обратно, включая выход в сад;
* `node tools/sietch_shots.mjs [--q=low] [--only=a,b]` — кадры в `dist/shots/sietch/` (после `node tools/build.mjs --out=sietch.html`).
