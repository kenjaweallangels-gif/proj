# Сиетч «Табр-ан-Нур» (браузерная версия) — пещерное поселение в живой скале

Модуль `game.sietch` (`index.js`). Сиетч — **лабиринт пещер, вырубленных в скале «Коготь»**: низкие неровные ходы с следами инструмента и
видимыми слоями породы, жилые ниши за занавесями из пряного волокна, двери-уплотнители (мембраны, сворачивающиеся в рулон),
парящие светошары, ветроловки, цистерна за печатью, зал собраний с «глоткой» червя. Никаких колонн, арок, кирпича и настенных
светильников.

## Бесшовность (без телепортов и затемнений)
* Сиетч лежит ВНУТРИ скалы в мировых координатах: `core/layout.js` → `SIETCH_ORIGIN {x:656,y:30,z:250,yaw:0}`, `ENTRY.cleft`
  (скрытая расщелина на западной грани), `GARDEN.portal` (выход на восточной грани).
* Проектная система сиетча (все числа в коде/данных): +X вглубь, +Z вправо, Y вверх. Мир = `ORIGIN + R(ORIGIN.yaw + CAVE_YAW) · local`
  (`cave/layout.js: CAVE_YAW = 60°` — ось залов идёт на ЮГО-ВОСТОК вдоль тела Когтя, чтобы 200 м пещер уместились в скале;
  `tools/sietch_walk.mjs` проверяет `clawInside`). `game.sietch.root` повёрнут, `ctx.toWorld(x,y,z)` / `ctx.toLocal(v)` — преобразования.
* `contains(pos)` — «внутри пещер» (включая входную расщелину и выходной туннель); `core/zones.js` по нему переключает `game.space`.
* Свет/туман/экспозиция плавно смешиваются по расстоянию до проёмов (обёртка `game.render`: мировые источники гасятся на `k`,
  туман/фон подмешиваются). Мировой солнечный свет вообще не попадает на материалы сиетча (`noSun`). Пустыня видна из проёмов;
  глубоко внутри (> 38 м от проёмов) мир скрывается `world.setVisible(false)`.
* Проёмы: `world.addRockHole({x,y,z,r})` и `world.addPassage({points, width})` вызываются, если реализованы (вход и портал).
* Выход: туннель от северо-восточной стены зала (змейка, −25 м) к порталу в котловину (`cave/layout.js: EXIT`).

## Как устроена геометрия (подход: запекание на этапе сборки)
1. **SDF** (`cave/sdf.js`, `cave/field.js`, данные формы — `cave/layout.js`): туннели — эллиптические капсулы по ломаным, камеры —
   смешанные эллипсоиды (гладкий min/max), пол — функция высоты `F(x,z)` (ступени-яруса, чаша, скат лестниц, спуск выхода),
   твёрдые тела (мост-арка, парапеты, плита карниза, природные колонны цистерны, парапет помоста) вычитаются, поверх —
   многооктавный шум (следы инструмента, неровности) и рёбра свода «глотки червя» (кольца + радиальные рёбра, рельеф «Глотка»).
2. **Запекание** `node tools/sietch_bake.mjs` (`cave/bake.js`, ~1–2 мин): surface nets (ячейка 0.34 м) → ~180k вершин / ~360k треугольников,
   гладкие нормали (градиент SDF), **вершинное AO трассировкой лучей по SDF**, **освещение светошарами/шахтами с тенями по SDF**,
   цвет (охры, копоть над шарами, полировка ладонями на высоте руки в узких местах и по тропам, влажность у цистерны, песок),
   конформные декали трёх слоёв истории, сетки пола и расстояния до стен (два слоя: пол < 4.4 м и карниз/мост), объём «зондов»
   света/AO 1 м для реквизита и толпы. Результат упаковывается (Uint16/Int8, дельта-индексы, zlib) в `src/assets/sietch_cave.js`
   (base64, ~3.7 МБ); `npm run build` запускает запекание только если исходники `cave/*` изменились (`--if-stale`).
3. **Рантайм** (`cave/runtime.js`): распаковка ~0.6 с, меш режется на чанки 16 м (frustum culling), материал `M.rock`
   (процедурные слои породы/штрихи инструмента/песок/влага + триплапланарные `getTex('rock_cave'|'cave_floor')`, если есть в манифесте).
   Весь сиетч (с реквизитом и толпой) собирается за ≈ 3 с на среднем ПК.
4. **Земля из SDF**: `heightAt` (поиск пола вниз от y ступней по запечённой сетке, два слоя) и `collide` (выталкивание по градиенту
   расстояния до стен на высоте тела + блоки реквизита + `game.colliders`) соответствуют видимой скале точно.

## API
| Метод | Что делает |
|---|---|
| `contains(pos)` | `pos` (мир) внутри пещер |
| `heightAt(x,z[,yFeet])`, `surfaceAt(x,z)`, `collide(pos,r)`, `zoneAt(pos)` | мировые координаты; зоны `B1_Airlock…B5_Hall`, `'sand'` в чаше |
| `enter([point])` | ТОЛЬКО отладочный телепорт без затемнения: `'B1'|'B2'|'B3'|'B4'|'B5'|'bowl'|'exit'|'cleft'` |
| `startRitual()` | идемпотентно; также по bus `ritual` и при входе в `B5_Hall` |
| `playFinale({hold})` → Promise | ≈ 20 с В РЕАЛЬНОМ ВРЕМЕНИ: без кат-сцены и без камеры; Хармат оборачивается к игроку, когда тот подходит к помосту (и принудительно к концу); `bus 'finale' {done}` |
| `endFinale()`, `speakerPos(id)` | `'Harmat'|'Priestess'|'Dancer'|'Guard'` → Vector3 (мир) |
| `toWorld(x,y,z)`, `toLocal(v)`, `crowd`, `doors`, `lighting`, `finale`, `poi`, `cave`, `probes` | внутренние подсистемы |

## Двери-уплотнители (`doors.js`)
Изогнутые полупрозрачные мембраны в эластомерном ободе с клёпками и сигнальными лампами. Две створки сворачиваются в рулон к краям проёма
(вершинный шейдер: спираль рулона растёт от свободного края), рулоны уходят в вертикальные карманы, вырезанные в скале.
Автооткрытие при приближении, шипение `Door.SealHiss`, bus `interact {tag:'Rakis.SealDoor'}`, конденсат-пар. Уплотнитель #3 (цистерна)
сдвинут навсегда, проход закрыт кованой решёткой (видна вода).

## Занавеси-«двери» и рука
Мини-комнаты (жилые ниши B3, спальные ниши карниза B2) закрыты тканью из пряного волокна. Ткань деформируется шейдером вокруг
капсул персонажей (`U.uCapA/uCapB`, до 6 толкателей: тело + «рука» игрока и спутников). Когда персонаж подходит к занавеси лицом
(< 1.35 м), вызывается `figure.reachTo?.(worldPoint, 'R', weight)` (IK руки); после прохода вес снимается.

## Твёрдость
Реквизит — блоки в `plan.addBlock` (учитываются `game.collide`) и боксы `game.colliders` (owner `'sietch'`); каждый житель — капсула
`game.colliders` (динамическая, обновляется каждый кадр).

## Инструменты
* `node tools/sietch_bake.mjs [--cell=0.34] [--if-stale]` — запекание; `node tools/sietch_walk.mjs [--dump]` — проходимость зон/спотов/портала и посадка в скале;
* `node tools/sietch_shots.mjs [--q=low] [--only=a,b]` — кадры в `dist/shots/sietch/` (после `node tools/build.mjs --out=sietch.html`).
