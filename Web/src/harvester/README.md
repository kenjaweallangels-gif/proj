# Харвестер «Сарт-Макр ХВ-017» (`src/harvester/**`)

Огромный рабочий добывающий комбайн (оригинальный дизайн): ~113 x 45 x 35 м, четыре гусеничные тележки, ковш-«пасть», подающий
конвейер, две башни-центрифуги, шесть труб, радиаторы, мостик с горящими окнами, моторная рубка, перила/трапы, стыковочные
захваты переноса на крыше. Над ним парит **переносчик** (тяжёлый орнитоптер, крылья «гудят» ~1,8 Гц).

Модуль подключается в `main.js` после `worm` (`harvester.create(game)`), регистрирует `game.harvester`.

## Расположение
- Старт: `x=330, z=-60` (метры раскладки), курс вдоль +X (`START` в `index.js`). Высота — по `game.world.heightAt` в четырёх
  точках под тележками (крен/тангаж плавно следуют рельефу). Виден с золотого пути P2–P4 как ориентир (бортом, ~160 м).
- В работе ползёт со скоростью **1,5 м/с** по большой петле радиуса 30 м влево (к -z) — не дальше ~60 м от старта.

## API (`game.harvester`)
| поле | описание |
|---|---|
| `state` | `'off' \| 'starting' \| 'running' \| 'stopping'` |
| `start()`, `stop()`, `toggle()` | запуск (≈10 с), остановка (≈6 с); возвращают true, если команда принята |
| `collide(pos, r)` | выталкивает `pos` (Vector3, XZ) из силуэта корпуса и ковша; true — было столкновение |
| `position` (Vector3), `heading`, `speed`, `rpm` (0..1), `dims` | телеметрия |
| `interactable` | запись в `game.interactables` (см. ниже) |
| `carryall` | `{group, update}` — переносчик |
| `debugSet('off'\|'running'\|'starting', t)`, `place(x, z, heading)`, `setVisible(b)` | для тестов/отладки |

### Коллизия (важно)
Пустыня (`src/desert`) не правится, поэтому в `create()` оборачиваем коллизию мира:
```js
const prev = game.world.collide;
game.world.collide = (p, r) => !!(prev.call(game.world, p, r) | harvester.collide(p, r));
```
`game.collide()` в пустыне идёт именно через `game.world.collide`. Силуэт — два повёрнутых прямоугольника
(корпус 111x45,6 м и ковш 17x41,6 м); пространство под корпусом считается непроходимым.

### Запуск и интерактив
- `game.interactables`: `{tag:'Rakis.Harvester', radius:4, label:{RU:'Завести харвестер',EN:'Start the harvester'}}` — пульт у трапа
  на правом борту (локально x=12,5, z=25,2); во время `running` подпись — «Заглушить»/`Shut down`; в переходных состояниях
  интерактив отключён (`enabled=false`).
- Последовательность запуска (~10 с): 0 с — клаксоны и вращающиеся маяки; 0–6 с — чёрный дым из труб, прогрев; 3–6,5 с — ковш
  опускается в песок; 5–7,5 с — шнек и лента; 6–10 с — гусеницы набирают ход, растёт шлейф оранжевой пыли; после 6 с дым светлеет
  до марева над трубами; на 10 с — состояние `running`. Остановка — в обратном порядке (6 с).
- Работающий харвестер: тряска `game.shake` (до ~0,36 вблизи, спад до ~170 м), колея `world.addFootprint(x, z, yaw, {type:'worm', size:4.3})`
  каждые 3,6 м по линиям тележек, шум.

### События шины
- `harvester {state}` — `'starting' | 'running' | 'stopping' | 'off'` (при каждом переходе и при создании — `'off'`).
- `noise {x, z, loudness, source:'Harvester'}` — раз в секунду, пока `state !== 'off'`; `loudness` 0,35..1,0 (при пуске — 0,5).
  Дикие черви не должны становиться смертельными — решает модуль червя.

### События звука (`game.audio?.event(id, pos)`, pos — Vector3 над центром машины)
- `Harvester.Start` — нажат пуск (клаксон, стартёр);
- `Harvester.Run` — переход в `running` (зацикленный гул двигателей; громкость можно брать из `game.harvester.rpm`);
- `Harvester.Stop` — нажата остановка.

## Свет
Ровно 4 источника: 2 прожектора кабины (SpotLight), рабочий свет ковша и лампа у пульта (PointLight). Число не меняется
(иначе пересборка шейдеров); интенсивность зависит от `world.sunDir.y` (ночь). Окна/лампы — эмиссив (`MeshBasicMaterial`),
маяки мигают красным, клаксоны — янтарные с вращающимися лучами.

## Производительность
- Корпус — 1 меш с вершинными цветами и тегами материала (`aTag`), общий материал `hull` (патч `onBeforeCompile` поверх
  `desert/env.js: patchMaterial` — общий туман): триплонарные панели 4x2 м, швы, заклёпки, грязь, масляные потёки, ржавчина,
  сколы, пескоструй, пыль на верхних гранях, нормали-«бамп» по производным (не на `low`).
- `InstancedMesh`: звенья гусениц (296), звёздочки/катки, стойки перил, болты, рёбра радиатора, планки ленты, барабаны, вентиляторы.
- Draw calls (вблизи): ~26 (+ частицы 1, лучи 1). Вдали (>420 м) — упрощённый корпус (1 меш), вне кадра — не рисуется (`root.visible`).
- Тени: только если `quality != 'low'` и камера ближе 260 м.
- Частицы: пул `1100 * k` (low 0,45; high 1,4).
- Декали-трафареты (гильдия, номер, шевроны, знаки) — один меш и один canvas-атлас (`material.js`).

## Файлы
`index.js` (состояния, физика движения, интерактив, свет, частицы) · `hull.js` (процедурная геометрия) · `tracks.js` (гусеницы) ·
`material.js` (шейдер корпуса, декали) · `fx.js` (частицы, лучи) · `carryall.js` (переносчик) · `parts.js` (сборщик геометрии).
Тест: `node tools/build.mjs --out=harvester.html && node tools/harvester_shots.mjs [--q=low|med] [--only=views,close,startup,run,night]`.

## Три слоя истории
Сам харвестер — наследие Квизарата: имперские шевроны/знаки гильдии на бортах; в правой секции видны латаные листы и
неумелые росписи (оливковые накладки, пучки меток смен) — след возрожденцев, подобравших брошенную машину.
