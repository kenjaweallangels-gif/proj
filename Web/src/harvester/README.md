# Харвестер «Сарт-Макр ХВ-017» (`src/harvester/**`)

Огромный рабочий добывающий комбайн-фабрика (оригинальный дизайн), ~118 x 46 x 38 м: бронированный корпус на четырёх гусеничных
тележках, **сидящий в песке** (подошва гусениц на 4 м ниже уровня песка, к бортам нагребены валы), ковш-«пасть» со шнеком, подающий
конвейер, башни-центрифуги, трубы, броневые «плечи», несущие балки и захваты для переноса на крыше, наблюдательный портал
с люлькой спасательной капсулы. **Внутрь можно войти**: трап → шлюз → коридор → кубрик, кают-компания, лаборатория, комната
дистикомбов, машинное отделение, приёмный зал, зал переработки с центрифугами и катвоками, штурманская, мостик с окнами на дюны.
Над машиной висит **переносчик** — тяжёлый аппарат вертикального взлёта с четырьмя членистыми крыльями.

Модуль подключается в `main.js` после `worm` (`harvester.create(game)`), регистрирует `game.harvester`.

## Расположение
- Старт: `x=330, z=-60` (метры раскладки), курс вдоль +X (`START` в `index.js`). Высота — по `game.world.heightAt` в четырёх
  точках под тележками (крен/тангаж плавно следуют рельефу), корпус утоплен на `SINK` = 4 м (`layout.js`).
- В работе ползёт со скоростью **1,5 м/с** по большой петле радиуса 30 м влево (к -z); **пока игрок на борту (трап/интерьер), машина стоит**
  (механизмы работают, гусеницы не идут), чтобы пол не уезжал из-под ног.

## Системы координат
Локально: `+x` — вперёд (ковш), `+y` — вверх от подошвы гусениц (песок на `y = SINK`), `+z` — правый борт.
Все размеры палуб/дверей — `layout.js` (`FA` пол нижней палубы 10,6; `FB` пол зала 17,9; `FC` пол мостика 22,9; `DOOR`, `GANG`, `LANDING`).

## API (`game.harvester`)
| поле | описание |
|---|---|
| `state` | `'off' \| 'starting' \| 'running' \| 'stopping'` |
| `start()`, `stop()`, `toggle()` | запуск (≈10 с), остановка (≈6 с); возвращают true, если команда принята |
| `position` (Vector3), `heading`, `speed`, `rpm` (0..1), `dims` | телеметрия (`position` — начало координат модели, на 4 м ниже уровня песка) |
| `interactable` | пульт запуска у подножия трапа (`game.interactables`); второй пульт — на мостике (`interactable2` в списке) |
| `carryall` | `{group, update, script, setCables, setPod, pod, cabMesh, lugWorld, body}` — переносчик |
| `debugSet('off'\|'running'\|'starting', t)`, `place(x, z, heading)`, `setVisible(b)` | для тестов/отладки |

### Борт как «подпространство» (как сиетч): `contains / heightAt / surfaceAt / collide`
Игрок может ходить по трапу, посадочной площадке и всем помещениям (в т.ч. на второй палубе и мостике). Ядро выбирает землю по точке:
| метод | описание |
|---|---|
| `contains(pos)` | true, если ступни `pos` (Vector3 в мире, **y обязателен**) стоят на борту (в пределах ±1,3 м от пола: трап, площадка, комнаты); под трапом/под корпусом — false |
| `heightAt(x, z, y)` | высота пола под точкой (мир). `y` — высота ступней (для многоэтажности). Если полов нет — высота грунта |
| `surfaceAt(x, z, y)` | `'rock'` на борту (металл — без шума песка), иначе `'sand'` |
| `collide(pos, r)` | на борту — стены/мебель/перила интерьера (по схеме проходимости); снаружи — силуэт корпуса и ковша. true — было столкновение |
| `roomAt(pos)` | `{id, name}` помещения под точкой или null |
| `occupied` | игрок на борту (машина стоит, твёрдость корпуса в `game.colliders` снята) |
| `interior` | `{ready, progress, floorAt, contains, collide, roomAt, stats()}` — в ЛОКАЛЬНЫХ координатах модели |

**Подключение к ядру.** По умолчанию модуль сам подменяет `game.heightAt / game.surfaceAt / game.collide` (идемпотентно, флаг
`harvester.autoWired`): если точка `contains` — высота/столкновения берутся с борта (`+ colliders.push(... ignore:'harvester')` для остальных тел), иначе — прежний путь.
Если ядро (`core/game.js groundAt`) выбирает землю само через `game.harvester`, выставьте `game.harvesterWired = true` **до** `harvester.create(game)` — тогда подмена не ставится.
Событие шины `harvester:board {inside}` и аудио-события `Harvester.Board` / `Harvester.Leave` при входе/выходе.

### Коллизия снаружи
Корпус и ковш зарегистрированы в общем реестре `game.colliders` как два повёрнутых бокса (`owner: 'harvester'`, корпус 96×45,6 м и ковш 17×41,6 м, высота 38 и 22 м),
позы обновляются каждый кадр. На время, пока игрок на борту (`occupied`), бокс корпуса получает `solid=false`
(червь/прочие тела при этом проходят насквозь — допущение; ковш остаётся твёрдым).
Харвестер **сам тормозит**, если корпус (сейчас или через ~5 с по дуге петли) заденет тело червя (`owner: 'worm'`): `harvester.blockedByWorm`.
`harvester.setCollidersEnabled(false)` — только на время проглатывания.

### Запуск и интерактив
- Пульт у подножия трапа (локально x=37,4, z=28,4) и второй — на мостике; подпись — «Завести харвестер»/«Заглушить»; в переходных состояниях интерактив отключён.
- Последовательность запуска (~10 с): 0 с — клаксоны и вращающиеся маяки; 0–6 с — чёрный дым из труб, прогрев; 3–6,5 с — ковш
  опускается в песок; 5–7,5 с — шнек и лента; 6–10 с — гусеницы набирают ход, растёт шлейф оранжевой пыли; на 10 с — `running`. Остановка — в обратном порядке (6 с).
- При работе внутри оживают механизмы: поршни и маховики в машинном отделении, вентиляторы, центрифуги в зале переработки (вращаются ротора), ленты (планки бегут),
  приводы приёмного зала, экраны (радар, обороты, выход пряности, схема ленты). Питание света: при пуске мерцание, при тревоге — пульсация.
- Работающий харвестер: тряска `game.shake`, колея `world.addFootprint(...)`, шум.

### Сценарий «Червь пожирает харвестер» (API для `worm/devour.js`) — без изменений
`setState('devoured')` / `isDevoured`, `restore()`, `script({x,y,z,pitch,roll})` / `script(null)`, `setLift(m)`, `alarm(b)`, `flare()`, `hookPoints()`,
`provokeWorm(opts)`, `hold(b)`, `toWorld(lx,ly,lz)`, `wreck`, `stain`, `particles`, `carryall.script`, `carryall.setCables(targets, tension, vib, t)`, `carryall.setPod(pos, yaw, visible)`.
Берма (песчаные валы) при подвесе/сценарной позе убирается; крюки захватов — на прежних местах (`LUG_TOP`), люлька капсулы — на портале (26; 37,2; 0).

### События шины
- `harvester {state}` — `'starting' | 'running' | 'stopping' | 'off' | 'devoured'`; `harvester:board {inside}`.
- `noise {x, z, loudness, source:'Harvester'}` — раз в секунду, пока `state !== 'off'`.
### События звука
`Harvester.Start`, `Harvester.Run`, `Harvester.Stop`, `Harvester.Board`, `Harvester.Leave`.

## Интерьер (`interior.js`, `rooms_a.js`, `rooms_b.js`, `ibuild.js`, `imaterial.js`)
- Помещения: нижняя палуба — шлюз-галерея (вход, дверь-шторка поднимается при приближении), главный коридор с трапом наверх, кубрик (63 койки),
  комната дистикомбов и рекуперации влаги, кают-компания, лаборатория проб, приёмный зал с лентой, машинное отделение; верхняя — зал переработки
  (две центрифуги, лента, катвоки второго яруса на 3,3 м, силосы), переход, штурманская, мостик (у лобовых окон; боковые и лобовые окна — проёмы).
- Строится **лениво** (камера ближе 170 м; по одному помещению за кадр), рисуется только когда камера у корпуса/внутри. ~22 draw call, ≈70–120 тыс. треугольников (только вблизи).
- Свет **запечён в вершинные цвета** (лампы комнаты, затемнение стыков) — без источников света (число светильников сцены не меняется, шейдеры не пересобираются);
  материал `MeshBasic` + процедурные панели/заклёпки/рифлёнка/ткань + текстура `metal_painted` (triplanar); «питание» ламп — uniform `uIPow`.
- Эмиссивные панели и экраны: меш свечения + атлас живых экранов (canvas, обновляется 5 раз/с только внутри).
- Три слоя истории: имперские трафареты Квизарата (орёл, шевроны, надписи) → резные плиты фрименов (волны/спираль) → неумелые росписи возрожденцев (червь, ладони, синий глаз, метки).
- Схема проходимости строится вместе с геометрией (`Plan`): полы (в т.ч. наклонные — трапы), твёрдые боксы (стены, мебель, перила). Запросы O(несколько сотен боксов).

## Внешний вид
- Корпус — полая силовая оболочка (стены-плиты 0,8 м) с настоящими проёмами (дверь, лестничные шахты, окна мостика); один меш с вершинными цветами и тегами материала (`aTag`),
  общий материал `hull` (триплонарные панели, швы, заклёпки, грязь, ржавчина, пескоструй, пыль/пряность на верхних гранях, песчаные наносы — тег 6).
- Песок: берма вокруг корпуса (`berm.js`, сетка 2 м, привязана к рельефу порциями), наносы на кровлях (тег 6), пыль на горизонтальных гранях.
- Броневые щиты тележек, «плечи» на палубе, жёлтые несущие балки кровли, портал-эстакада с наблюдательной кабиной.

## Переносчик (`carryall.js`)
Фюзеляж + грузовой киль с четырьмя лебёдками (крюки на прежних точках подвеса `LUG_LOCAL`), носовой гондол экипажа, хвост с двойным оперением,
**четыре членистых крыла по 3 звена** (взмахи с запаздыванием по звеньям, гул ~1,5–1,9 Гц), четыре подъёмных кольцевых вентилятора (вращаются), убирающиеся опоры
(выпускаются у земли), навигационные огни, декали (эмблема/номер/шевроны). API прежний.

## Производительность
- Корпус (вблизи) — 1 меш + `InstancedMesh`: звенья гусениц, катки, перила, болты, рёбра радиатора, барабаны, планки ленты; ~30 draw call. Вдали (>420 м) — упрощённый корпус (1 меш).
- Шейдер корпуса дешевеет с расстоянием: полный (>170 м → упрощённый), триплонарная текстура гаснет к 190 м.
- Тени: только если `quality != 'low'` и камера ближе 260 м; кастеры — корпус и ковш.
- Интерьер: строится заранее, но не рисуется снаружи; свет без источников; экраны и механизмы обновляются только когда интерьер виден.
- Частицы: пул `1100 * k` (low 0,45; high 1,4).
